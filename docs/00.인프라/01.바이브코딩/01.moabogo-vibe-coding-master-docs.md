# 모아보고 (MoaBogo) 바이브 코딩 마스터 통합 개발 문서

## 📌 최신 반영사항 및 서비스 개요

* **서비스명**: **모아보고 (MoaBogo)**
* **도메인**: `moabogo.com`
* **핵심 정체성**: 1인 다중 가계부 + 독립 정산/게임 + 확장 생활 서비스 (당번, 용돈, 빌림)
* **주요 정책**: 
  1. **모아당번**: 게스트 지정 지원, `ASSIGNED` -> `ENDED` -> `COMPLETED` 상태 머신.
  2. **독립 이벤트**: 게스트 포함 시 전체 자동 연동 차단 -> 정식 구성원만 `[수동 연동]` 버튼 활성화.
  3. **회계 원칙**: 모아용돈은 그룹 가계부 내 이중 합산 방지, 모아빌림은 자산/부채 이동 처리.
