# 01-prd-spec.md : 모아보고 (MoaBogo) 제품 요구사항 정의서 (PRD)

## 1. 서비스 정체성 & 기본 정책
- **서비스명**: 모아보고 (MoaBogo) | **도메인**: `moabogo.com`
- **핵심 가치**: 1인 다중 가계부, 독립 모임 정산/게임, 확장 라이프 서비스(당번/용돈/대여) 통합.

---

## 2. 모듈별 상세 요구사항

### 2.1 1인 다중 가계부 (Multi-Ledger)
- **개인 가계부 자동 생성**: 회원가입 완료 즉시 `[내 개인 가계부]` (`ledger_type: PERSONAL`) 기본 생성 (Zero-Onboarding).
- **그룹 가계부 스위칭**: `[우리집 가계부]`, `[모임 가계부]` (`ledger_type: GROUP`) 스위칭 시 RBAC 권한(Owner, Member, Viewer) 및 알림톡 공유 활성화.

### 2.2 2단계 OCR & 오인식 예외 처리 가드레일
- **1차 로컬 OCR**: 우분투 Docker EasyOCR 컨테이너 실행.
- **2차 사용자 OCR**: 1차 실패 시 사용자가 직접 등록한 개인 API Key(OpenAI/Google Vision)로만 2차 처리. (시스템 키 없음, 운영비 0원).
- **오인식 예외 모달**: [날짜, 금액, 가맹점/수신자] 유효성 검사 실패 시 실패 항목을 주황/빨강 테두리로 하이라이트 표시하여 수동 보정 유도.
- **중복 검증**: [날짜 + 금액 + 가맹점] 중복 시 경고 알림 노출.

### 2.3 오프라인 PWA 제어 & 온라인 재연결 무효화(Stale) 정책
- **오프라인 가능 기능**: 현금 수동 입력(IndexedDB 캐싱), 로컬 가계부 조회, 독립 게임 실행.
- **오프라인 차단 기능**: 명세서 OCR 업로드, 카톡 알림톡, **카카오/토스/네이버 딥링크 결제/이체 버튼 (Disabled)**.
- **온라인 재연결 시 무효화(Cancel/Stale)**: 오프라인 캐시 내역이 서버에서 이미 수정/삭제된 경우, 서버 반영을 즉시 취소하고 "네트워크 연결 후 확인 결과 이미 변경/삭제된 내역입니다" 경고 모달 노출.

### 2.4 독립 이벤트 (정산/게임) & Fallback UX
- **개방형 접근**: 그룹 소유자 승인 없이 구성원 누구나 1/N 정산, 사다리타기, 술래잡기 즉시 실행.
- **스마트 인원 자동 세팅**: 모임 실행 시 구성원 전원 자동 선택 (불참자 체크 해제, 게스트 추가, `+ / -` 인원 조절기).
- **바인딩 옵션**: `[실행 후 선택 (기본값)]`, `[자동 연동]`, `[연동 생략]`.
- **게스트 포함 시 Fallback UX**:
  - 게스트('친구A' 등)가 1명이라도 포함되면 자동 연동 제한.
  - 정산 결과 화면에서 미매핑 게스트는 `[게스트 / 매핑 필요]` 태그 표시.
  - **확실히 매핑된 정식 구성원에 대해서만 `[가계부 연동 / 요청]` 버튼 활성화**.

### 2.5 3대 빅테크 간편 송금 딥링크
- 정산/용돈/대여 결과 화면에서 **카카오페이(`kakaopay://`)**, **토스(`supertoss://send?...`)**, **네이버페이(`naverpay://`)** 딥링크 버튼 제공. 3초 만에 이체 화면 연결.

### 2.6 확장 라이프 서비스 (모아3종)
1. **모아당번 (MoaDuty)**
   - 정식 회원 및 **게스트 사용자** 지정 지원.
   - 상태 머신: `ASSIGNED(할당)` -> `ENDED(수행완료/사진등록)` -> `COMPLETED(승인완료)`.
   - **승인 옵션**: `ENDED` 상태만으로도 정당한 이행(해결) 상태로 인정.
   - **승인 필수**: `COMPLETED` 상태에 도달해야 최종 해결 상태로 인정.
2. **모아용돈 (MoaAllowance)**
   - 자녀 요청 -> 부모 딥링크 이체 -> 지급 완료 시 수입/지출 처리.
   - **그룹 가계부 이중 합산 방지**: 가족 전체 가계부에서는 '가족 내부 이동'으로 처리하여 지출 중복 합산 차단.
3. **모아빌림 (MoaLoan)**
   - 차용 금액, 변제 예정일, 상환 방식 트래킹.
   - **회계 분류 원칙**: 소비 지출이 아닌 **`[자산 이동 / 채권·부채]`**로 분류하여 이번 달 생활비 예산 통계 보호.
