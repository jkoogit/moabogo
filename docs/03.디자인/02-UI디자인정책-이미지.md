# 모아보고 (MoaBogo) UI 디자인 정책 및 이미지 참조 가이드 v1.0_261006

## 1. 디자인 시스템 개요 및 시각 도면 매핑 체계

본 문서는 **모아보고(MoaBogo)** 스마트 가계부 및 라이프 서비스의 정규화된 UI/UX 표준 디자인 정책과 실제 제작·게시된 시각적 화면 도면(Visual Wireframes & Showcase Schematics)을 1:1 대조하여 개발자, 디자이너, AI 에이전트가 완벽히 상호 참조할 수 있도록 작성된 종합 지침서이다.

### 1.1 LETO 모티브 디자인 언어 및 핵심 디자인 원칙
모아보고 UI/UX 디자인 시스템은 B2B/SaaS Clean 인터페이스인 **LETO (`app.leto.kr`)** 디자인 언어를 모티브로 채택하여 데이터 중심의 가독성과 시각적 정돈감을 제공한다.

* **절제된 1px 테두리 (Subtle 1px Border)**: 강한 입체 그림자를 배제하고 `1px Subtle Border` (`border-slate-200`)와 깔끔한 라이트 배경 배색(`bg-slate-50`, `bg-white`)을 활용하여 가독성을 최우선으로 확보한다.
* **정보 구획화 (Bento Grid Layout)**: 대시보드 및 복합 화면 배치 시 벤토 그리드(Bento Grid) 타일 레이아웃을 채택하여 사용자의 시선 흐름을 자연스럽게 정돈한다.
* **최소한의 텍스트와 직관적 아이콘**: 불필요한 서술형 설명 단어를 배제하고, 직관적인 라인 아키텍처 아이콘과 시맨틱 뱃지를 조합하여 상태를 즉각 파악하게 한다.

## 2. 필수 레이아웃 & 수직 중앙 정렬 가드레일 (시각화 분석)

### 2.1 수직 100% 중앙 정렬 필수 규칙 (Vertical Center Mandatory)
모든 컴포넌트 내부 텍스트와 아이콘은 높이(Height) 기준 **수직 100% 중앙 정렬**을 오차 없이 준수한다.

* **수직 정렬 고정 (`items-center` / `valign: center`)**:
  * 입력필드, 버튼, Pills 뱃지, 필터 칩, 체크박스, 라디오, 토글 스위치, 탭, 테이블 셀, 수직 트랙 내부의 텍스트와 아이콘은 컨트롤 중앙점(`y_center`)과 텍스트의 x-height 중앙점이 단일 수평 축을 형성하도록 고정한다.
  * 시각 도면 `moabogo-design-system-complete-showcase.png`의 모든 뱃지 및 입력 상자에서 인덱스 라인을 기준으로 상하 여백이 정확히 동등함을 확인할 수 있다.
* **수평 정렬 속성 분리 (Horizontal Alignment Control)**:
  * 수평 정렬(Left, Center, Right)은 속성 옵션(`align: left | center | right`)으로 처리하되, 수직 정렬은 예외 없이 중앙으로 고정한다.

### 2.2 텍스트 줄바꿈 및 스태킹 정책 (Text Wrapping Policy)
화면 크기 변화 시 컴포넌트 변형 및 레이아웃 파손을 방지하기 위한 엄격한 줄바꿈 분리 정책이다.

* **요소 내부 (`whitespace-nowrap`)**:
  * 버튼, 필터 칩, Pills 뱃지, 탭, 테이블 메타데이터 셀 등 개별 컴포넌트 내부의 텍스트는 **요소 내부에서의 줄바꿈을 일절 금지**한다.
  * 공간 초과 시 텍스트가 두 줄로 넘어가며 컨테이너 높이를 변형시키지 않도록 말줄임표(`truncate`) 처리를 원칙으로 한다.
* **요소 간 (`flex-wrap / Grid Stacking`)**:
  * 요소와 요소 사이는 `flex-wrap` 또는 반응형 Grid 시스템(`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`)을 적용한다.
  * 뷰포트 너비 축소 시 개별 요소의 외형을 유지한 채 요소 단위로 자연스럽게 다음 줄로 스태킹(Stacking)되도록 처리한다.

### 3.2 모바일 공간감(Spaciousness) 확장 원칙 및 v2 시안 시각 분석
초기 모바일 시안(`moabogo-mobile-mode-wireframe.png`)의 조밀함과 답답함을 해소하기 위해 **`moabogo-mobile-mode-wireframe-v2.png`**에 반영된 4대 개선 방안의 시각적 구현 스펙이다.

1. **상단 네비게이션의 하단 이관 (Bottom Nav Bar)**:
   * 상단에 복잡하게 누적되던 메인 메뉴(`가계부`, `모아당번`, `정산게임`, `프로필`)를 화면 최하단 고정 네비게이션 바(`Bottom Nav Bar`)로 분리하여 상단 스크린의 시각적 쉼표를 확보했다.
2. **여백(Spacing) 스케일 대폭 확대**:
   * 화면 좌우 가장자리 여백을 `16px`에서 **`24px`**로 확장하고, 카드 내부 패딩을 `16px ~ 20px`, 카드 간 수직 간격을 `16px ~ 20px`로 확대하여 넉넉한 공간감을 연출했다.
3. **프로그레시브 디스클로저 및 바텀시트 (Bottom Sheet)**:
   * 복잡한 트리 수정 폼과 카테고리 편집 UI를 메인 화면에 평면으로 보여주지 않고, `[카테고리 관리 ⬆]` 버튼 클릭 시 아래에서 부드럽게 슬라이드 업되는 바텀시트 모달로 격리했다.
4. **타이포그래피 계층 대조 명확화**:
   * 메인 지출 총액 및 주요 헤더의 폰트 크기 대조(`20px ~ 22px Bold`)를 극대화하고 충분한 행간(`leading-relaxed`)을 적용하여 텍스트 뭉침을 제거했다.

## 4. 원자적 공통 엘리먼트 토큰 (`ELM-*`) 별 시각적 렌더링 명세

시각 도면 **`moabogo-design-system-complete-showcase.png`**에 수록된 14종 원자적 공통 엘리먼트 토큰의 디자인 사양 및 인터랙션 규격이다.

### 4.1 기본 입력 및 디스플레이 토큰

* **`ELM-TYP-01` (메인 타이틀)**:
  * CSS: `text-lg md:text-xl font-semibold text-slate-900 tracking-tight`.
  * 스펙: 화면 헤더 및 섹션 상단에 배치되며 수직 100% 중앙 정렬을 준수한다.
* **`ELM-INP-01` (일반 입력필드)**:
  * CSS: `relative w-full pl-3 pr-8 py-2 text-sm bg-white border border-slate-200 rounded-lg focus:ring-2 focus:ring-indigo-500/20`.
  * 상시 X 버튼: 우측 `absolute right-2.5` 위치에 `✕` Clear 아이콘이 항상 노출되며, 클릭 시 입력값이 즉시 초기화된다.
* **`ELM-INP-04` (검색 입력필드)**:
  * CSS: `ELM-INP-01` 상속 + 좌측 `Search` 백터 아이콘 (`pl-9`) + 우측 상시 X Clear 버튼 결합.
* **`ELM-SEL-01` (선택 목록 드롭다운)**:
  * CSS: `w-full px-3 py-2 text-sm bg-white border border-slate-200 rounded-lg appearance-none` + 우측 `ChevronDown` 아이콘.

### 4.2 선택, 스위치 및 상태 표시 토큰

* **`ELM-FLT-01` (필터 선택 칩)**:
  * CSS: `inline-flex items-center gap-1.5 px-3 py-1.5 text-xs font-medium rounded-full border border-slate-200 bg-white hover:bg-slate-50`.
  * Selected 상태: `bg-indigo-50 border-indigo-300 text-indigo-700 font-semibold`.
* **`ELM-RAD-01` / `ELM-CHK-01` (라디오 & 체크박스)**:
  * CSS: `w-4 h-4 border-slate-300 rounded-full(md) text-indigo-600 focus:ring-2 focus:ring-indigo-500/20`.
  * 엑스박스 방지: OS 기본 컨트롤 대신 SVG 백터 라인으로 렌더링하여 이미지 깨짐을 방지하며, 텍스트 라인과 수직 100% 중앙 정렬된다.
* **`ELM-SWT-01` (토글 스위치)**:
  * CSS: `w-9 h-5 bg-slate-200 peer-checked:bg-indigo-600 rounded-full transition-all`.
* **`ELM-CNT-01` (건수 뱃지)**:
  * CSS: `inline-flex items-center justify-center px-2 py-0.5 text-xs font-semibold rounded-full bg-slate-100 text-slate-600`.
* **`ELM-STT-01` (상태 Pills 뱃지 6종)**:
  * Emerald (`완료/승인`), Amber (`대기/보정`), Rose (`실패/반려`), Purple (`자산이동`), Indigo (`진행중`), Slate (`개인/대기`).

### 4.3 복합 구조 및 인터랙션 토큰

* **`ELM-TRE-01` (목록 데이터 트리 - 뷰/수정 모드)**:
  * **View Mode**: 접기/펼침 계층 구조 (`▼`, `►`), 계층별 인덴트(Indent), 우측 하위 건수 및 합계 금액 수직 중앙 배치.
  * **Edit Mode**: 드래그 핸들러(`≡`) 아이콘, 인라인 수정 입력필드(`ELM-INP-01`), `[저장]`, `[삭제]`, `[+하위추가]` 액션 버튼 세트.
* **`ELM-FAB-01` (우측 하단 펼침기능 맨위로 FAB)**:
  * 위치: 화면 우측 하단 `fixed bottom-6 right-6` 고정.
  * Normal: 클릭 시 화면 최상단으로 이동하는 `Top 🔝` 스크롤.
  * Expanded (Speed Dial): 클릭 시 `✕` 아이콘으로 전환되며, 위쪽으로 `[📷 OCR 스캔]`, `[➕ 빠른지출]`, `[🧹 당번수행]` 메뉴가 펼쳐짐.
* **`ELM-PRF-01/02` (프로필 아바타 그룹)**:
  * `ELM-PRF-01`: 3가지 표준 규격 (`Small 32px`, `Medium 48px`, `Large 64px`) 원형 아바타.
  * `ELM-PRF-02`: 원형 아바타 우측 하단에 오버레이 카메라/수정 뱃지(`Slate-900`, 24px)가 결합되어 모달 호출.
* **`ELM-STP-01` (단계별 진행 상태 스테퍼)**:
  * 수평 프로세스 바: `Step 1. 할당 완료 (✓ Emerald)` ➔ `Step 2. 사진 인증 (⏳ Indigo)` ➔ `Step 3. 최종 승인 (⚪ Slate)`.
* **`ELM-TAB-01` (탭 컨텐츠)**:
  * Bar: 선택된 탭은 `White` 카드 배색 및 `Indigo-600` 하단 인디케이터 바 강조.
  * Panel: 탭 변경 시 하단 컨텐츠 영역 비동기 스위칭.
* **`ELM-SLD-01/02` (슬라이드 휠 드래그 트랙)**:
  * `ELM-SLD-01` (기본형): 좌우 마우스 드래그 및 스크롤 휠 탐색 + 이동 종단 **Magnetic Snap (자석 스냅)**.
  * `ELM-SLD-02` (옵션형): 트랙 좌우에 `◀`, `▶` 이동 버튼이 결합되어 클릭 및 스크롤 이동 동시 지원.

## 5. 오프라인 UI/UX 인디케이터 & 프로그레시브 디스클로저 시각 패턴

### 5.1 프로그레시브 디스클로저 (Progressive Disclosure) & 바텀시트
모바일 뷰포트에서 정보 과부하를 방지하기 위해 2차 상세 편집 입력폼은 바텀시트(Bottom Sheet) 모달로 처리한다.

* **바텀시트 시각 스펙**: `fixed inset-x-0 bottom-0 z-50 bg-white rounded-t-2xl p-6 shadow-2xl max-h-[85vh] overflow-y-auto`.
* **인터랙션**: 배경 디밍(`bg-slate-900/40 backdrop-blur-sm`) 오버레이 및 상단 드래그 핸들 바(`w-12 h-1.5 bg-slate-300 rounded-full mx-auto mb-4`) 배치.

### 5.2 오프라인 UI/UX 인디케이터 (`SYS-OFFLINE`)
네트워크 연결이 불가능한 환경에서도 사용자가 안심하고 오프라인 작업을 수행할 수 있도록 명확한 시각 인디케이터를 제공한다.

1. **상단 스티키 오프라인 상태 바**:
   * 네트워크 단절 감지 즉시 최상단에 `[📡 오프라인 모드: 네트워크 재연결 시 자동 동기화됩니다]` 스티키 뱃지(`bg-amber-500 text-white text-xs py-1.5 text-center font-medium shadow-sm`)가 고정 노출된다.
