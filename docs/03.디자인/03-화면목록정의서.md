# 모아보고 (MoaBogo) 서비스 화면 목록 정의서 v1.0_261006

## 1. 개요 및 화면 체계

본 문서는 `docs/09.참고/261006_화면검토/261006_화면검토.md` 요구사항 및 `docs/03.디자인/02-UI디자인정책-이미지.md` 디자인 정책을 바탕으로 모아보고의 전체 서비스 화면을 기능 영역별로 분류하고 고유 **화면 ID (Screen ID)**를 배정한 화면 목록 정의서이다.

### 1.1 화면 ID 명명 체계
* **형식**: `SCR-[도메인 3자리]-[순번 2자리]`
* **도메인 코드**:
  * `GNT`: 게스트/비로그인 공용 (Guest/Public)
  * `AUT`: 인증 및 세션 (Authentication)
  * `DSH`: 대시보드 및 메인 (Dashboard)
  * `LED`: 가계부 관리 (Ledger)
  * `GOL`: 모아목표 (MoaGoal)
  * `DUT`: 모아당번 (MoaDuty)
  * `MON`: 모아머니 (MoaMoney - 요구머니/요청머니)
  * `QCK`: 빠른 등록 (Quick Entry - 머니/수행)
  * `EVT`: 독립 이벤트 게임 (Event - 정산/사다리/술래잡기)
  * `SET`: 사용자 설정 (User Settings)
  * `SYS`: 시스템 관리 (System Settings)
  * `SMP`: 디자인 시스템 샘플 쇼케이스 (Sample Showcase)

## 3. 화면 간 전이 및 네비게이션 맵

```text
[비로그인 사용자] ──▶ SCR-GNT-01 (게스트 메인 / 무료 게임)
                          │
                  ┌───────┴───────┐
                  ▼               ▼
            SCR-AUT-01       SCR-AUT-02 (로그인 및 오프라인 세션 생성)
             (회원가입)           │
                                  ▼
[로그인 회원] ────────────▶ SCR-DSH-01 (로그인 메인 대시보드)
                                  │
      ┌───────────┬───────────────┼───────────────┬────────────┐
      ▼           ▼               ▼               ▼            ▼
  SCR-LED-01  SCR-GOL-01      SCR-DUT-01      SCR-MON-01   SCR-EVT-01
  (가계부관리) (모아목표)       (모아당번)       (모아머니)    (독립정산게임)
      │           │               │               │
      └───────────┴───────┬───────┴───────────────┘
                          │ (우측 하단 FAB / 단축키)
                          ▼
            SCR-QCK-01 / SCR-QCK-02 (빠른 등록 모달/바텀시트)
                          │
                          ▼
            SCR-SET-01 (사용자설정) / SCR-SYS-01 (시스템설정)
                          │ (오프라인 상태 전환 시)
                          ▼
            SCR-OFF-01 (오프라인 인디케이터 및 Stale 무효화 모달)
```
