## 4. 참고 1.1 디자인 개선사항 검토 및 준수 현황

`docs/03.디자인/02-UI디자인정책-이미지.md`에서 제시된 6대 핵심 품질 가드레일을 본 시스템에 100% 반영하여 검토를 완료하였다.

### 4.1 수직 100% 중앙 정렬 (Vertical 100% Center Mandatory)
* **문제점**: 컨트롤 박스 내부에서 글자가 위쪽이나 아래쪽으로 1~2px 치우쳐 어색해 보이는 시각적 불안정성.
* **개선책**:
  * 모든 버튼, 인풋, Pills 뱃지, 필터 칩, 드롭다운, 체크박스/라디오 컨테이너에 `flex items-center` 및 명시적 행간(`leading-none` 또는 `leading-normal`)을 결합하여, 높이 중앙선과 폰트 x-height 중심선을 정확히 일치시킴.
  * 아이콘과 텍스트 간격 또한 `gap-1.5`로 통일하고 높이 축을 동기화함.

### 4.2 텍스트 줄바꿈 방지 및 요소 간 스태킹 (Text Wrapping Policy)
* **문제점**: 작은 화면에서 버튼이나 뱃지 안의 텍스트가 두 줄로 떨어지면서 컨테이너 높이가 제각각 깨지는 현상.
* **개선책**:
  * **요소 내부**: 버튼, 필터 칩, 뱃지, 카운터에 `whitespace-nowrap`을 필수 적용하고 필요 시 `truncate` 처리.
  * **요소 간**: 부모 컨테이너에 `flex-wrap` 및 반응형 `grid`를 적용하여 요소 외형을 원형 보존한 채 다음 줄로 매끄럽게 떨어지도록 처리.

### 4.3 모든 입력필드 상시 X (Clear) 버튼 탑재
* **개선책**:
  * `ELM-INP-01`과 `ELM-INP-04` 모든 입력필드 우측에 값이 존재할 때 즉시 초기화할 수 있는 원형 `✕` Clear 버튼을 고정 배치하여 모바일/데스크톱 모두에서 빠른 재입력 UX를 제공.

### 4.4 모바일 공간감(Spaciousness) 개선 및 바텀시트 격리
* **개선책**:
  * 모바일 뷰포트에서 상단 헤더 메뉴의 과밀화를 해소하기 위해 최하단 고정 `Bottom Nav Bar`(`ELM-NAV-01`)로 메인 네비게이션을 분리.
  * 좌우 마진을 기존 16px에서 **24px**로 시원하게 확대.
  * 복잡한 수정 폼과 카테고리 트리는 평면 배치 대신 아래에서 올라오는 바텀시트(`ELM-BSH-01`)로 격리하여 쾌적한 공간감 연출.

### 4.5 엄지손가락 터치 타겟 규격 (최소 44px)
* **개선책**:
  * 모바일 모드의 모든 클릭/터치 대상(버튼, 필터 칩, 네비게이션 아이콘, 체크 영역)에 최소 `min-h-[44px]` 또는 `p-3` 이상의 터치 바운딩 박스를 확보.

### 4.6 오프라인 및 동기화 인디케이터 투명성
* **개선책**:
  * 오프라인 전환 시 최상단 고정 노란색 배너(`ELM-OFF-01`)와 로컬 대기열 카드에 `⏳ Sync Pending` 뱃지를 부착하여 네트워크 상태를 사용자에게 명확히 고지.

### 4.7 슬라이드 드래그휠 이벤트 전파 차단 및 가로너비 유연한 줄바꿈 정책 (Zero-Jitter Wheel & Flex-Wrap)
* **문제점**:
  * 수평 슬라이드 트랙 또는 탭/카테고리 필터 영역에서 마우스 휠(`onWheel`)로 가로 스크롤을 시도할 때, `e.stopPropagation()`이 누락되면 이벤트가 상위 브라우저 윈도우로 전파되어 화면 전체가 세로로 덜컹거리거나 가로 스크롤이 정상 작동하지 않는 현상 발생.
  * `flex-nowrap` 강제로 인해 반응형 뷰포트에서 항목들이 한 줄로 찌그러지거나 잘리는 현상 발생.
* **개선책**:
  * **전파 차단 필수 (Mandatory)**: 모든 수평 휠 스크롤 컨테이너의 `onWheel` 핸들러에서 델타값 감지 시 반드시 `e.stopPropagation()`을 선행 호출하여 배경 스크롤 간섭 및 화면 점핑을 100% 원천 차단.
    ```tsx
    onWheel={(e) => {
      if (e.deltaY !== 0) {
        e.stopPropagation();
        e.currentTarget.scrollLeft += e.deltaY;
      }
    }}
    ```
  * **유연한 줄바꿈 (Flex-Wrap)**: 가로 너비가 초과되는 필터 칩, 탭, 액션 버튼 그룹은 `flex flex-wrap items-center gap-1.5`를 적용하여 뷰포트 협소 시 자연스럽게 다음 행으로 줄바꿈되도록 보장.

### 4.8 안내정보 ?(도움말) 아이콘 팝오버 및 카드/목록 뷰 모드 가드레일
* **문제점**:
  * 긴 설명 문구가 메인 화면에 상시 노출되어 가로 공간을 과도하게 점유하고 중요 컨트롤 버튼을 찌그러뜨리는 문제.
* **개선책**:
  * **안내정보 ? 아이콘화**: 상시 텍스트 대신 `HelpCircle` ? 아이콘 버튼을 배치하고, 사용자 클릭 시 팝오버/툴팁으로 상세 안내를 펼쳐 공간 효율 극대화.
  * **카드/목록 뷰 스위칭 (`CARD` / `LIST`)**: 거래 내역 및 데이터 리스트가 가로 폭 부족으로 뭉개지는 것을 방지하기 위해 다열 카드 그리드 뷰(`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`)와 테이블 목록 뷰 모드를 상호 전환할 수 있는 직관적인 스위처 제공.

### 4.9 긴 텍스트 말줄임 항목 롱프레스(Long-Press) 툴팁 및 원클릭 복사 정책 (`ELM-TIP-01`)
* **문제점**:
  * 식당 상호명, 영수증 적요, 상세 비고 등 데이터 길이가 긴 텍스트가 뷰포트 협소 시 `truncate`로 말줄임 처리되면서 핵심 식별 정보가 가려지고 사용자가 전체 텍스트를 확인하거나 복사할 수 없는 한계 발생.
* **개선책 (정책화)**:
  * **500ms 롱프레스 트리거**: 마우스 좌클릭 유지 또는 모바일 터치 길게 누름(500ms) 시 툴팁 레이어가 열리며 생략된 원본 전문을 완전 노출.
  * **원클릭 클립보드 복사 아이콘 제공**: 툴팁 우측에 `Copy` 아이콘 버튼을 상시 배치하여 터치/클릭 즉시 `navigator.clipboard.writeText`로 복사하고 `"클립보드에 복사되었습니다."` 토스트 피드백 제공.
  * **바깥 영역 클릭 시 자동 닫기**: 화면 외부 터치/마우스 이동 시 직관적으로 툴팁을 해제하여 UI 방해 최소화.

### 4.10 금융 계좌번호 및 지정장부 식별자 요소 분리 래핑 규격
* **문제점**:
  * `우리은행 (1002-***-918231)` 등 은행명과 계좌번호가 단일 텍스트 문자열에 고정 너비(`max-w-[140px] truncate`)로 묶여 있어 화면 축소 시 계좌번호 뒷자리가 잘려 식별 불가능해지는 문제.
* **개선책 (정책화)**:
  * **원자 요소 분리**: [라벨 명칭] + [은행명 뱃지] + [계좌번호/장부명 뱃지]를 개별 독립 요소로 분리하고 상위 컨테이너에 `flex flex-wrap items-center gap-1.5`를 적용.
  * **화면 협소 시 줄바꿈 보존**: 텍스트 말단을 강제 절단하지 않고 요소 단위로 다음 행에 자연스럽게 배치되도록 하여 금융 정보의 무손실 식별성 보장.

### 4.11 증빙 썸네일 운용, UI 기술문구 제거 및 원본 다운로드 라이트박스 규격
* **문제점**:
  * 백엔드의 아카이빙 압축(tarball)이나 메모리 파기 주기 등 엔지니어링 기술 내용이 일반 사용자 화면에 장황하게 노출되어 시각적 피로감을 유발하고 핵심 금융 정보 조회를 방해함.
* **개선책 (사용자 중심 정제)**:
  * **기술 문구 화면 배제**: 아카이빙 시뮬레이터 및 내부 압축률 텍스트를 일반 UI에서 완전 제거.
  * **썸네일 캐시 뷰어**: 증빙 이미지는 썸네일 카드로 제공하며, 마우스 호버 시 "전체화면으로 조회" 뱃지 제공.
  * **전체화면 라이트박스 팝업**: 썸네일 클릭 시 고해상도 라이트박스 모달이 펼쳐져 상세 영수증/명세서를 확대 검토 가능.
  * **온디맨드 원본 다운로드 버튼 상시 배치**: 썸네일 헤더 및 라이트박스 상단에 `[원본 다운로드]` 버튼을 배치하여 사용자가 공증 원본 사본을 즉시 로컬 파일로 저장할 수 있도록 일관된 액션 제공.

### 4.12 태블릿(768px~1024px) 툴바 줄바꿈, 컴팩트 상단 여백 및 자산이동 레이블 간소화 규격
* **문제점**:
  * 태블릿 해상도(768px~1024px)에서 상단 속성 바가 강제 1행 고정(`sm:flex-row`)되어 우측 제어 툴바(소유자 권한, 참여자 관리, 커버색상, 마감 토글)가 뭉개지거나 잘리는 현상 발생.
  * 다중 컨테이너 중첩으로 인한 상단 수직 여백 누적(Compounding Margins/Paddings).
  * 퀵필터에 이미 자산이동이 있음에도 체크박스 라벨에 장황한 설명(`(생활비 왜곡 차단)`)이 표기되어 시각적 노이즈 유발.
* **개선책 (정책화)**:
  * **태블릿 유연 줄바꿈(`lg:flex-row`)**: 태블릿 화면 구간에서도 모바일과 동일하게 2행 줄바꿈(`flex-wrap`)을 허용하여 소유자 및 참여자 관리 버튼의 온전한 형태를 보장.
  * **컴팩트 상단 여백**: 최외곽 컨테이너 상단 패딩(`pt-2 sm:pt-3.5`)과 책꽂이 래퍼 상단 여백(`pt-1 pb-2 sm:pt-1 sm:pb-3`)을 경량화하여 과도한 빈 공간 해소.
  * **자산이동 레이블 간소화**: 장황한 부가 설명을 전면 배제하고 직관적인 `자산이동` 단일 레이블로 정돈.

### 4.13 반응형 기능안내 [?] 팝업레이어(ELM-HLP-01), 슬라이드드래그휠 옵션화 및 딥 잉크 블랙 테마 규격
* **문제점**:

  * 다크모드 환경에서 탁한 회색 계열(`#121214`, `#1a1a1e`)이 사용되어 올레드(OLED) 디스플레이 시각적 깊이감 및 프리미엄 심미성 부족.
  * 금융계좌, 카드사, 장부명 등 핵심 데이터 텍스트가 강제 축소 시 글자 중간에서 쪼개지는 현상 발생.
* **개선책 (정책화 및 공통화)**:
  * **반응형 기능안내 [?] 팝업레이어 (`ELM-HLP-01`)**:
    - `HelpCircle` [?] 버튼 클릭 시 모바일 뷰포트 초과 방어 레이아웃(`fixed inset-x-3 top-24 sm:static sm:absolute sm:inset-auto sm:top-full sm:mt-1.5 z-50 w-auto sm:w-84 max-w-[calc(100vw-1.5rem)]`) 일괄 적용.
    - 모바일 전용 배경 백드롭 레이어 및 바깥 영역 클릭/Esc 키 누름 시 자동 닫기 핸들러 내장.
    - 옵션형 텍스트 레이블(`buttonText`) 및 헤더 아이콘(`headerIcon`) 지원으로 간결성과 설명력 동시 확보.
  * **슬라이드드래그휠 (`ELM-SLD-03`) 좌우 버튼 옵션화**:
    - `showNavButtons?: boolean` (기본값 `true`) 옵션을 통해 좁은 공간이나 탭 영역에서 버튼 노출 여부를 자유롭게 제어.
    - DOM 레벨 `passive: false` 리스너 바인딩으로 휠 이벤트 발생 시 상위 윈도우 스크롤 체이닝(`e.stopPropagation()`, `e.preventDefault()`) 100% 원천 차단.
  * **프리미엄 딥 잉크 블랙 (Deep Obsidian / Midnight Black) 테마**:
    - 메인 캔버스: 탁한 그레이 대신 깊이감 있는 딥 옵시디언 블랙(`html.dark body`: `#090a0f`).
    - 카드 타일 서피스: 딥 잉크 블랙(`html.dark .bg-white, .bg-slate-100`: `#111318`).
    - 컨트롤 및 활성 요소: 정제된 다크 옵시디언(`html.dark .bg-slate-200`: `#1c1e26`).
    - 1px 미세 테두리: 슬림한 딥 잉크 테두리(`html.dark .border-slate-200`: `#1e2029`).
  * **텍스트 원자 요소화 (Atomization)**:
    - [라벨] + [은행명] + [계좌번호/장부명]을 독립 원자 뱃지로 분리하고 상위 컨테이너에 `flex flex-wrap items-center gap-1.5` 및 `break-keep`, `whitespace-nowrap`을 적용하여 텍스트 쪼개짐 원천 차단.
