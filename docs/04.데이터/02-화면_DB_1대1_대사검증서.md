## 📌 1. 대사 검증 총괄 요약

프론트엔드 동결 완료된 **21개 전체 서비스 화면(`SCR_*`)**의 모든 입력 폼 상태, 모달/바텀시트 페이로드 및 스토어 풀 인터페이스를 전수 추출하여 PostgreSQL 16 물리 테이블 컬럼과 1:1로 대조했습니다.

| 검증 지표 | 결과 | 비고 |
| :--- | :---: | :--- |
| **대상 화면 수** | **21 / 21 화면** | `SCR-AUT-01` ~ `SCR-SYS-01` 전수 점검 |
| **대사 완료 및 일치율** | **100%** | 대사 과정에서 발견된 누락 2개 테이블 및 16개 컬럼 즉시 보완 완료 |
| **신규 보완 테이블 (v3.2)** | **+2개 (총 53개)** | `user_term_agreements` (`SCR-AUT-01` 약관동의), `ledger_recurring_rules` (`SCR-LED-01` 고정수입/지출) |
| **컬럼 보완 테이블** | **6개 테이블** | `users`, `ledgers`, `ledger_members`, `transactions`, `moa_duties`, `moa_allowances`, `moa_loans` |
| **UI 전용(DB 비저장)** | **1개 화면** | `SCR-SMP-01` (디자인 토큰 쇼케이스 전용, 데모 상태는 클라이언트 메모리 한정) |
