## 3. 핵심 문제 해결 및 기술 검증 (Troubleshooting)

### 3.1 사다리 기둥 내 드롭다운 CSS 부모 컨테이너 Trapping 및 레이어 팝업 전환
- **문제점**: 사다리 기둥(84px) 내부에서 인라인 드롭다운을 펼쳤을 때, 부모 컨테이너의 `transform` 및 `overflow: hidden` 제약으로 인해 드롭다운 목록이 잘리고, 기둥 아래의 [사다리 타기] 버튼에 가려져 선택이 불가능한 인터랙션 트랩이 발생함.
- **원인 분석**: 좁은 기둥 컴포넌트 내부에서 상대/절대 위치(`absolute`)로 목록을 띄우는 방식은 다단 중첩 레이아웃에서 뷰포트 바운더리를 벗어날 수 없음.
- **해결책**:
  1. 기둥 내부는 순수 트리거 버튼으로 전환.
  2. 사다리 목표 클릭 시 최상위 React Portal/루트 레이어 팝업(`fixed inset-0 z-50`) 오픈.
  3. 모바일에서는 하단에 밀착하는 가로 100% 바텀시트, 태블릿/PC에서는 중앙 모달(`sm:max-w-md`)로 렌더링.
  4. 최상단에 16종 아이콘 피커, 첫 항목에 타이핑 가능한 입력창, 아래에 추천 프리셋 목록을 일체형으로 배치하여 가림 현상을 완전히 해소.

### 3.2 세션 14 결과물 누락 원인 규명 및 토큰 쇼케이스(`SMP-01`) 복원
- **문제점**: 직전 세션 14 마감 과정에서 토큰 소진 긴급 조치로 원격 형상 동기화가 일부 누락되어, 세션 15 진입 시 `SCR_SMP_01`이 이전 구형 버전으로 남아있었음.
- **원인 분석**: `AGENTS.md`의 비상 푸시 및 태스크 승급 절차에서 실제 Git CLI 실행과 원격 브랜치 패스트포워드 푸시 명령이 명확하지 않아 로컬/원격 상태 간 괴리가 발생함.
- **해결책**:
  1. 세션 14에서 작성되었던 메타데이터 구조(`ui-tokens-metadata.json`)를 완벽히 연동하여 `SCR_SMP_01`을 재구축.
  2. 신규 `ELM-CMB-01` 콤보박스 사양까지 함께 등록.
  3. `AGENTS.md`의 Git 자동화 지침을 대폭 보강하여 향후 동일 누락을 원천 차단.
