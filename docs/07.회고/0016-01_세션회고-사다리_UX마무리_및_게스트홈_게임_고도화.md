### 주요 추진 목표
1. **매장 헤더 및 버튼 레이아웃 직관화**:
   - 매장 닫기(X) 버튼을 메뉴판 버튼 바로 뒤로 재배치하여 동선 최적화.
   - `[게임공유]`, `[?]` 안내 버튼을 헤더 우측 끝(`ml-auto`)으로 배치하여 안정적 시각 밸런스 확보.
   - 메뉴판 모달 상단 네이버 주문 링크에서 텍스트를 제거하고 `ExternalLink` 아이콘만 단독 노출하여 깔끔한 모바일 UX 제공.
   - 매장명 뒤의 "▾ 변경" 텍스트를 제거하고 더 크고 시인성이 높은 `ChevronDown` 화살표 아이콘으로 교체.
2. **매장 메뉴 실물 이미지 데이터셋 매핑 및 사다리 아바타 연동**:
   - `StoreMenuItem` 타입에 `imageUrl?: string` 추가 및 주요 브랜드(진진만두국, 샐러디, 싸다김밥, PLUS CAFE) 대표 메뉴에 실제 음식/음료 사진 매핑.
   - 메뉴판 모달 리스트 항목 좌측에 썸네일 이미지(`w-12 h-12`) 및 폴백 이모지 표출.
   - 참가자가 메뉴를 고르면 사다리 상단 원형 아바타에 선택한 메뉴의 실물 사진과 미니 아바타 이모지 뱃지 복합 렌더링.
3. **공통 슬라이더 휠 스크롤 (`ElmSld03`) 브라우저 화면 상하 연동**:
   - PC 와이드 뷰와 같이 전체 카드가 한 화면에 다 들어와 수평 스크롤이 불필요한 경우나 좌우 끝 지점에 도달했을 때 마우스 휠을 굴리면 상하 브라우저 기본 스크롤이 자연스럽게 작동하도록 이벤트 개선.
4. **가중치 기능 고도화 (음수 지원 & 1:1 초기화)**:
   - `-5 ~ +10` 음수 가중치 허용 및 최소값 기반 오프셋 정규화 확률 공식 적용으로, 특정인의 가중치를 낮추면 타인의 당첨 확률(%)이 자동 상승하는 직관적 게임 밸런스 달성.
   - "가중치 비율" 옆에 회전 화살표(`RotateCcw`) 초기화 아이콘을 배치하여 원클릭 1:1 리셋 지원.
5. **결과 복사 영역 반응형 줄바꿈 정돈**:
   - 좁은 뷰포트에서 `결과 복사:` 타이틀 바로 뒤에서 줄바꿈이 일어나고, 복사 버튼군(텍스트/카드/다운로드)은 분리되지 않고 한 줄로 나열되도록 레이아웃 정돈.

## 3. 핵심 문제 해결 및 기술 검증 (Troubleshooting)

### 3.1 음수 가중치 수학 모델 (Offset Normalization)
- **문제점**: 사용자가 특정 참가자에게 벌칙성 음수 가중치(예: -1, -2)를 부여할 때, 단순 합산 공식($\frac{w_i}{\sum w}$)을 사용하면 분모가 0 또는 음수가 되어 확률 계산이 파탄 나는 문제가 발생함.
- **해결책**:
  1. 전체 참가자의 가중치 중 최소값($\min(w)$)을 탐색.
  2. 최소값이 0 이하일 경우 모든 참가자 가중치에 $(1 - \min(w))$의 기저 오프셋을 더해 유효 가중치($w'_{i} = w_i + \text{offset}$)를 양수 영역으로 정규화.
  3. $P_i = \frac{w'_i}{\sum w'}$ 공식을 적용함으로써 한 명의 가중치를 깎으면 타인의 당첨 확률 비율(%)이 안전하고 자연스럽게 상승하는 수학적 무결성을 확립함.

### 3.2 슬라이더 휠 스크롤 화면 체이닝 간섭 해소
- **문제점**: 화면에 모든 슬라이더 카드가 이미 다 노출되어 수평 스크롤이 불필요한 데도 `e.preventDefault()`가 호출되어 마우스 휠을 굴려도 페이지 전체 스크롤이 먹통이 되는 현상 발생.
- **해결책**: `canScrollHorizontally` 플래그를 사전에 계산하여 수평 스크롤 가능 여부를 확인하고, 불필요하거나 끝단에 도달했을 때에는 `preventDefault`를 생략하여 브라우저의 기본 상하 스크롤 체이닝이 끊김 없이 매끄럽게 동작하도록 개선함.
