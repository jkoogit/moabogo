## 1. 세션 개요 및 핵심 마일스톤

본 세션 0017은 모아보고(MoaBogo) 비로그인 게스트홈(`SCR-GNT-01`) 내 **즐겨보고(정산·사다리·룰렛) 3대 유틸리티의 UI/UX 완성도 극대화**와 **신규 공통 토스트 토큰(`ElmToast01`) 신설**, **초기값 및 인원수 제약 표준화(0원, 6인/6개, 2~20인)**를 완결하기 위해 진행되었습니다.

### 주요 추진 목표
1. **정산 탭 가중치 버튼 재배치 및 인원수 레이아웃 최적화**:
   - 가중치 토글 버튼이 금액 입력 영역에 위치하여 맥락상 어색했던 문제를 해결하고, '인원수' 타이틀 바로 우측으로 재배치하여 참가자별 가중치 조절이라는 본래 의도에 부합하도록 동선 최적화.
   - 인원수 라벨 문구를 `"정산인원수(인원제한 없음)"`에서 직관적인 `"인원수"`로 간결화.
   - 2~20명 제한을 엄격히 유지하고, 경계값(2명, 20명) 도달 시 -, + 버튼의 비활성화(`disabled`) 시각 피드백 명확화.
2. **정산·사다리·룰렛 초기값 및 명칭 표준화**:
   - 금액 초기값: `0원` 표준화 (불필요한 임의 기본 금액 배제).
   - 기본 인원 및 항목 수: `6인 / 6개` 표준화 (참가자1~6, 항목1~6).
   - 인원/항목 수 제약 통일: 최소 2명/개 ~ 최대 20명/개.
   - 룰렛 탭 텍스트 정리: `"참여 인원"`을 `"설정 항목"`으로 변경하고, 불필요한 `"(드래그하여 순서 변경)"` 안내 문구 삭제.
3. **룰렛 항목 인디케이터 및 슬라이더 컨트롤 분리**:
   - 사다리 인원수 컨트롤과 동일한 디자인 토큰인 `ElmRng01` 슬라이더를 적용.
   - 항목 수 슬라이더 컨트롤과 프리셋 선택기 영역을 상하 분리 행(`flex-col sm:flex-row`)으로 고정하여 좁은 모바일 화면에서도 텍스트나 버튼이 겹치지 않는 안정적 레이아웃 구축.
4. **신규 공통 토스트 토큰 `ElmToast01` 신설 및 결과 복사 UX 개선**:
   - 결과 텍스트/카드 복사 시 인라인 텍스트 메시지가 버튼 옆에 렌더링되면서 줄바꿈이 발생하고 높이가 흔들리는 현상 근본 차단.
   - 모아보고 디자인 시스템 기반의 플로팅 토스트 컴포넌트 `ElmToast01` 신설 (`src/components/common/ElmToast01.tsx`).
   - 공유 영역의 복사 버튼은 단독 아이콘(`Copy`)을 유지하고, 복사 시 하단 플로팅 토스트로 즉각 안내 후 2.2초 뒤 자동 페이드아웃되도록 UX 개선.

## 3. 핵심 문제 해결 및 기술 검증 (Troubleshooting)

### 3.1 인라인 복사 안내 메시지로 인한 모바일 레이아웃 밀림 해소
- **문제점**: 결과 복사 버튼 클릭 시 버튼 옆에 인라인으로 `"복사되었습니다!"` 텍스트를 노출할 경우, 모바일 기기나 좁은 뷰포트에서 가로 폭이 부족하여 줄바꿈이 발생하고 카드 전체의 높이가 덜컹거리는 시각적 불안정성이 존재함.
- **해결책**:
  - 버튼군에는 깔끔한 단독 `Copy` 아이콘 버튼만 유지.
  - 전역 디자인 시스템과 조화를 이루는 플로팅 토스트 `ElmToast01`을 신설하여 화면 하단 중앙에 부드럽게 띄우고 자동으로 닫히도록 개선하여 뷰포트 크기와 무관하게 100% 안정적인 레이아웃 보장.

### 3.2 룰렛 인디케이터 및 프리셋 버튼 겹침 방지
- **문제점**: 룰렛 항목 수 조정 슬라이더와 상용 프리셋 버튼(점심메뉴, 사다리벌칙 등)이 한 행에 인라인으로 배치되어 있어 모바일 화면에서 줄바꿈이 불규칙하게 일어남.
- **해결책**: 상단은 항목 수 슬라이더(`ElmRng01`)와 현재 개수 뱃지, 하단은 프리셋 선택 뱃지 그룹으로 영역을 명확히 상하 분리(`flex flex-col gap-2.5`)하여 시각적 인지성과 조작 편의성을 극대화함.
