## 1. 세션 개요 및 핵심 마일스톤

본 세션 0018은 모아보고(MoaBogo)의 **화면 레이어 상단 고정 바 최적화, 뷰포트 전환 모드 팝업화, 화면 타이틀 디자인 표준화(`SCR-DSH-01`, `SCR-LED-01`)**, 그리고 게스트홈 즐겨보고(사다리·룰렛) 및 공통 UI 토큰(`ELM-TRE-01`, `ELM-TOA-01`)의 **완성도 및 조작성 고도화**를 완결하기 위해 진행되었습니다.

### 주요 추진 목표
1. **화면 레이어 상단고정 및 뷰포트 전환 모드 팝업화 (`src/App.tsx`)**:
   - 기존 상단 고정 헤더에 나열되어 있던 뷰포트 전환 버튼들을 단일 뷰포트 아이콘 버튼(`ElmBtn01`)과 안내 모달 팝업으로 집약.
   - 해상도 모드(모바일 390px, 태블릿 768px, 데스크톱 1280px, 전체화면 100%)와 해상도 안내 문구를 모달에서 직관적으로 선택할 수 있도록 설계하여 상단 여백을 극대화.
2. **로그인 / 회원가입 화면 레이아웃 및 텍스트 간결화 (`SCR-AUT-01`, `SCR-AUT-02`)**:
   - 상단 중복 헤더 영역을 완전히 제거하여 페이지 진입 시 깔끔한 폼 포커스 보장.
   - 버튼 텍스트를 직관적인 `"로그인"`, `"회원가입"`으로 간결화.
   - 메인 버튼 좌측에 홈으로 즉시 복귀할 수 있는 `"홈"` 바로가기 버튼(`onGoHome`)을 배치하여 탐색 편의성 제고.
3. **가상 매장 실물 이미지 매핑 및 사다리/캔버스 결과 카드 개선 (`systemStorePool.ts`, `SCR_GNT_01`, `gameResultCardCanvas.ts`)**:
   - `sys_store_pluscafe_45f` 34개 전 제품에 스타벅스 공식 SKU 고해상도 실물 이미지 URL(`imageUrl`)을 전수 매핑.
   - 사다리 참가자 아바타 및 메뉴 선택 모달에 실물 이미지를 둥근 썸네일(`referrerPolicy="no-referrer"`)로 렌더링.
   - 사다리 결과 카드 복사 시 선택한 메뉴의 카테고리 대표 아이콘(☕, 🧊, 🍵, 🥛, 🥐 등)과 실물 썸네일이 누락 없이 캔버스에 렌더링되도록 엔진 고도화.
4. **룰렛 회전 중 '즉시 결과' 스냅 버튼 및 플로팅 토스트 피드백 연동**:
   - 룰렛이 회전 중(`isSpinning`)일 때도 `즉시 결과` 버튼을 클릭하여 대기 없이 즉각(0ms 스냅) 최종 결과를 확정하고 모달을 띄울 수 있도록 인터랙션 보완.
   - 사다리 및 목표 재배치 실행 시 화면에 플로팅 토스트(`ElmToast01`)를 띄워 직관적인 상태 피드백 제공.
   - `ELM-TOA-01`을 공통 컴포넌트 쇼케이스(`SCR-SMP-01`)에 공식 표준 토큰으로 등록 및 라이브 데모 제공.
5. **트리 목록 데이터 편집모드 드래그 위치 플래그 표시 (`Tokens.tsx - ElmTre01`)**:
   - 트리 항목의 드래그 핸들(`☰`)을 이용한 이동 시, 상위/하위 노드 및 다른 브랜치로 이동하는 과정에서 실시간 삽입 대상 위치 플래그(`▲ 위 삽입`, `↳ 자식 편입`, `▼ 아래 삽입`, `🚫 이동 불가`)를 시각적으로 명확히 표시.
   - `SCR-SMP-01` 쇼케이스와 연동하여 트리 노드 이동 시 토스트 알림을 즉각 발행.
6. **화면 타이틀 및 뱃지 표준화 (`SCR-DSH-01`, `SCR-LED-01`)**:
   - 메인 대시보드 및 그룹가계부 상세 화면의 Section 1 헤더에 화면 식별자 뱃지(`SCR-DSH-01`, `SCR-LED-01`) 및 타이포그래피 토큰(`<ElmTyp01>`)을 일관되게 적용.

## 3. 핵심 문제 해결 및 기술 검증 (Troubleshooting)

### 3.1 뷰포트 제어 컨트롤의 모바일/상단 바 공간 점유 해소
- **문제점**: 뷰포트 전환 모드 버튼들이 상단 고정 네비게이션에 여러 개 노출되어 모바일이나 작은 화면에서 다른 헤더 컨트롤(가계부 선택, 알림, 테마 등)과 충돌하거나 시각적 복잡도를 높임.
- **해결책**:
  - 단일 뷰포트 모드 버튼(`ElmBtn01`)만 상단 우측에 유지.
  - 클릭 시 모바일/태블릿/데스크톱/풀스크린 4대 규격과 상세 해상도를 깔끔하게 안내하는 모달 팝업 레이어로 격리하여 상단 영역의 여백과 시각적 안정성을 확보함.

### 3.2 룰렛 회전 중 즉각 결과 확정(Skip Animation) 지원
- **문제점**: 룰렛 애니메이션이 길어질 때 사용자가 빠르게 결과를 확인하고 싶어도 회전이 완료될 때까지 기다려야 하는 불편이 존재함.
- **해결책**:
  - 회전 중(`isSpinning === true`) 상태에서도 `즉시 결과` 버튼을 활성화 상태로 유지하고 앰버 펄스 애니메이션으로 강조.
  - 클릭 시 `requestAnimationFrame` 루프를 즉시 취소하고 목표 각도로 0ms 스냅하여 딜레이 없이 당첨자 모달과 결과 카드를 즉시 렌더링하도록 개선.

### 3.3 트리 데이터 편집모드 드래그 삽입 위치 실시간 가이드
- **문제점**: 트리 구조에서 드래그하여 순서를 바꿀 때, 현재 마우스 위치가 같은 레벨의 위/아래인지, 아니면 대상 노드의 자식으로 들어가는지 직관적으로 인지하기 어려움.
- **해결책**:
  - 대상 노드의 상단 25%, 중간 50%, 하단 25% Y축 감지 로직을 구축.
  - 마우스 포인터 옆에 `▲ 위 삽입`, `↳ 자식 편입`, `▼ 아래 삽입` 플래그 뱃지를 실시간으로 노출하여 오작동 없는 안전한 계층 구조 편집 경험을 달성함.
