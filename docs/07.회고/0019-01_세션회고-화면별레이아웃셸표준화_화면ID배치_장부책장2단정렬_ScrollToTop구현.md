## 1. 세션 개요 및 핵심 마일스톤

본 세션 0019는 모아보고(MoaBogo)의 **화면별 레이아웃 셸 및 헤더 디자인 표준화, 화면 식별자 뱃지 타이틀 후면 배치, 대시보드 위젯 접기/펼치기 아코디언 토글 추가, 장부 책장 2단 정렬 개편, 모바일 빠른등록 독 축소, 전역 Scroll-to-Top 플로팅 위젯 구현, 그리고 신규 장부 생성 모달 테마 지원**을 완결하기 위해 진행되었습니다.

### 주요 추진 목표
1. **전체 13개 화면 식별자 뱃지 타이틀 후면 배치 표준화**:
   - 모아보고 주요 13개 화면(`SCR-DSH-01`, `SCR-LED-01`, `SCR-TRN-01`, `SCR-SET-01`, `SCR-MEM-01`, `SCR-CAL-01`, `SCR-REP-01`, `SCR-DUT-01`, `SCR-NOT-01`, `SCR-AST-01`, `SCR-STK-01`, `SCR-GNT-01`, `SCR-SMP-01`)의 Section 1 헤더 타이틀 바로 뒤에 은은한 모노톤 뱃지(`text-[10px] font-mono px-1.5 py-0.5 rounded border opacity-75`)로 일관되게 배치.
   - 추후 설정이나 릴리즈 단계에서 단일 플래그로 일괄 숨김/표시 전환이 가능하도록 구조화.
2. **대시보드(`SCR-DSH-01`) Section 1 정돈 및 5대 위젯 접기/펼치기 구현**:
   - 2행에 중복 배치되어 공간을 차지하던 조작 버튼 3종(가계부 선택, 뷰포트 전환, 위젯 초기화)을 완전 제거하여 상단 공간 확보.
   - 대시보드 5개 핵심 위젯(오늘의 한마디, 개인 재정 현황, 그룹 모임 장부, 정산·할일 브리핑, 금융 캘린더)에 `isCollapsed` 아코디언 토글을 장부 책장과 동일한 인터랙션 패턴으로 적용.
3. **전체 화면 상단 내부 여백 통일 (`pt-2 sm:pt-3.5`)**:
   - 화면마다 `pt-1`, `pt-4`, `pt-6` 등으로 상이했던 최상단 여백을 모바일 `pt-2`, 태블릿/데스크톱 `sm:pt-3.5`로 완전 통일하여 화면 전환 시 시각적 울렁거림 및 점핑 현상 해소.
4. **장부 화면(`SCR-LED-01`) 책장 영역 2단 정렬 체계 확립**:
   - 1행: 책장 타이틀, 화면 뱃지(`SCR-LED-01`), 4개 컨트롤 버튼(책장 열기/닫기, 책장 펼치기/접기, 슬라이드 모드, 장부 추가).
   - 2행: 책장 필터 슬라이더(`ElmSld03`)를 전폭 독립 배치하여 모바일 및 태블릿 환경에서의 줄바꿈 찌그러짐 원천 차단.
5. **빠른등록 독(`ElmQck01`) 번개 버튼 슬림화**:
   - 화면 하단을 가리던 번개 액션 버튼 크기를 기존 대형 규격에서 `w-9 h-9`(아이콘 `w-4 h-4`), 상단 드래그 핸들을 `w-8 h-4`로 축소하여 모바일 콘텐츠 가독성과 조작성 향상.
6. **전역 Scroll-to-Top 플로팅 위젯 구현 (`src/App.tsx`)**:
   - 화면 스크롤 240px 이상 감지 시 부드러운 페이드인으로 노출되는 전역 플로팅 버튼 배치.
   - 1클릭 시 최상단(`top: 0, behavior: 'smooth'`) 즉시 스크롤.
   - 서브 액션 레이어를 통해 최하단 점프 기능 제공 및 Light/Dark/Dawn 테마 완벽 연동.
7. **신규 장부 생성 모달(`NewLedgerModal.tsx`) 테마 및 용어 표준화**:
   - 라이트, 다크, 던(Dawn) 3색 테마 토큰을 모달 전체 배경, 입력창, 선택 카드, 버튼에 전면 반영.
   - 구 용어 "가계부"를 서비스 표준 용어인 "장부"로 전면 정비.

## 3. 핵심 문제 해결 및 기술 검증 (Troubleshooting)

### 3.1 13개 화면 타이틀과 식별자 뱃지 배치 일관성 확립
- **문제점**: 화면마다 식별자 뱃지의 위치(제목 앞, 제목 위, 별도 행)와 스타일이 제각각이어서 디자인 통일성을 해치고, 화면 타이틀의 가독성을 저해함.
- **해결책**:
  - 모든 화면의 최상단 Section 1 헤더에서 화면 타이틀 바로 뒤 인라인 플렉스(`inline-flex items-center gap-2`)로 배치.
  - 은은한 모노스페이스 뱃지 스타일(`text-[10px] font-mono px-1.5 py-0.5 rounded border opacity-75`)을 통일 적용하여 시각적 방해를 최소화하면서도 개발/QA 시 직관적 식별을 보장함.

### 3.2 장부 화면 책장 컨트롤과 슬라이더의 좁은 화면 충돌 해결
- **문제점**: 책장 조작 버튼 4종과 장부 필터 슬라이더(`ElmSld03`)가 단일 행에 공존하면서 모바일/태블릿 폭에서 버튼이 밀려나거나 슬라이더 폭이 비정상적으로 축소되는 현상 발생.
- **해결책**:
  - 책장 영역을 2단 구조로 분리하여 1행에는 타이틀과 책장 조작 버튼을, 2행에는 독립된 전폭 슬라이더를 배치.
  - 슬라이더의 핸들과 트랙 폭이 충분히 확보되어 터치 및 드래그 조작성이 대폭 개선됨.

### 3.3 전역 Scroll-to-Top 인터랙션 및 모바일 가림 방지
- **문제점**: 모바일 긴 화면 탐색 시 상단 복귀가 번거로우며, 기존 빠른등록 독(`ElmQck01`)과 플로팅 버튼이 겹칠 우려가 있음.
- **해결책**:
  - 스크롤 240px 이상 이동 시에만 나타나도록 스크롤 이벤트 리스너를 등록하고 `requestAnimationFrame` 디바운스를 적용.
  - 빠른등록 독과 겹치지 않도록 우측 하단 여백(`bottom-20 sm:bottom-6 right-4 sm:right-6`)을 계산하여 최적 배치.
