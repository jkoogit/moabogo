## 1. 세션 개요 및 핵심 마일스톤

본 세션 0027은 모아보고(MoaBogo)의 **금전거래 대상 관리 및 가계부 용돈구성원 대표입금계좌 1:1 매핑 체계(BKL-ACC-10)**를 완성하고, 사용자 피드백에 입각한 **Zero-Friction 계좌 원칙**, **응원/송금 시 계좌 유무 분기(숨김 vs 비활성화)**, **송금 팝업 예외 처리(수신계좌 직접 입력 및 이체없이 종료)**를 유기적으로 완결하기 위해 진행되었습니다.

### 주요 추진 목표 및 달성 내역

1. **[Zero-Friction 계좌 원칙 확립]**:
   - 모아보고는 단순 금융 송금 앱이 아닌 라이프스타일/생활 가계부이므로, 계좌 등록 없이도 가계부, 목표, 당번, 1/N 정산, 게임을 100% 정상 이용할 수 있도록 보장.
   - 계좌 등록은 선택 사항으로 두어 사용자 진입 장벽을 원천 제거.

2. **[응원/송금 시 계좌 유무 분기 규약]**:
   - **받는사람(수신자) 계좌 부재 시**: 실천 이력에서 `[응원 송금 💰]` 버튼을 완전히 없앰(미노출).
   - **주는사람(송금자) 계좌 부재 시**: 버튼은 노출하되 비활성화(`disabled`, opacity-70) 처리하고 계좌 등록 필요 툴팁 안내.

3. **[송금 팝업 내 수신계좌 직접 입력 및 듀얼 종료 액션]**:
   - **수신 계좌 미등록 시**: 송금 모달([SCR_GOL_02](file:///d:/dev/workspace/git.jkoogit/moabogo/src/sample/screen/SCR_GOL_02_모아목표상세.tsx), [SCR_DSH_01](file:///d:/dev/workspace/git.jkoogit/moabogo/src/sample/screen/SCR_DSH_01_로그인메인대시보드.tsx)) 내에서 은행/계좌번호/예금주를 인라인으로 직접 입력할 수 있는 폼 제공.
   - **이체없이 종료처리 (현금전달 등)**: 실제 은행 이체 없이 직접 현금 지급 후 이체 완료 상태(`COMPLETED`/`APPROVED`)로 마감하고 활동 피드/댓글에 현금 전달 이력을 기록하는 `[이체없이 종료 (현금전달) 💵]` 버튼 신설.

4. **[설정 화면 내 다중 계좌 관리 (SCR-SET-01)]**:
   - 사용자 설정 Tab 4(`ACCOUNT`)에 복수 계좌 등록/수정/삭제, 대표계좌 지정, 마스킹 계좌번호 복사, 목적 태그 부여 기능 완결.

5. **[가계부 참여자 설정 모달 내 1:1 대표계좌 매핑 (SCR-LED-01)]**:
   - 참여자별 용돈 수령 대상 토글, 지급 방식(계좌 송금 vs 현금 직접 지급) 선택, 1:1 대표계좌 매핑 인라인 패널 연동.
