## 1. 세션 개요 및 핵심 마일스톤

본 세션 0029는 모아보고(MoaBogo)의 **모아당번 서비스 전면 개편**과 **게스트홈 사다리 게임의 핵심 사용성 개선**을 완결하기 위해 진행되었습니다. 모아목표(SCR-GOL-01/02)의 성공적인 화면 분리 패턴을 계승하여 단일 당번 화면을 **관리(`SCR-DUT-01`)**와 **상세(`SCR-DUT-02`)** 2대 축으로 명확히 구조적 분리하였으며, 사용자 18대 피드백을 전수 반영하여 직관적이고 표준화된 LETO 토큰 기반 UI를 구축하였습니다. 또한 비로그인 게스트홈의 사다리 게임에서 누락되었던 **참가자 이름 현장 수정 기능**을 복원하고, 선택 시 발생하던 **높이 단차(Stagger)를 0%로 완벽 해결**하였습니다.

### 주요 추진 목표 및 달성 내역

1. **[모아당번 관리(SCR-DUT-01) vs 상세(SCR-DUT-02) 구조 분리]**:
   - **`SCR-DUT-01` (모아당번 관리)**:
     - 중복적인 상단 KPI 벤토 서머리를 삭제하고 검색 필터 탭에 상태별 건수를 직관적으로 통합.
     - 카테고리 분류 트리를 기본 접힘(`isCollapsed = true`) 상태로 배치하고 접기/펴기 토글 지원.
     - 주기 및 배정 방식을 친근한 한글(`매주 화·목·토 (주 3회)`, `연령 가중 순환 배정`)로 전면 개편.
     - 새 당번 등록 팝업 헤더 고정(`sticky top-0`) 및 완수 기준/주의사항 마크다운 탭 지원.
   - **`SCR-DUT-02` (모아당번 상세)**:
     - 난해한 개발자 용어 '피어 승인'을 **'당번 완료 승인 투표'**로 전면 전환.
     - 대신수행 지정요청 시 복수 멤버 선택 체크박스 카드 지원.
     - 정산 주기 기준 신설(`일간정산`, `주간정산`, `월간정산`) 및 상계정산 테이블 연동.
     - 실시간 통계 탭 주차별 그래프 클릭 시 기여도 랭킹 뷰와 양방향 인터랙티브 연동.
     - 실적·인증 이력 2열 마스터-디테일 레이아웃 구축.
     - 당번 운영 안내 문구를 플로팅 도움말 팝업(`ElmHlp01`)으로 통일하고 슬라이드드래그휠(`ElmSld03`) 직결.

2. **[SCR-GNT-01 사다리 게임 참가자 이름 수정 및 단차 없는 단일선택]**:
   - **아이콘 상단 인풋 필드 배치**:
     - 각 참가자 컬럼 상단에 독립 `<input>`을 배치하여 현장에서 원클릭 전체선택(`select()`)으로 참가자 이름 즉시 수정 복원.
     - 게임 진행 중(`isTracing`) 자동 비활성화로 데이터 왜곡 방지.
   - **높이 단차(Stagger) 0% 해결**:
     - 컬럼 길이를 변화시키던 하단 텍스트 라벨을 전면 제거하고 아바타 우상단에 `absolute -top-1.5 -right-1.5` 플로팅 체크마크 배지(`Check`) 적용.
   - **단일 선택(Single-Seat) 배타적 점유**:
     - 여러 개 중복 선택을 차단하고, 새 자리 선택 시 기존 점유를 자동 해제하여 마지막 선택한 1개 아이콘만 '내 자리'로 보장.

3. **[무서버 실시간 동기화 기술 검증 및 백로그 이연]**:
   - 브라우저 표준 `BroadcastChannel API`와 로컬스토리지 `storage-event`를 결합한 0ms 무서버 실시간 동기화 프로토콜 프로토타입 검증 완료.
   - 사용자 지침에 따라 실제 실시간 다자간 방 공유 및 크로스 디바이스 연동은 차기 세션(`0030`, `BKL-LAD-01`)에서 집중 구현하기로 백로그 정식 이연.
