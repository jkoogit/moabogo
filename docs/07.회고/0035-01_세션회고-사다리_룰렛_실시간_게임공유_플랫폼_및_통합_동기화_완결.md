## 2. 주요 아키텍처 및 구현 성과

### 2.1 룰렛판 중앙 버튼 연속 회전 및 SVG 외부 고정 허브 UI
- **연속 회전 인터랙션 (`RouletteGameZone.tsx`)**:
  - 기존의 `if (isSpinningRef.current && broadcast) return;` 차단 가드를 제거하고, 회전 중 중앙 버튼을 다시 누르면 `clearSpinTimer()`로 직전 스핀 타이머를 취소한 뒤 현재 각도 기준으로 새로운 스핀 목표 각도를 즉각 재계산하여 끊김 없이 연속 회전하도록 개편했습니다.
- **SVG 휠 외부 고정 허브 오버레이 (`RouletteWheelSvg.tsx`)**:
  - 회전판 중심의 버튼을 SVG 내부에서 분리하여 `absolute inset-0 m-auto z-20` 고정 오버레이로 전환함으로써, 휠이 고속 회전하는 중에도 텍스트가 정방향 수평을 유지하고 터치/클릭 반응성을 극대화했습니다.

### 2.2 게임공유 팝업 모드 분리 및 자동 퇴장 파이프라인
- **2-Way 탭 인터페이스 (`LadderModals.tsx`)**:
  - `[📱 공유 게시 · 관리]`와 `[🔑 방 코드로 참여]` 모드를 명확히 분리하여 초대 링크 없이도 6자리 방 코드 입력만으로 간편 입장을 지원했습니다.
- **이전 방 자동 퇴장 연동**:
  - 새 방 입장 시 기존 채널 연결을 닫고 백엔드 `/leave` API를 선행 호출하여 방 접속 인원수가 정확히 차감되도록 안전장치를 구축했습니다.

### 2.3 사다리 ↔ 룰렛 통합 플랫폼 네비게이션 및 동기화
- **호스트 주도 전역 탭 이동 (`SCR_GNT_01_비로그인게스트홈.tsx`, `server.ts`)**:
  - 개별 게임에 국한되었던 방 공유를 전체 게임 플랫폼으로 확대하여, 방장이 사다리나 룰렛 화면으로 이동하면 참여자 화면도 동일하게 즉시 전환되도록 구현했습니다.
  - 게스트에게는 게임 탭 전환을 비활성화하고 자물쇠 뱃지와 토스트 안내를 제공하여 방장 주도 중계 질서를 확립했습니다.
- **사다리 가로줄 배열 직접 동기화 (`LadderGameZone.tsx`)**:
  - 환경별 난수 시드 오차로 인한 가로줄 불일치 문제를 해결하기 위해, `SHUFFLE_RUNGS` 시 `rungs` 배열 자체를 브로드캐스트 및 서버에 저장하도록 개선했습니다.
- **매장 변경 시 메뉴 즉시 초기화**:
  - 방장이 매장을 변경하거나 해제할 때 참가자들의 메뉴 선택 내역을 `undefined`로 즉시 초기화하여 일관성을 확보했습니다.

### 2.4 가중치 3대 개선 정책 및 비례 풍선효과
- **기본 가중치 10 상향**: 사다리 참가자, 룰렛 항목, 프리셋 4종의 기본 가중치를 `10`(`10x`)으로 설정하고 정수 단위(`±1`)로 증감하도록 개선했습니다.
- **가중치 토글 OFF 시 전원 리셋**: 가중치 스위치를 끄면 방장과 참여자 화면의 모든 가중치 값이 즉시 `10`으로 일괄 리셋됩니다.
- **가중치 0 고정 및 비례 풍선효과**:
  - 가중치가 0에 도달하면 음수로 내려가지 않고 `0`으로 고정(`0x 🎈`).
  - 0에서 `[-]` 추가 클릭 시 타 양수 항목들이 현재 가중치 비율에 비례하여 증가(`proportionalBonus = Math.max(1, Math.round(otherW / minOtherW))`).
  - 회전판에서 가중치 0 항목은 슬라이스 각도 0도로 제외되고 1,000회 연속 추첨 시뮬레이션에서도 당첨 확률 0%로 완전 배제됨을 검증했습니다.

## 3. 학습 및 반성 (Keep, Problem, Try)

### Keep (지속할 점)
- **독립 Node.js 단위 테스트 기반 검증**: 풍선효과 및 휠 제외 로직을 `scratch/test_balloon_weights_v2.cjs`로 사전에 엄격히 검증하여 회귀 버그를 방지함.
- **FSD 아키텍처 및 RBAC 역할 분리**: 방장과 게스트의 권한 범위를 명확히 나누고, 백엔드(`HOST_ONLY_ACTIONS`)와 프론트엔드(UI Guard) 양단에서 이중 방어 체계를 확립함.
- **빠른 피드백 반영 및 완결성**: 사용자의 직관적인 UX 요구사항(풍선효과, 버튼 중복 제거, 코드 입력 분리 등)을 짧은 호흡의 마이크로 턴으로 정확하게 반영함.

### Problem (발생했던 문제 및 한계)
- Windows 환경에서 Antigravity IDE 업데이트 및 VS Code 정책 감시 네이티브 모듈(`.node`) 관련 윈도우 보안 알림이 발생하여 원인 분석 및 개발 안전성 안내를 병행함.
- `BKL-LAD-03`(RDBMS 세션/분산 락/CSPRNG) 백엔드 영속성 및 `BKL-DATA-01`(PostgreSQL 16 실제 테이블 연동) 과제는 인프라 범위로 인해 다음 세션 과제로 이월됨.

### Try (다음 세션 개선 과제)
- **`BKL-LAD-03` 게임공유 백엔드 보안 강화 착수**: 인메모리 룸 상태를 PostgreSQL/Redis 분산 락 및 세션 테이블로 전환하여 다중 인스턴스 환경 대비.
- **`BKL-DATA-01` PostgreSQL 16 실 원장 테이블 연동**: 가계부/모아머니/정산 실제 DDL 마이그레이션 및 ORM 레포지토리 레이어 구축.
