## 2. 주요 아키텍처 및 구현 성과

### 2.1 정산 영역 컴팩트 단일 컨테이너 전환 (`SettlementGameZone.tsx`)
- **타이틀 인라인 가중치 토글 & 레이어드 안내 팝업**:
  - `총 결제 금액 (원)` 라벨 우측에 `[가중치 ON/OFF]` 버튼을 인라인으로 배치하고, 안내문구를 `?` (HelpCircle) 아이콘 버튼 클릭 시 열리는 레이어드 툴팁 팝업으로 전환하여 세로 높이를 절약했습니다.
- **결과 복사 영역 하단 이동 및 기존 패널 삭제**:
  - 기존 우측 패널(`div.flex.flex-col.justify-between.space-y-3`)을 완전히 삭제하고, 참가자별 송금 현황 목록 하단으로 텍스트 복사, 이미지 카드 복사, 파일 다운로드 3대 버튼을 이동하여 상단 금액 입력을 직관적 단일 컬럼으로 정돈했습니다.

### 2.2 게임공유 팝업 높이 고정 스크롤 컨테이너 (`LadderModals.tsx`)
- `GameShareModal` 내 탭 컨텐츠를 `min-h-[420px] max-h-[72vh] overflow-y-auto no-scrollbar`로 래핑하여 두 탭 간 높이를 QR 코드 표시 기준으로 일치시키고 탭 전환 시 창 크기 변경에 따른 혼란을 방지했습니다.
- 팝업 내 불필요하게 중복 노출되었던 `🔒 게임 종료` 버튼을 정리하여 화면 상단 헤더와의 기능 중복을 제거했습니다.

### 2.3 사다리 플레이 존 360px 반응형 및 속도 조절 드래그 휠 (`LadderGameZone.tsx`)
- **매장 연동 레이어드 팝업**:
  - 2줄의 매장 연동 설명 텍스트를 `?` 아이콘 버튼 클릭 시 열리는 팝업 툴팁으로 전환하여 상단 높이를 대폭 절약했습니다.
- **속도 조절 `ElmSld03` 적용**:
  - 배속 선택 버튼 바에 모아보고 표준 수평 슬라이더 토큰인 `ElmSld03`을 적용하여 마우스 드래그, 터치 스크롤, 휠 스크롤(화면 상하 스크롤 간섭 방지)을 매끄럽게 지원했습니다.
- **최종 매칭 결과 카드 모바일 1열화**:
  - `grid-cols-1 sm:grid-cols-2 md:grid-cols-3`를 적용하여 360px 화면에서도 텍스트 생략 없이 모든 참가자 결과를 한 줄에 하나씩 온전히 노출했습니다.

### 2.4 룰렛 플레이 존 정돈 및 프리셋 위치 최적화 (`RouletteGameZone.tsx`)
- **추천 프리셋 영역 상단 재배치**:
  - 주제 선택과 밀접한 추천 프리셋 영역을 `현재 룰렛 주제` 헤더 바로 아래로 배치하여 직관적인 조작 흐름을 제공했습니다.
- **가중치 버튼 좌측 정렬 & 버튼명 축약**:
  - `설정 항목` 라벨 옆으로 `[가중치 ON/OFF]` 버튼을 배치하고, `항목 & 프리셋 설정` 버튼명을 `항목상세설정`으로 축약했습니다.
- **인라인 헤더 흐름 및 중복 요소 제거**:
  - 휠 상단 헤더에서 타이틀, 방 코드, 접속자 수, [게임 종료] 버튼이 공간이 허용되면 한 줄로 자연스럽게 이어지도록 flex 구조를 개선하고, 상단 중복 공유 버튼 및 배지를 제거했습니다.
