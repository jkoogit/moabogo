## 2. 주요 아키텍처 및 구현 성과

### 2.1 시스템설정 백오피스(`SCR-SYS-01`) 전역 거버넌스 승격
- 기존 단순 인프라 관제(PostgreSQL, 터널, RAM OOM, EasyOCR) 화면을 8대 서류철 탭 체계로 전면 확장:
  1. `INFRA`: 실시간 리소스 관제 대시보드
  2. `AUTH_SEC`: 로그인 인증 및 보안 거버넌스
  3. `NOTIFY`: 12종 전역 알림 발송 매트릭스
  4. `RBAC`: 6대 시스템 관리 (약관, 메뉴, 화면, 권한그룹, 권한매핑, 사용자)
  5. `FINANCE`: 금융 컴플라이언스 송금 통제
  6. `MASTER_CODES`: 20대 마스터 그룹 및 상세 코드 관리
  7. `GAME_POOL`: 사다리 매장/메뉴 풀 및 룰렛 프리셋
  8. `NOTICES`: 3모드 긴급 공지 관리

### 2.2 약관 거버넌스 & 서브버전 자동 증가 알고리즘
- **약관 카드 UI 최적화**: 카드 헤더에 있던 라디오버튼을 제거하고 시행일, 이력 건수, 삭제 버튼으로 정돈.
- **개정 저장이력 체크박스(`ElmChk01`) 단일 배타적 선택**:
  - 각 이력 행 맨 앞의 체크박스를 클릭하면 해당 버전만 `isCurrent = true`로 승격되고, 기존의 다른 이력들은 즉시 `isCurrent = false`로 자동 해제.
- **이력 선택 시 상단 본문 즉시 전환**:
  - 과거 이력을 클릭하면 상단 약관 표시 영역(본문 및 버전 뱃지)이 선택된 이력의 Markdown 내용으로 실시간 전환.
- **서브버전 자동 증가 규칙 (`calculateNextSubVersion`)**:
  - 사용자가 버전을 수정하지 않고 저장 시: 단일 정수(`v1`)는 `v1.1`로, 서브버전(`v1.1`)은 다음 서브버전(`v1.2`)으로 자동 증가 등록.
  - 사용자가 버전 필드를 직접 입력하여 수정한 경우: 입력한 버전 그대로 저장.

### 2.3 공통 디자인 정책 토큰 신설 및 고도화 (`Tokens.tsx`)
- **`ElmMkd01` (마크다운 에디터 & 실시간 미리보기)**:
  - 툴바 모드 전환 탭: 텍스트 없이 **아이콘 전용(`Edit2`, `Eye`, `Columns`)** 콤팩트 디자인 및 툴팁(`title`) 제공.
  - **코드 프리셋 단축 버튼**: [+ 표], [+ Mermaid], [+ 코드], [+ 체크] 원클릭 템플릿 삽입 지원.
- **`ElmMkdViewer` (마크다운 렌더러)**:
  - 마크다운 테이블(`| th1 | th2 |`) 다크모드 대응 반응형 HTML table 렌더링.
  - Mermaid 다이어그램(````mermaid ... ````) 파싱, 시각화된 노드-엣지 흐름도 카드 렌더링 및 [코드 원문 보기] 토글 지원.
- **`ElmChk01` (체크박스 토큰)**:
  - 라벨 텍스트 클릭 시 전체 영역 토글 이벤트 보장 (`sr-only` input + label onClick).
  - 테이블 내 disabled 체크박스 및 모든 폼 컨트롤 표준화.

### 2.4 사용자 맞춤설정(`SCR-SET-01`)과 실시간 동적 연동
- 백오피스에서 추가/수정/삭제된 사다리 매장 및 메뉴 정보가 `getSystemStorePool()` 헬퍼를 통해 사용자 맞춤설정 화면에 실시간으로 반영되어, 플랫폼 관리자와 일반 사용자의 데이터 정합성을 완전 확보.
