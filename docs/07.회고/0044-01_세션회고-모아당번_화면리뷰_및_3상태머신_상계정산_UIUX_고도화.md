## 2. 주요 구현 및 기술적 성과

### 1) 상세 본문(정보 제공)과 수정 폼(팝업 모달)의 명확한 역할 분리
- 기존 당번 상세화면(`SCR_DUT_02`)은 정보 조회 영역과 상태 변경, 주기 수정 등 인터랙션 요소가 혼재되어 화면이 복잡하고 버튼이 난립해 있었습니다.
- 사용자 피드백에 따라 상세 본문을 **'정갈한 정보 제공 대시보드 뷰어(Info Dashboard)'**로 리팩토링하고, 당번 정보 및 정책, 상태값의 일괄 편집은 헤더 우측의 **`[✏️ 당번 정보 수정]` 전용 팝업 모달(`ElmBsh01`)**로 완벽히 분리하였습니다.
- 이를 통해 사용자는 평상시 깔끔한 상태 대시보드로 당번 진행/정산/검증 현황을 모니터링하고, 필요 시에만 집중 모달을 열어 수정을 진행할 수 있게 되었습니다.

### 2) 인지 혼선을 초래하던 텍스트 토글의 드롭다운(`<select>`) 전환
- 정산 주기 기준(주간/월간/일간)이 단순히 링크 텍스트를 클릭하여 순환 토글되는 방식이어서, 현재 상태인지 다음 변경할 상태인지 사용자가 파악하기 어려웠습니다.
- 이를 명확한 HTML `<select>` 드롭다운 컴포넌트로 개편하여 현재 선택된 정산 주기를 즉시 인지하고 원클릭으로 변경할 수 있도록 시인성을 극대화하였습니다.

### 3) 카테고리 트리(`ElmTre02`) 높이 프리셋(`3건 | 5건 | 10건 | 전체`) 제어
- 가계부 카테고리 분류 요소가 세로로 길어져 화면의 상당 부분을 차지하던 문제를 해결하기 위해, `ElmTre02CategoryView`에 `heightPreset` 제어 기능을 추가하였습니다.
- 펼침 시 상단에 `[3건 | 5건 | 10건 | 전체]` 세그먼트 버튼을 제공하며 기본값은 3건(약 145px 내부 스크롤)으로 설정하였습니다.
- 접기 토글 시 높이 선택 옵션도 함께 숨겨져 깔끔한 미니멀 UI를 완성하였습니다.

### 4) `?` 도움말 아이콘 레이어 팝업을 통한 시각적 노이즈 제거
- 직교 3상태머신(진행/검증/정산)에 대한 긴 설명 배너가 화면 상단을 지속적으로 점유하던 것을, `① 진행 상태` 라벨 옆의 컴팩트한 `?` 아이콘 버튼으로 축소하였습니다.
- 사용자가 필요할 때만 아이콘을 눌러 `showStateGuideModal` 레이어 팝업으로 상세 상태 전이 규칙을 확인할 수 있도록 개선하여 화면의 여백과 쾌적함을 확보하였습니다.

### 5) 단순 캐주얼 게임과 정규 업무 간 억지 결합도 해소
- 사다리타기와 룰렛은 가볍고 즐거운 내기/추첨 게임임에도, 게임 완료 시 당번 과업을 의무적으로 생성하도록 유도하던 결합 모달(`isDutyModalOpen`)이 사용자 피로도를 유발하고 있었습니다.
- 사용자 피드백을 수용하여 해당 강제 연계 모달과 핸들러를 과감히 제거하고, 게임은 본연의 경쾌한 결과 공유에 집중하도록 하였습니다.

### 6) 전역 캘린더 허브 & 스마트 라이프 다이어리(`BKL-CAL-01`) 기획
- 마이페이지 내 전역 일정관리(가계부, 목표, 당번, 루틴의 일정을 카테고리별로 필터링/통합 확인) 기능 기획을 수립하였습니다.
- 단순 일정을 넘어 키워드 일기, 3줄 일기, Markdown 서식(토글/표/이미지), N년 전 오늘 회고("과거의 오늘"), 모바일 사진 EXIF/타임스탬프 기반 작성 추천 기술을 체계적으로 정의한 공식 백로그(`docs/06.백로그/BKL-CAL-01_...md`)를 수립 및 등록하였습니다.

## 3. 장애 대응 및 예외 방어 내역

1. **PowerShell 멀티 라인 `&&` 실행 구문 에러 교정**:
   - `git fetch origin dev && git checkout -B dev origin/dev` 실행 시 PowerShell 환경의 `&&` 토큰 파싱 에러를 식별하고, 세미콜론(`;`) 구분자 방식으로 신속히 변경하여 원격 동기화를 완결하였습니다.
2. **패키지 매니저 실행 환경 적응 (`pnpm` ➔ `npm` / `npx`)**:
   - 환경에 `pnpm`이 누락되어 있어 발생한 오류를 인지하고, 전역 설치된 `npx.cmd tsc --noEmit`과 `npm.cmd run build`로 빌드 및 컴파일 명령을 일원화하여 0-Error 검증을 수행하였습니다.
3. **네트워크 스트림 단절 시 안정적인 복원**:
   - `git push` 중 네트워크 스트림 끊김이 발생했으나, 원격 브랜치 상태(`git status`, `git branch -vv`)를 즉시 재확인하고 안전하게 PR #115 발행, 머지 및 3개 브랜치 패스트포워드 승급을 완결하였습니다.
4. **대화 턴 최하단 후속 프롬프트 코드블록(```) 100% 준수**:
   - 사용자 피드백을 최우선으로 반영하여, 세션 정리 및 모든 대화 턴의 최하단에 사용자가 원클릭으로 복사하여 다음 액션을 즉시 실행할 수 있는 정제된 단일 후속 프롬프트 코드블록을 100% 필수 제공하였습니다.
