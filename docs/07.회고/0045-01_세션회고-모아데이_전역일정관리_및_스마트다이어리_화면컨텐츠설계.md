## 2. 주요 구현 및 기술적 성과

### 1) 네이버 캘린더형 상세 반복 설정 엔진 (`MoaDayRecurrenceModal`)
- 네이버 캘린더의 직관적인 반복 인터페이스를 벤치마킹하여, 반복 주기(`DAILY`, `WEEKLY`, `MONTHLY`, `YEARLY`), 반복 간격, 주간 반복 시 특정 요일(월~일) 복수 선택, 종료 조건(종료일 없음, N회 반복 후 종료, 특정 일자까지 반복)을 완벽히 모델링하였습니다.
- 설정된 규칙을 사람이 읽기 쉬운 한국어 요약문(`summary`)으로 실시간 렌더링하고, RFC 5545 iCalendar 호환 데이터 구조로 영속화하여 일정 등록 모달과 완벽히 바인딩하였습니다.

### 2) 구조적 스마트 다이어리 3대 블록 및 PWA 리소스 수집기
- 하나의 긴 글 작성에 대한 부담감을 덜어주기 위해, 다이어리를 **[1. 해시태그 키워드] ➔ [2. 3줄 일기 요약 (사건/느낌/다짐)] ➔ [3. 자유 마크다운 서술]** 3대 독립 블록 아코디언 구조로 설계하였습니다.
- GPS 위치 및 실시간 기상 자동 수집, PWA 시뮬레이션을 통한 당일 모바일 사진/통화녹음/문서 감지 및 일괄 일기 본문 배치, 오디오 플레이어 연계를 완결하였습니다.

### 3) 태그별 에피소드 작성 및 전체보기 전수 나열 렌더링
- 하루 동안 여러 관심사(예: #업무, #운동, #식단)가 복합적으로 발생하는 일상의 특성을 반영하여, 태그 칩 선택 시 해당 태그 전용 3줄 일기와 본문을 독립적으로 작성할 수 있는 태그별 에피소드 엔진(`taggedBlocks`)을 구축하였습니다.
- 일자 상세 패널 및 확대보기 팝업에서 `ALL`(전체보기) 선택 시 공통 일기뿐만 아니라 태그별 에피소드를 순차적으로 빠짐없이 모두 열거 렌더링하여 데이터 누락 없는 풍부한 기록 열람을 보장하였습니다.

### 4) 가로 슬라이더 휠 트랩 방지(Pass-Through) 스크롤 통제 표준화
- 필터 칩 바, 과거의 오늘 카드, 미리보기 태그 바, 상세 패널 태그 바 등 가로 슬라이더 요소에서 마우스 휠 동작 시 상하 스크롤이 차단되는 '휠 트랩(Wheel Trap)' 현상을 완벽히 방어하였습니다.
- `scrollLeft <= 0 && deltaY < 0` 또는 `scrollLeft + clientWidth >= scrollWidth - 1 && deltaY > 0`인 양 끝 도달 시 브라우저 기본 세로 스크롤로 부드럽게 패스스루시키는 이벤트를 표준화하여 데스크톱과 모바일 모두에서 최고의 스크롤 사용성을 확보하였습니다.

### 5) `ElmBsh01` 바텀시트 고정 3분할(Header / Body / Footer) 표준 아키텍처 확립
- 기존 모달의 헤더와 버튼 바가 본문 스크롤과 함께 위로 밀려 사라지던 구조적 한계를 극복하기 위해, `ElmBsh01` 컴포넌트를 **고정 상단 헤더(`shrink-0`) + 단독 세로 스크롤 본문(`flex-1 overflow-y-auto`) + 고정 하단 푸터(`footer?: React.ReactNode`, `shrink-0 border-t`)** 3분할 구조로 리팩토링하였습니다.
- 이를 통해 사용자는 긴 폼을 스크롤하는 도중에도 언제든지 타이틀/닫기 버튼을 인지하고, 하단의 [미리보기], [취소], [저장] 액션을 즉각 수행할 수 있게 되었습니다.

## 3. 장애 대응 및 결함 보정 내역

1. **마크다운 서식 프리셋 추가 버그 해결**:
   - 공통 외 태그 에피소드 모드에서 템플릿 프리셋(감사일기, KPT, 가계부점검 등) 추가 시 본문에 반영되지 않던 문제를 추적하여, `handleInsertTemplateAtCursor`에서 `setDiaryMarkdown` 직접 호출 대신 활성 블록 상태에 맞는 `handleUpdateCurrentMarkdown`을 호출하도록 수정하여 해결하였습니다.
2. **에피소드 전환 시 UX 인지 부하 해소**:
   - 태그별 작성 모드로 전환된 후 공통 작성으로 돌아오기 어렵던 문제를 해결하기 위해, 태그 칩 재클릭 토글 오프, `#태그선택해제` 텍스트 명시, 에디터 헤더 뱃지 내 `✕` 닫기 버튼 일체화를 적용하여 인지 부하를 완전히 해소하였습니다.
3. **가변 패널 리사이징 시 텍스트 선택 방지**:
   - 패널 경계면을 드래그하여 너비/높이를 조절할 때 화면 내 텍스트가 블록 선택되는 현상을 방지하기 위해, 리사이징 활성 시 컨테이너에 `select-none`을 동적 바인딩하여 매끄러운 드래그 경험을 제공하였습니다.
