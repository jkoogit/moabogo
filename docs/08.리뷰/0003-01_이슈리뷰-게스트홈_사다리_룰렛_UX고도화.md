## 2. 코드 레벨 아키텍처 및 상세 구현 분석

### 2.1 사다리 경로 추적 및 발자국(`footprints`) 상태 머신
```tsx
// 사다리 이동 틱마다 참가자의 좌표 및 방향을 계산하여 궤적을 실시간 SVG에 반영
const currentPos = pathCoords[currentStepIndex];
activeFootprints.push({ x: currentPos.x, y: currentPos.y, memberId: member.id });
```
- 발자국 좌표를 메모이제이션하여 렌더링 부하를 최소화하고, 모든 라인의 이동이 끝난 후 당첨자 목록을 순차 집계합니다.

### 2.2 룰렛 회전 및 동적 트랜지션 제어
```tsx
// 룰렛결과(즉시 결과) 실행 시 600ms 동적 트랜지션과 함께 당첨 슬라이스 중심각(sliceMidAngle)으로 정확히 회전
setRouletteTransitionDuration(600);
const chosenSlice = rouletteSlices.find((s) => s.member.id === chosen.id);
const sliceMidAngle = chosenSlice ? (chosenSlice.startAngle + chosenSlice.endAngle) / 2 : 180;
const targetDelta = ((270 - sliceMidAngle) % 360 + 360) % 360;
setRouletteRotation(prev => {
  const currentMod = prev % 360;
  return prev - currentMod + 360 * 2 + targetDelta;
});
```

### 2.3 제로-줄바꿈(Zero Text-Wrap) 버튼 레이아웃 정책
- 버튼 내부 텍스트는 `whitespace-nowrap`을 강제하여 단어가 임의 분절되는 현상을 방지.
- 컨테이너는 `flex flex-wrap items-center gap-2`를 적용하여 뷰포트가 좁아질 경우 버튼 자체가 통째로 다음 행으로 개행되도록 보장.
