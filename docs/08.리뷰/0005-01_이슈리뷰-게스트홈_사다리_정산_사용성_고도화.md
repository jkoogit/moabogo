## 2. 코드 레벨 아키텍처 및 상세 구현 분석

### 2.1 사다리 가로줄 동적 생성 및 무작위 재배치 (`handlePlayAgain`)
```tsx
// 다시 사다리 타기 실행 시 신규 시드로 가로줄을 즉각 재배치하여 실행
const handlePlayAgain = () => {
  const newSeed = Math.floor(Math.random() * 1000000);
  setLadderSeed(newSeed);
  const newRungs = generateLadderRungs(members.length, newSeed);
  handlePlayLadder(false, newRungs);
};
```
- `computeLadderPaths`에 `customRungs` 파라미터를 지원하도록 확장하여, 상태 변경의 비동기 지연 없이 인자로 전달된 새로운 사다리 구조를 즉시 계산 및 주행하도록 개선했습니다.

### 2.2 목표 텍스트 생성 헬퍼 (`generateDefaultLadderGoals`)
```tsx
const generateDefaultLadderGoals = (total: number, winners: number) => {
  const goals: { text: string; icon: string }[] = [];
  for (let i = 0; i < winners; i++) {
    goals.push({ text: `선택 ${i + 1}`, icon: '🎁' });
  }
  const remaining = Math.max(0, total - winners);
  for (let i = 0; i < remaining; i++) {
    goals.push({ text: `통과 ${i + 1}`, icon: '💨' });
  }
  return goals;
};
```
- 당첨 인원수와 전체 참가자 수에 따라 `선택 1`, `선택 2` (🎁 선물상자)와 `통과 1`, `통과 2` (💨 바람)가 규칙적으로 배치되며, 인원 변동 시에도 순번이 흐트러지지 않도록 상태 동기화 훅(`useEffect`)을 연결했습니다.

### 2.4 정산 금액 빠른 증감 기능 (`handleAdjustAmount`)
```tsx
const handleAdjustAmount = (delta: number) => {
  const numeric = parseInt(amount.replace(/[^0-9]/g, '') || '0', 10);
  const next = Math.max(0, numeric + delta);
  setAmount(next > 0 ? next.toString() : '');
};
```
- 쉼표나 특수문자가 섞인 입력값에서도 숫자만 안전하게 추출하여 계산하며, 음수 입력 방지(`Math.max(0, ...)`) 및 0원 도달 시 빈 값 정리를 수행합니다.
