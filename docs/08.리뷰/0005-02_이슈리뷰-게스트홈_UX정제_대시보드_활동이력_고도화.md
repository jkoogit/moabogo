### 2.1 정산 프리셋 영역 가로스크롤 완전 제거 (`SCR_GNT_01`)
```tsx
{/* 2. 중앙 영역: {1만원, 3만원, 5만원, 8만원, 10만원} 프리셋 칩 (가로 스크롤 삭제 및 유연한 래핑) */}
<div className="flex-1 min-w-0 flex items-center justify-center gap-1 flex-wrap py-0.5">
  {[10000, 30000, 50000, 80000, 100000].map((preset) => (
    <button
      key={preset}
      type="button"
      onClick={() => handleAdjustAmount(preset)}
      className="px-2 py-0.5 text-[11px] font-bold rounded-lg border border-slate-200 bg-white hover:bg-emerald-50 hover:border-emerald-300 text-slate-700 transition-all shadow-xs shrink-0 active:scale-95"
    >
      {preset >= 10000 ? `${preset / 10000}만원` : `${preset.toLocaleString()}원`}
    </button>
  ))}
</div>
```
- 컨테이너가 좁은 모바일 화면에서도 스크롤 바가 생기거나 칩이 잘리지 않고 자동으로 줄바꿈(`flex-wrap`)되어 모든 금액 선택지가 즉시 노출됩니다.

### 2.3 대시보드 활동이력 뷰어 및 페이징 상태 머신 (`SCR_DSH_01`)
```tsx
// 활동이력 상태 관리: 20건 모의 데이터, 카드/목록 모드, 5/10/20 필터, 페이지 번호
const [activityFeed, setActivityFeed] = useState<ActivityItem[]>([...20건 풀 데이터...]);
const [activityViewMode, setActivityViewMode] = useState<'CARD' | 'LIST'>('LIST');

// 슬라이싱 및 페이징 파이프라인
const effectiveFeed = activityFeed.slice(0, activityLimit);
const ITEMS_PER_PAGE = 5;
const totalPages = Math.max(1, Math.ceil(effectiveFeed.length / ITEMS_PER_PAGE));
const currentPageFeed = effectiveFeed.slice((activityPage - 1) * ITEMS_PER_PAGE, activityPage * ITEMS_PER_PAGE);
```

### 2.4 카드 뷰 vs 목록 뷰 반응형 렌더링
- **목록 모드 (`LIST`)**: 타임라인 점(`w-2 h-2 rounded-full`)과 함께 컴팩트한 단일 행으로 좌측 서비스 뱃지, 제목/상세 설명, 우측 금액 및 타임스탬프를 정렬.
- **카드 모드 (`CARD`)**: `grid grid-cols-1 sm:grid-cols-2 gap-2`의 카드 블록 형태로 서비스 아이콘, 승인/완료 상태 뱃지, 핵심 금액을 강조 렌더링.
- **스크롤 & 페이징**: 5줄 초과 시 `max-h-[380px] overflow-y-auto` 스크롤과 함께 하단 네비게이션 컨트롤(`[이전]`, `[1]`, `[2]`, `[다음]`)을 동시 지원.
