## 1. 개요 및 요구사항 대비 구현 내역

본 태스크는 `AGENTS.md` v2.2 하네스 및 디자인 거버넌스 규정에 따라,
화면 상단 고정 레이어 최적화, 뷰포트 모드 전환기 팝업화, 헤더 타이틀 디자인 표준화, 인증 화면 중복 레이아웃 제거, 사다리 실물 매장 제품 이미지 현행화, 룰렛 즉시결과 및 ELM-TRE-01 데이터 트리 드래그 위치 플래그 기능을 전수 구현하고 검증하였습니다.

### 1.1 핵심 구현 내역 요약

1. **뷰포트 모드 전환기 팝업화 (`src/App.tsx`)**:
   - 상단 헤더 바에서 3개 버튼(`Monitor`, `Tablet`, `Smartphone`)이 나열되어 공간을 차지하던 것을, 현재 활성화된 모드의 단일 아이콘 버튼 + 클릭 시 심플 레이어 팝업 선택창(체크마크, 해상도 안내, 외부 클릭 감지 닫힘)으로 전환.
2. **헤더 타이틀 디자인 표준화 (`SCR_DSH_01`, `SCR_LED_01`, `Tokens.tsx`)**:
   - `SCR-DSH-01`(대시보드) 및 `SCR-LED-01`(가계부 상세): 임의 `h1/p` 태그를 화면 식별 뱃지와 `<ElmTyp01>` 디자인 토큰 컴포넌트로 표준화.
   - `ElmTyp01` 다크모드 텍스트 컬러(`dark:text-zinc-100`, `dark:text-zinc-400`) 지원 보강.
3. **로그인 / 회원가입 화면 중복 탑영역 제거 및 버튼 개선 (`SCR_AUT_01`, `SCR_AUT_02`)**:
   - 화면 내부 중복 `<header>` 영역을 제거하고, 식별 뱃지를 카드 내부 타이틀 상단으로 일원화.
   - 버튼 텍스트 간결화: `로그인하고 내 가계부 열기` ➔ `로그인`, `가입 완료하고 내 가계부 바로 열기` ➔ `회원가입`.
   - `홈` 이동 버튼(`onGoHome`)을 로그인/회원가입 버튼 좌측에 인라인 결합 배치.
4. **사다리 실물 매장 제품 이미지 전수 교체 및 화면 요소 현행화**:
   - `PLUS CAFE 45층` (여의도 63빌딩 WPS 스타벅스 공식 파트너) 34종 전 메뉴에 실물 제품 이미지 URL(`imageUrl`) 전수 연동 (`systemStorePool.ts`).
   - 사다리 참가자 기둥 상단 원형 아바타, 메뉴 선택 모달 목록, 롱프레스 상세 툴팁에 실물 제품 이미지 렌더링 및 `referrerPolicy="no-referrer"` 적용.
   - 사다리 결과 카드 이미지 생성 시 메뉴 선택 참가자 아바타를 해당 메뉴 대표 아이콘(☕, 🧊, 🍵, 🥛, 🥐 등) 및 실물 제품 썸네일로 카드 이미지에 반영 (`gameResultCardCanvas.ts`).
5. **룰렛 회전 중 '즉시 결과' 확인 기능 (`SCR_GNT_01`)**:
   - 회전 중(`isSpinning`)에도 `즉시 결과` 버튼을 클릭할 수 있도록 활성화하고 앰버 펄스 하이라이트 제공.
   - 클릭 시 회전 타이머를 즉시 취소하고 확정 각도로 0ms 스냅하여 지체 없이 당첨 결과를 표출.
6. **사다리·목표 재배치 표준 토스트 연동 및 쇼케이스 등록**:
   - 사다리 가로줄 및 목표 재배치 시 화면 하단 중앙 플로팅 토스트(`ElmToast01`)로 시맨틱 알림 표출.
   - `ui-tokens-metadata.json`에 `ELM-TOA-01` 공식 토큰 등록 및 `SMP-01` 쇼케이스 내 4대 시맨틱 토스트 라이브 데모 구현.
7. **`ELM-TRE-01` 목록 데이터 트리 편집모드 드래그 핸들 및 실시간 위치 플래그 (`Tokens.tsx`)**:
   - 편집 모드 시 핸들(`☰`) 드래그로 상하 및 다른 부모 노드로 항목 위치 변경 지원.
   - 드래그 중 실시간 위치 플래그 표출: `▲ [위치 플래그] '...' 앞에 삽입`, `↳ [위치 플래그] '...'의 하위(자식) 노드로 이동`, `▼ [위치 플래그] '...' 뒤에 삽입`, `🚫 이동 불가`.
   - 순환 참조 방지 및 드롭 시 자동 트리 확장, 쇼케이스 `SMP-01` 연동.
