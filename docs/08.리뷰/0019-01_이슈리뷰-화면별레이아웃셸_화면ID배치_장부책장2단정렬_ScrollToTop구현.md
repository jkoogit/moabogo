## 2. 주요 작업 내용 및 설계 반영

### 2.1 화면 ID 뱃지 위치 전면 최적화 (개발 완료 후 숨김 용이 구조)
- **배경**: 기존에는 각 화면의 좌측 최상단에 `SCR-XXX-01` 뱃지가 크게 자리잡아 화면 타이틀 및 디자인 미관을 저해함. 개발 완료 시 조건부 숨김 처리가 용이하도록 타이틀 바로 뒤로 위치를 재조정.
- **반영**:
  - `SCR-AUT-01` (회원가입): 카드 헤더 타이틀 뒤편으로 뱃지 이전.
  - `SCR-AUT-02` (로그인): 카드 헤더 타이틀 뒤편으로 뱃지 이전.
  - `SCR-DSH-01` (메인 대시보드): `ElmTyp01`의 `badge="SCR-DSH-01"` 속성으로 이전.
  - `SCR-LED-01` (통합 장부): `ElmTyp01`의 `badge="SCR-LED-01"` 속성으로 이전.
  - `SCR-GNT-01` (게스트 홈): 상단 히어로 헤더 타이틀 뒤편으로 뱃지 이전.
  - `SCR-DUT-01` (모아당번): `ElmTyp01`의 `badge="SCR-DUT-01"` 속성으로 이전.
  - `SCR-GOL-01` (모아목표): `ElmTyp01`의 `badge="SCR-GOL-01"` 속성으로 이전.
  - `SCR-MON-01` (모아머니): `ElmTyp01`의 `badge="SCR-MON-01"` 속성으로 이전.
  - `SCR-SET-01` (사용자설정): `ElmTyp01`의 `badge="SCR-SET-01"` 속성으로 이전.
  - `SCR-OFF-01` (오프라인): `ElmTyp01`의 `badge="SCR-OFF-01"` 속성으로 이전.
  - `SCR-SMP-01` (쇼케이스): `h1` 타이틀 바로 뒤 `SCR-SMP-01` 뱃지 배치.
  - `SCR-QCK-01` (빠른머니등록): 타이틀 뒤편으로 뱃지 이전.
  - `SCR-QCK-02` (빠른수행등록): 타이틀 뒤편으로 뱃지 이전.

### 2.2 화면 타이틀 영역 상단 여백 표준화
- **기준 규격**: `SCR-LED-01`의 최적화된 패딩 (`px-3 sm:px-6 lg:px-8 pt-2 sm:pt-3.5 pb-8 space-y-4 sm:space-y-5`)을 전 화면 컨테이너에 일관되게 적용하여 스크롤 낭비를 없애고 뷰포트 밀착도를 극대화.

### 2.3 SCR-DSH-01 대시보드 중복 액션 제거 및 섹션 접기/펼치기 토글
- **Row 2 액션 버튼 제거**: "머니등록", "수행등록" 중복 버튼을 삭제하고 화면 우측 하단의 글로벌 퀵독(`ElmQck01`)으로 진입 동선을 단일화.
- **아코디언 토글 연동**:
  - 모듈 2: 요청된 머니 (`isInboundExpanded`)
  - 모듈 4: 모아당번 (`isDutyExpanded`)
  - 모듈 5: 모아목표 (`isGoalExpanded`)
  - 모듈 6: 게임·정산 퀵런처 (`isGameExpanded`)
  - 모듈 7: 활동이력 (`isActivityExpanded`)
  - 모든 토글 버튼은 `ChevronUp/ChevronDown` 아이콘과 함께 부드러운 전환을 지원하며, 벤토 그리드 및 Flex 구조를 손상시키지 않도록 설계.

### 2.4 SCR-LED-01 장부책장 2단 정렬 구조 개편
- **기존 문제**: 데스크톱 화면에서 1행에 [타이틀] [전체/개인/장기/단기 슬라이더] [새장부/건수/닫기/방향]이 가로로 빽빽하게 배치되어 필터가 압박됨.
- **개선**:
  - **1행**: 좌측 타이틀("장부책장") + 우측 통합 제어 컨트롤러 ([+ 새 장부] [건수 뱃지] [책장 열기/닫기] [▲▼ 스택 방향])
  - **2행**: 장부구분 필터 슬라이더 (`ElmSld03`) - 전체, 개인, 장기, 단기 뱃지를 데스크톱/태블릿/모바일 모두 아래 줄에 여유롭고 일관되게 배치.

### 2.5 전역 Scroll-to-Top 플로팅 레이어 버튼 (`App.tsx`)
- **스크롤 감지**: `<main ref={mainRef}>`의 `scrollTop > 140`을 실시간 감지하여 상단이 스크롤되어 내려갔을 때만 노출하고 최상단 도달 시 자동 숨김.
- **플로팅 위젯 레이어 UX**:
  - 원클릭으로 최상단 스무스 스크롤 (`handleScrollToTop`).
  - 펼치기/접기 버튼을 통해 서브 레이어를 토글하여 [최상단으로 / 최하단으로] 양방향 이동 탐색 지원.
  - Light, Dark, Dawn 테마 실시간 블러 및 테두리 색상 동기화.

### 2.6 NewLedgerModal 테마 연동 및 "장부" 용어 정비
- `useTheme` 훅 연동으로 라이트, 다크, 던(Dawn) 모드 배경 및 인풋 색상 완벽 대응.
- 모달 타이틀을 "새 장부 추가"로 변경하고 "가계부" ➔ "장부"로 명칭 일원화.

### 2.7 빠른실행(`ElmQck01`) 번개 아이콘 너비 최적화
- 번개 버튼을 `w-9 h-9`, 상단 드래그 핸들을 `w-8 h-4`로 축소하여 모바일 및 태블릿 화면에서도 콘텐츠를 가리지 않고 미려하게 조화되도록 개선.
