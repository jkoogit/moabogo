## 2. 요구사항 및 반영 내역

### 1) 업무 정의 재정립 (당번 vs 목표 도메인 분리)
- **모아당번 (Duty / Chore)**: 여럿이 역할을 순환하며 함께 결과를 완수하는 책임 미션.
- **모아목표 (Goal / Milestone)**: 개인/그룹의 마일스톤 달성을 관람자에게 공개하고 동행/응원받는 성취 미션.
- 화면 상단에 두 미션의 성격과 규칙을 안내하는 비교 가이드 배너 탑재.

### 2) 사용자 관리형 카테고리 체계 구축
- 시스템 기본 7종 카테고리(청소, 주방, 분리수거, 회계, 돌봄, 운동, 독서) 기본 탑재.
- 모임/가족 필요에 따라 자유롭게 이모지와 이름을 추가·관리할 수 있는 카테고리 관리 모달 구현.

### 3) 새 당번 등록 폼 및 4대 정책 엔진 구현
- **4대 순환 정책**:
  - `RANDOM`: 무작위 추첨
  - `NAME_ASC`: 가나다 이름순 순환
  - `BIRTH_DATE`: 생년월일순 순환
  - `AGE_WEIGHTED`: 기여도 및 나이 가중치 순환 알고리즘 (`calculateNextAssignee`)
- **주기 설정**: 매일, 매주(요일선택), 격주, 매월 + 주기당 완수 횟수.
- **4대 완료 승인 정책**:
  - `PEER_3_APPROVAL`: 타인 3인 이상 완료 확인 (다자간 피어 승인)
  - `ADMIN_APPROVAL`: 관리자 단독 승인
  - `SELF_CONFIRM`: 본인 확인 즉시 완료
  - `NO_APPROVAL`: 승인 생략 (자율 인정)
- **참가자 권한 부여**: `ASSIGNEE`(순환 수행자) vs `VIEWER`(관람자) 분리.
- **초대 링크 발송**: 게스트 소멸성(Transient) 원칙 기반 초대 링크 생성 및 클립보드 복사.

### 4) 당번 목록 조회 및 5대 탭 분기
- `전체 당번` / `내 담당` / `대신수행 요청` / `초대함` (실시간 뱃지) / `실적·인증 이력`
- 키워드 검색, 카테고리 필터 버튼, 미션 구분(당번 vs 목표) 필터 제공.

### 5) 당번 초대 수신함 및 즉시 편입
- 수신된 초대 목록을 조회하고, [초대 수락 및 당번 편입] 클릭 시 내 당번 목록으로 즉시 편입.

### 6) 직교 3상태머신 가시화 및 실적 인증 제출
- `progress_status` (PENDING ➔ ASSIGNED ➔ IN_PROGRESS ➔ SUBMITTED ➔ COMPLETED)
- `settlement_status` (UNSETTLED ➔ SETTLED)
- `evaluation_status` (UNVERIFIED ➔ AUTO_APPROVED / MANUAL_CONFIRMED)
- 수행자가 사진과 메모를 등록하면 순환 알고리즘에 의해 차기 담당자가 즉시 자동 배정.
- 타인 3인 이상 확인 승인 시 누적 카운트 증가 및 임계치 도달 시 자동 완결 전이.

### 7) 대신수행 요청 및 가계부 보상 연계
- 특정인 지명 vs 전체 공개 선착순 요청 지원.
- 보상 베네핏(용돈/머니 vs 품앗이 티켓) 설정 및 [가계부 지출 거래 자동 생성] 토글 지원.
- 다른 구성원이 [내가 대신 수행하기] 수락 시 담당자 스왑 및 가계부 자동 거래 생성 예약 안내.
