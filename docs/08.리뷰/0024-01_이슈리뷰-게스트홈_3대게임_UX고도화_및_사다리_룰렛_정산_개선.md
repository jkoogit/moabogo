## 3. 5대 핵심 피드백 상세 구현 내역

### 3.1. [정산] 금액 미입력 시 가중치 통제 및 값 초기화 일관성 확보
- **문제점**:
  - 금액이 없을 때(0원/빈값) 가중치 증감 버튼을 클릭해도 화면 표시가 `1.0x`로 고정된 채 내부 상태만 누적되어, 금액 입력 시 한 번에 반영되는 유령 클릭(Ghost Click) 발생.
- **해결 방안**:
  - `settlementEngine.ts`: 금액이 0원일 때도 `memberShares`를 계산하여 현재 가중치 상태가 누락되지 않도록 방어.
  - `SettlementGameZone.tsx`:
    - `settlementSummary.total === 0`일 때 가중치 조정 버튼(`-`, `+`, `면제`)을 비활성화(`disabled`, `opacity-30`, `cursor-not-allowed`) 및 툴팁/경고 토스트(`"정산 금액을 먼저 입력해 주세요."`) 제공.
    - 금액 0원 초기화 버튼 클릭 시 또는 금액이 0원이 될 때 모든 참가자의 가중치를 `1.0x`로 완전 리셋하여 일관성 보장.

### 3.2. [사다리] 매장 팝업 모드 분기 및 참가자 메뉴 아이콘 아바타 교체
- **문제점**:
  - 상단 "매장 변경/해제" 버튼과 참가자별 "+ 메뉴 선택" 버튼이 동일한 범용 팝업을 열어 불필요한 탭 전환과 혼란 야기.
  - 메뉴 선택 시 참가자 아바타에 메뉴 이미지가 반영되지 않음.
- **해결 방안**:
  - `StoreMenuSelectModal`: `mode: 'STORE_ONLY' | 'MEMBER_MENU'` 분기 추가.
    - `STORE_ONLY`: 상단 바에서 열릴 때 탭 버튼 숨김, 매장 카드 클릭 시 즉시 매장 설정 후 팝업 닫힘(메뉴 선택 불필요 차단).
    - `MEMBER_MENU`: 참가자별 메뉴 버튼에서 열릴 때 해당 참가자 이름 노출 및 메뉴 선택 즉시 진입.
  - `LadderGameZone.tsx`:
    - `handleSelectMenuForMember`에서 `getStoreMenuEmoji(item)`를 호출하여 참가자의 `avatar`를 선택한 메뉴 아이콘(☕, 🥤, 🥪, 🍰 등)으로 즉시 교체.

### 3.3. [사다리] 참여 인원수 임계치 `[+]` 5명 추가 버튼 신설
- **문제점**: 참여 인원수가 기본 12명으로 제한되어 대규모 모임 시 확장 불가.
- **해결 방안**:
  - `Tokens.tsx` (`ElmRng01`): `unit="명"` 우측에 `onAddThreshold` 전용 `[+]` 버튼 신설.
  - `SCR_GNT_01_비로그인게스트홈.tsx`: `maxMemberLimit` 상태(기본 12) 관리, `[+]` 클릭 시 5명씩 임계치 확장 (12 -> 17 -> 22...).
  - 캐릭터 프리셋 순환 모듈로 12명 이상 시에도 안정적으로 아바타/컬러 부여.

### 3.4. [사다리] 가중치 모드 홀/짝 지그재그(Staggered) 높이 차이 구현
- **문제점**: 컬럼 폭이 84px로 좁아 가중치 조절기(`[-] 1.0x [+]`)가 인접 컬럼과 수평 간섭을 일으킴.
- **해결 방안**:
  - `LadderGameZone.tsx`: 참가자 헤더 칩 컨테이너를 `items-start`로 변경하고 홀수 인덱스(`idx % 2 === 1`)에 `pt-7` (28px) 적용. 짝수 컬럼과 홀수 컬럼의 가중치 버튼이 서로 다른 높이에 배치되어 완벽한 공간 분리 달성.
  - `LadderViewerSvg.tsx`: 하단 목표 칸(Goal Boxes)도 동일하게 `isOdd ? 'pt-6' : 'pt-0'` 적용하여 위아래 엇갈림 레이아웃으로 시각적 안정감 극대화.

### 3.5. [룰렛] 버튼명 고정, 결과 모달 재실행 & [즉시결과], 조건 변경 시 결과 초기화
- **해결 방안**:
  - **버튼명 고정**: 메인 회전 버튼 라벨을 항상 `"룰렛 돌리기"`로 고정 (`"다시 돌리기"` 변경 제거).
  - **결과 모달 개선 (`RouletteResultModal`)**:
    - `"다시 돌리기"` -> `"재실행"`으로 버튼명 변경.
    - `[⚡ 즉시결과]` 버튼 추가: 모달을 닫지 않고 그 자리에서 즉시 새로운 당첨자를 선출하여 결과 카드 및 배경 룰렛판 실시간 갱신.
  - **기본조건 변경 시 초기화**:
    - 설정 항목 수 슬라이더 변경(`handleUpdateRouletteItemCount`) 시 `selectedRouletteWinner = null` 초기화.
    - 추천 프리셋 선택(`handleSelectPreset`, `handleApplyMembersToRoulette`) 시 `selectedRouletteWinner = null` 초기화.
