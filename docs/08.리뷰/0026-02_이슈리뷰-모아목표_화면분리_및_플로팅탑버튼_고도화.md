# 0026-02 이슈리뷰: 모아목표(SCR-GOL-01/02) 화면 분리 및 플로팅 탑버튼 고도화

## 1. 개요 및 배경
- **세션 및 태스크 ID**: 세션 `0026`, 태스크 `[0026-02]` (관련 이슈: GitHub #70)
- **작업 파일**:
  - `src/sample/data/goal-mock-data.ts` (모아목표 공통 도메인 모델 및 샘플 데이터)
  - `src/sample/screen/SCR_GOL_01_모아목표관리.tsx` (모아목표 관리 목록 화면 신설/대체)
  - `src/sample/screen/SCR_GOL_02_모아목표상세.tsx` (모아목표 상세 3대탭 화면 신설)
  - `src/sample/elements/Tokens.tsx` (`ElmFab01` 듀얼 스크롤 감지 및 자체 스크롤탑 버튼 보강)
  - `src/App.tsx` (라우팅 등록 `SCR-GOL-01`, `SCR-GOL-02`, window+mainRef 듀얼 스크롤 감지)
- **목적**:
  1. **모아목표 관리(`SCR-GOL-01`)와 상세(`SCR-GOL-02`)의 완전한 화면 분리**:
     - 기존 단일 파일 내 조건부 렌더링을 지양하고, `SCR-GOL-01`(목록/검색/등록)과 `SCR-GOL-02`(상세 3대탭/인증/용돈이체)로 분리하여 독립 라우팅 및 단일 책임 원칙(SRP) 확립.
     - 모아당번 연계 배너 삭제 (기능적 연관성 없음 검토 완료).
  2. **모아목표 관리(`SCR-GOL-01`) 검색조건 및 뷰 고도화**:
     - 복합 검색 툴바: `ELM-CMB-01` 카테고리 콤보박스, `ELM-FLT-01` 내 역할 다중선택 필터 (`전체역할`, `관리자`, `참가자`, `관람자`), 초기화 아이콘(`RotateCcw`), `목표등록` 버튼.
     - 조회 뷰 전환 토글: `카드보기` (`LayoutGrid`) ↔ `목록보기` (`List` 테이블).
     - `모아목표 등록` 팝업: `ELM-SEL-02` (아이콘 목록선택) 적용, 고정 항목(규칙/기준) 및 입력 항목(수행 기록 가이드) 필드 신설, 등록 시 목록 즉시 반영.
  3. **모아목표 상세(`SCR-GOL-02`) 3대 탭 및 사용자 경험 극대화**:
     - 헤더 타이틀 '모아목표 관리' 유지, 불필요한 역할선택 버튼 및 새목표등록 버튼 완전 삭제.
     - `ELM-STP-01` 단계바 삭제 ➔ `ELM-STT-01` 상태 뱃지(`진행중 🏃`, `달성완료 🎉`, `내 역할`)로 간결화.
     - 탭 1 (목표 현황): 버튼명 `인증제출 ✓`, 실제 파일 첨부 기능(`<input type="file" accept="image/*">`, 썸네일 미리보기, 파일명/용량 표시, 삭제).
     - 소셜 및 권한 규칙: 관리자 역할은 소셜 응원/댓글 등록 불가.
     - 탭 2 (수행 이력): 용돈 수령 대상자(자녀 구민우) 인증 카드에 **[용돈이체 💰]** 버튼 제공 ➔ 클릭 시 **송금 처리 팝업 모달(토스뱅크 대표계좌, 1/3/5/10천원 칩, 토스 송금, 송금마감)** 연동.
     - 탭 3 (참가자 현황): 관람자 시 **RBAC 차단 배너** 노출 (프라이버시 보호).
  4. **플로팅 탑버튼 (Scroll-to-Top) 미작동 문제 완전 해결**:
     - `App.tsx`와 `ElmFab01`에 `window`와 `mainRef` **듀얼 스크롤 감지 리스너** 적용 (`window.scrollY || mainEl.scrollTop > 80`).
     - 화면 스크롤 시 부드럽게 노출, 최상단 복귀 시 자동 숨김, 클릭 시 최상단 스무스 스크롤 보장.
  5. 무오류 정적 빌드(`tsc --noEmit` 0-Error 및 `vite build` 100% 성공) 및 브라우저 E2E 무결성 검증.

### 2.2. [SCR-GOL-01] 모아목표 관리 화면
- **`src/sample/screen/SCR_GOL_01_모아목표관리.tsx`**:
  - 모아당번 연계 배너 완전 삭제.
  - 상단 우측에 `카드보기` ↔ `목록보기` 뷰 모드 전환 토글 배치.
  - 검색 툴바: `ELM-CMB-01` 카테고리 드롭다운 콤보 + `ELM-FLT-01` 역할 다중필터 + `RotateCcw` 초기화 + [목표등록] 버튼.
  - `모아목표 등록` 모달: `ELM-SEL-02` (아이콘 포함 목록 선택), 목표 기준치/단위/기간, 고정 항목 및 입력 항목 설정 폼.
  - 목표 클릭 시 `onSelectGoal(goal.id)` 호출을 통해 `SCR-GOL-02` 상세 화면으로 안전하게 네비게이션.

### 2.3. [SCR-GOL-02] 모아목표 상세 화면
- **`src/sample/screen/SCR_GOL_02_모아목표상세.tsx`**:
  - 헤더: 타이틀 '모아목표 관리' 유지, 좌측 [←] 뒤로가기(`SCR-GOL-01` 복귀), 우측 [초대하기] 및 [응원하기] (관리자는 비활성화).
  - 역할 선택 버튼 및 새목표등록 버튼 삭제.
  - 부적절한 `ELM-STP-01` 단계바 제거 및 `ELM-STT-01` 상태 뱃지 활용.
  - **탭 1 (목표 현황)**: `ELM-RNG-01` 기준치 슬라이더, 실제 파일 첨부 인증제출 폼(버튼명: `인증제출 ✓`), 관리자 응원등록 불가 처리.
  - **탭 2 (수행 이력)**: 자녀 `구민우`의 인증 카드에 `용돈이체 💰` 버튼 배치 ➔ 간편 송금 모달(`TransferModal`) 연동으로 즉시 용돈 송금 완결.
  - **탭 3 (참가자 현황)**: 관람원 역할 시 RBAC 차단 배너 노출, 동행원/관리자 시 전체 명단 열람.
  - **멤버 초대 모달 (`InviteModal`)**: 동행원/관람원 초대 링크 복사 및 6자리 간편 코드(`GOL-7892`) 제공.

### 2.4. [App.tsx & Tokens.tsx] 플로팅 탑버튼 듀얼 스크롤 감지 보정
- **`src/sample/elements/Tokens.tsx` (`ElmFab01`)**:
  - `showScrollTop?: boolean` 옵션과 함께, 컴포넌트 자체 내부 `useEffect`로 `window.scrollY > 80`을 감지하는 `internalScrolled` 2중 안전망 구축.
  - `scrollToTop` 호출 시 `window`, `document.documentElement`, `mainEl` 모두에 대해 스무스 스크롤 실행.
- **`src/App.tsx`**:
  - `window`와 `mainRef` 양쪽에 스크롤 리스너 바인딩 (`const currentY = Math.max(winY, mainY); if (currentY > 80)`).
  - `SCR-GOL-01` 및 `SCR-GOL-02` 독립 화면 라우팅 등록 및 `selectedGoalId` 상태 연동.
