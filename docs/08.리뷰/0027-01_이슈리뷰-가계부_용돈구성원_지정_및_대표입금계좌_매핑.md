# 0027-01 이슈리뷰: 가계부 용돈구성원 지정 및 대표입금계좌 1:1 매핑 체계 구축

## 1. 개요 및 배경
- **세션 및 태스크 ID**: 세션 `0027`, 태스크 `[0027-01]` (관련 이슈: GitHub #73)
- **작업 파일**:
  - `src/sample/data/accountStorePool.ts` (사용자 다중 계좌 및 가계부 용돈구성원 하네스 스토어 신설)
  - `src/sample/screen/SCR_SET_01_사용자설정.tsx` (사용자 설정 화면 4번째 탭 '계좌 관리' 전면 신설/개편)
  - `src/components/ledger/modals/LedgerMemberManageModal.tsx` (가계부 참여자 설정 모달 내 용돈구성원 및 대표계좌 1:1 매핑)
  - `src/sample/screen/SCR_GOL_02_모아목표상세.tsx` (모아목표 실천이력 응원 송금 분기 및 송금 모달 직접입력/현금종료 연동)
  - `src/sample/screen/SCR_DSH_01_로그인메인대시보드.tsx` (대시보드 요청머니 승인 팝업 내 수신계좌 직접입력 및 현금정산 종료)
  - `docs/04.데이터/01.데이터설계.md` (`USER_BANK_ACCOUNTS`, `LEDGER_ALLOWANCE_MEMBERS` DDL 및 ERD 반영)
  - `docs/01.프로젝트/02-backlog-spec.md` (`BKL-ACC-10` 상세 기능 요건 현행화)
  - `docs/README-docs.md` (문서 변경 이력 인덱스 반영)
- **목적 및 사용자 요구사항 완결**:
  1. **Zero-Friction 계좌 원칙 수립**:
     - 가계부/목표/당번/게임 등 라이프스타일 기능은 계좌 등록 없이도 100% 정상 작동 보장.
     - 금융 강제성을 배제하고, 실제 송금/이체가 필요한 순간에만 계좌를 등록·활용할 수 있도록 설계.
  2. **응원/송금 시 계좌 유무 분기**:
     - **1.1 받는사람 계좌 부재 시**: 실천 이력에서 `[응원 송금 💰]` 버튼을 완전히 없앰(미노출).
     - **1.2 주는사람 계좌 부재 시**: `[응원 송금 (계좌필요) 💰]` 버튼을 비활성화(`disabled`, opacity-70) 처리하고 계좌 등록 필요 툴팁 안내.
  3. **송금 팝업 내 예외 처리 및 듀얼 종료 액션**:
     - **수신 계좌 미등록 시**: 송금 모달 내에서 은행/계좌번호/예금주를 인라인으로 직접 입력할 수 있는 폼 표시.
     - **2.1 이체없이 종료처리 (현금전달 등)**: 실제 은행 이체 없이 직접 현금 지급 후 완료 마감하는 `[이체없이 종료 (현금전달) 💵]` 버튼 신설 (댓글 및 피드에 현금 전달 이력 기록).
  4. **가계부 참여자 1:1 대표계좌 매핑**:
     - 가계부 참여자 관리 모달에서 구성원별 용돈 수령 대상 지정(토글) 및 지급 방식(계좌 송금 vs 현금 직접 지급) 선택 지원.

## 2. 세부 구현 내역

### 2.1. [데이터 모델] 하네스 스토어 풀 및 헬퍼 함수 구축
- **`src/sample/data/accountStorePool.ts`**:
  - `UserBankAccount`: 개별 사용자 복수 계좌 엔티티 (`id`, `userId`, `bankName`, `accountNo`, `accountHolder`, `alias`, `isDefault`, `assignedPurposes`).
  - `LedgerAllowanceMember`: 가계부별 용돈 구성원 엔티티 (`ledgerId`, `memberId`, `memberName`, `isAllowanceTarget`, `paymentMethod`, `representativeAccount`).
  - `localStorage` 기반 동기화 및 헬퍼 함수 (`loadUserBankAccounts`, `saveUserBankAccounts`, `loadLedgerAllowanceMembers`, `saveLedgerAllowanceMembers`, `getMemberAllowanceAccount`, `getCurrentUserDefaultAccount`, `maskAccountNo`).

### 2.2. [SCR-SET-01] 사용자 설정 화면 (계좌 관리 탭 신설)
- **`src/sample/screen/SCR_SET_01_사용자설정.tsx`**:
  - Tab 4(`ACCOUNT`)에 Zero-Friction 가이드 배너 제공 ("계좌를 등록하지 않아도 가계부, 목표, 당번, 게임은 100% 정상 이용할 수 있습니다").
  - 복수 계좌 카드 그리드(대표 뱃지, 별칭, 마스킹 계좌번호, 복사, 용도 태그, 대표 지정, 수정/삭제).
  - 새 계좌 등록/수정 모달 구현.

### 2.3. [SCR-LED-01] 가계부 참여자 설정 모달 (용돈 구성원 & 대표계좌 매핑)
- **`src/components/ledger/modals/LedgerMemberManageModal.tsx`**:
  - 참여자 목록 내 `[용돈설정 💰]` 인라인 아코디언 패널 배치.
  - 용돈 지급 대상 지정 토글, 지급 방식(계좌 송금 vs 현금 직접 지급) 선택 폼 제공.
  - 참여자별 1:1 대표계좌 매핑 및 저장 상태 뱃지(`💰 용돈: 은행 ***` vs `💵 현금 직접 수령`) 실시간 동기화.

### 2.4. [SCR-GOL-02] 모아목표 상세 (응원 송금 & 팝업 고도화)
- **`src/sample/screen/SCR_GOL_02_모아목표상세.tsx`**:
  - 탭 2 실천 이력에서 수신자 계좌 미등록 시 버튼 미노출, 송금자 계좌 미등록 시 버튼 비활성화 적용.
  - `TransferModal` 내 수신자 계좌 직접 입력 폼 및 `[이체없이 종료 (현금전달) 💵]` 버튼 연동.
  - 현금 전달 완료 시 `💵 [현금전달 완료]` 댓글 자동 기장.

### 2.5. [SCR-DSH-01] 로그인 메인 대시보드 (송금 모달 고도화)
- **`src/sample/screen/SCR_DSH_01_로그인메인대시보드.tsx`**:
  - 요청 머니 승인 팝업에서 계좌 미등록 시 인라인 계좌 직접 입력 폼 노출.
  - `[이체없이 종료 (현금전달) 💵]` 클릭 시 현금 전달 완료 마감 및 활동 피드 기장.
