## 2. 핵심 구현 및 개선 내역

### 1) 참가자 이름 입력 필드(`<input>`) 아이콘 상단 배치 및 수정 기능 복원
- **문제점**: 이전 UI 개편 과정에서 사다리 참가자 이름을 현장에서 직접 변경하는 기능이 축소되어 사용자 편의성이 저하됨.
- **해결 내역**:
  - 각 참가자 컬럼 최상단에 이름 수정용 `<input>`을 아바타 아이콘 위에 독립 배치.
  - 클릭 시 텍스트 전체 자동 선택(`e.currentTarget.select()`) 지원으로 빠른 이름 수정 가능.
  - 사다리가 타는 중(`isTracing`)일 때는 입력창을 `disabled` 처리하여 게임 진행 중 상태 왜곡 원천 차단.

### 2) 참가자 선택 시 높이 단차(Stagger) 해결
- **문제점**: 참가자 선택 시 버튼 하단에 `내 자리` 텍스트 레이블이 동적으로 추가되어 해당 열만 아래로 길어지면서 전체 컬럼 간 높이 단차가 발생함.
- **해결 내역**:
  - 하단 텍스트 레이블을 완전히 제거하고, 아바타 아이콘 우상단에 `absolute -top-1.5 -right-1.5` 플로팅 원형 배지(`Check` 아이콘)를 적용.
  - 모든 참가자 컬럼의 아바타 버튼 높이를 `w-10 h-10`으로 일정하게 고정하여 컬럼 간 수평 정렬 일치도 100% 달성.

### 3) '내 자리' 단일 선택(Single-Select) 배타적 점유 보장
- **문제점**: 여러 참가자 아이콘을 연달아 누를 경우 여러 자리가 동시에 '내 자리'로 중복 체크되는 문제 발생.
- **해결 내역**:
  - 참가자 선택 핸들러(`handleToggleClaimSeat`)에서 현재 클라이언트가 점유(`claimedBy === currentTabId`)한 기존 항목을 모두 해제.
  - 가장 마지막에 클릭한 단 1개의 참가자만 '내 자리'로 배타적 체크되도록 단일 선택 규칙을 엄격히 적용.

### 4) 공유 기능 차기 세션 이연 결정
- 백엔드 없는 실시간 동기화(`BroadcastChannel API` + `localStorage storage-event` 듀얼 채널) 기술 검증을 성공적으로 마쳤으며, 사용자 지침에 따라 실제 공유 기능 UI 노출 및 고도화는 차기 세션(`0030`, `BKL-LAD-01`)에서 진행하도록 백로그로 정식 이연 처리함.
