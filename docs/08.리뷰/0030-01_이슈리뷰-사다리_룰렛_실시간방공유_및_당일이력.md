# 이슈 리뷰: [0030-01] 사다리 & 룰렛 실시간 방 공유, 초대 링크 폐기 및 당일 이력 조회 구축

## 1. 개요 및 목적
- **작업 ID**: `[0030-01]`
- **대상 화면**: `SCR-GNT-01` (비로그인 게스트홈 - 즐겨보고 사다리 & 룰렛)
- **핵심 목표**:
  1. 사다리 및 룰렛 게임 타이틀 헤더에 직관적이고 시인성 높은 **실시간 공유 / QR 코드 버튼(`Share2`)** 및 방 코드 뱃지, 동시 접속자 수 표기.
  2. **초대자(방장) 전용 게임 종료 기능**: 방장이 게임을 종료하면 초대 링크를 폐기하고 신규 유입을 완벽 차단.
  3. **폐기된 링크 접속 시 동작 보장**: 신규 게임 참여는 차단되지만, 기존 링크로 접속한 참여자에게 최종 게임 결과(사다리 매칭 결과 또는 룰렛 당첨자)를 즉시 보존·표시.
  4. **당일 공유 게임 이력 보관 및 아코디언 토글**: 당일(오늘 `YYYY-MM-DD`) 이력만 로컬스토리지에 유지하고, 하단에 이력이 1건 이상 존재할 때만 토글 영역을 노출하여 클릭 시 결과 팝업을 즉시 재조회.

## 2. 주요 아키텍처 및 구현 내용

### 2.1 크로스 디바이스 실시간 방 공유 프로토콜
- **방 식별자(Room ID)**: Type-prefixed Crockford Base32 형식(`LAD-XXXXXX`, `ROU-XXXXXX`)으로 충돌을 원천 차단하고 식별성을 보장.
- **하이브리드 동기화 채널**:
  - 동일 브라우저 탭 간: `BroadcastChannel` + `localStorage` 기반 초저지연 동기화.
  - 이기종/크로스 디바이스 간: Node.js Express SSE(Server-Sent Events) 스트림(`GET /api/v1/games/rooms/:roomId/events`) 및 REST 액션 브로드캐스트(`POST /api/v1/games/rooms/:roomId/action`).
- **서버 인메모리 방 상태(`server.ts`)**:
  - `isClosed`: 방 종료 플래그 (true 시 신규 유입 및 조작 차단)
  - `closedAt`: 방 종료 시각
  - `finalResult`: 최종 사다리 결과 맵 또는 룰렛 당첨자 객체 영구 보존
  - 방 등록, 조회, SSE 브로드캐스트 엔드포인트 완비.

### 2.2 타이틀 헤더 영역 공유 버튼 및 게임 종료 컨트롤
- **사다리 플레이존 (`LadderGameZone.tsx`)**:
  - 타이틀 헤더에 `사다리 플레이존`, 방 코드 뱃지(`{roomId}`), 동시 접속자 수 뱃지(`{connectedClients}명`), 상태 뱃지 노출.
  - 방장인 경우: 원클릭 **"🔒 게임 종료"** 버튼 제공 (초대 링크 폐기 및 당일 이력 저장).
  - 공유 버튼: **"실시간 공유 / QR"** 버튼 클릭 시 초대 URL 복사 및 QR 코드 모달 노출.
  - 방 종료 시: 상단에 "🔒 방장이 게임을 종료하여 신규 참여가 마감되었습니다" 배너 표시 및 사다리 타기 버튼 비활성화.
- **룰렛 플레이존 (`RouletteGameZone.tsx`)**:
  - 사다리와 동일한 규격의 타이틀 헤더 바 신설 (`룰렛 플레이존`, 방 코드, 접속자 수, 방장 전용 "🔒 게임 종료" 버튼, "실시간 공유 / QR" 버튼).
  - 마운트 시 서버 방 조회(`GET /api/v1/games/rooms/:roomId`)를 통해 닫힌 방이면 `isRoomClosed = true`로 동결하고 최종 당첨자 결과 모달 자동 팝업.
  - 룰렛 돌리기 버튼 비활성화 (`disabled={isRoomClosed}`).

### 2.3 당일 공유 게임 이력 보관 및 토글 아코디언 (`SCR_GNT_01_비로그인게스트홈.tsx`)
- **데이터 보관 원칙 (`types.ts`)**:
  - `localStorage`의 `moabogo_today_game_history` 키를 단일 진실 공급원(SSOT)으로 사용.
  - `new Date().toISOString().slice(0, 10)` 기반으로 저장 및 로드 시 당일 날짜가 아닌 과거 데이터는 자동 필터링 및 정리(Garbage Collection).
- **조건부 아코디언 토글**:
  - `todayHistory.length > 0`일 때만 메인 게임 영역 하단에 "📋 오늘의 공유 게임 이력 ({todayHistory.length}건)" 아코디언 섹션 노출.
  - 접기/펼치기 토글 기능 및 주기적 자동 갱신(스토리지 이벤트 및 타이머 연동).
- **결과 재조회 팝업 연동**:
  - 이력 카드 클릭 시 당시의 게임 유형에 따라 `LadderResultModal` 또는 `RouletteResultModal`을 즉시 팝업으로 호출하여 당시의 당첨자와 후보군, 텍스트 복사를 완벽하게 재조회.

### 2.4 AI Studio 샌드박스 도메인 연동 및 심플 아이콘 공유 버튼 정돈
- **샌드박스 URL 및 'Page not found' 원인/해결**:
  - `ais-pre-xxxx.run.app` 도메인은 AI Studio 상단의 'Share' 버튼으로 공개 발행(Publish)하기 전까지는 미배포 상태(`Error: Page not found`)가 반환됨.
  - 따라서 실시간 구동 중인 개발 서버(`window.location.origin`) 주소를 기본값으로 안전하게 제공하여 404/Page not found를 원천 방지함.
  - 403 Forbidden 방지 가이드: 시크릿 창(Incognito)에서는 구글 로그인 세션 부재로 403이 발생하므로, 현재 브라우저의 일반 새 탭 또는 다른 일반 창에서 열면 403 없이 즉시 크로스 탭 실시간 동기화가 동작함을 모달에 상세 안내.
- **공유 버튼 심플화 (텍스트 제거 및 아이콘 전담)**:
  - 게스트홈 상단 헤더 및 각 게임존(사다리, 룰렛) 타이틀 바의 공유 버튼에서 텍스트("공유링크 생성", "실시간 공유 / QR")를 제거하고, 정돈된 `Share2` 심플 아이콘 버튼으로 표준화하여 시각적 간결성과 반응형 레이아웃 일관성을 확보함.
