# 이슈 리뷰: [0031-01] 사다리·룰렛 참여자 권한(RBAC) 제약 및 실시간 탭 접속자수 정밀화

## 1. 개요 및 목적
- **작업 ID**: `[0031-01]`
- **대상 화면**: `SCR-GNT-01` (비로그인 게스트홈 - 사다리 및 룰렛 플레이존)
- **핵심 목표**:
  1. **게스트 참여자(Guest) 방 제어 권한(RBAC) 엄격 제한**: 초대 링크로 참여한 게스트가 방의 기본 규칙(참여인원수, 매장메뉴, 당첨인원수, 가중치, 속도 슬라이더, 목표 직접 편집)을 임의 변경하지 못하도록 읽기 전용 및 비활성화 가드레일 구축.
  2. **실시간 섞기 브로드캐스트 전파**: 방장이 사다리 참가자 순서(`SHUFFLE_MEMBERS`), 가로줄(`SHUFFLE_RUNGS`), 목표(`SHUFFLE_GOALS`), 룰렛 항목(`SHUFFLE_ROULETTE_ITEMS`)을 섞었을 때 실시간으로 모든 참여자에게 동기화.
  3. **고유 탭 식별자(tabId) 기반 실시간 접속자 수(Presence) 정밀 집계**: 중복 카운팅을 방지하고 `connectedTabs: Map<string, express.Response>` 구조로 정밀화.
  4. **브라우저 탭 닫기/이탈 시 실시간 자리 자동 해제**: 탭 종료 또는 이탈 시 `beforeunload` 비콘(`navigator.sendBeacon`) 및 SSE 종료 이벤트를 통해 점유했던 자리(`claimedBy`)를 0ms 즉각 자동 해제 및 전원 브로드캐스트.
  5. **다중 환경 GitHub 토큰 자동 감지 규약**: AI Studio, Antigravity CLI, Antigravity IDE `.env` 환경별 권한 오류 원천 차단 (`AGENTS.md`).

## 2. 주요 아키텍처 및 구현 내용

### 2.1 게스트 참여자(Guest) RBAC 가드레일
- **사다리 플레이존 (`LadderGameZone.tsx`)**:
  - `isGuest = isRoomJoined && !isRoomHost` 식별자 바인딩.
  - 상단 매장 연동 바: 게스트 시 `disabled={true}`, 자물쇠 아이콘 및 `(방장 전용)` 배지 표기.
  - 당첨 인원수 슬라이더 (`ElmRng01`): 게스트 시 비활성화 및 `<Lock /> 방장 제어` 뱃지 노출.
  - 가중치 ON/OFF 토글 및 속도 선택 바: 게스트 조작 비활성화.
  - 사다리 목표 직접 클릭 편집 (`handleGoalColClick`): 게스트 차단 및 안내 토스트 발행.
  - 참가자 아바타/메뉴 선택 (`handleOpenStoreMenuPicker`): 본인이 점유한 자리(`claimedBy === currentTabId`) 한정 허용.
  - 실행 바: 게스트에게는 실행 버튼 대신 `🔒 방장이 사다리를 시작하면 모든 화면에서 함께 진행됩니다` 보라색 실시간 상태 배너 노출.
- **룰렛 플레이존 (`RouletteGameZone.tsx`)**:
  - `isGuest = !!roomId && !isRoomHost` 식별자 바인딩.
  - 항목 수 슬라이더 (`ElmRng01`), 가중치 토글, 추천 프리셋 원터치 버튼: 게스트 비활성화.
  - 항목 & 프리셋 설정 모달: 게스트 접근 차단 (`항목 설정 (방장 전용)`).
  - 룰렛 SVG 센터 클릭 및 메인 실행 버튼: 게스트 조작 차단 및 `🎮 방장이 룰렛을 돌리면 모든 화면에서 함께 회전합니다` 안내 배너 노출.
- **공통 게스트홈 (`SCR_GNT_01_비로그인게스트홈.tsx`)**:
  - 상단 공통 참여 인원 슬라이더: `isGuestInRoom` 판별 시 `참여 인원수 (방장 제어 · 읽기 전용)`으로 비활성화.

### 2.2 실시간 섞기 액션 브로드캐스트
- **사다리 참가자 섞기 (`handleShuffleMembers`)**:
  - 퀵 액션 바에 `참가자 섞기` 버튼 신설 (`Users` 아이콘).
  - 방장 클릭 시 참가자 배열을 무작위 셔플하고 `SHUFFLE_MEMBERS` 메시지 전파 (`channelRef.current.send`).
  - 참여자 화면에서 실시간으로 사다리 출발점 참가자 순서 동기화.
- **룰렛 항목 섞기 (`handleShuffleRouletteItems`)**:
  - 룰렛 항목 바에 `항목 섞기` 버튼 신설 (`Dices` 아이콘).
  - 방장 클릭 시 항목 순서를 셔플하고 `SHUFFLE_ROULETTE_ITEMS` 액션 실시간 브로드캐스트.

### 2.3 탭 식별자 Presence 및 탭 이탈 자동 자리 해제
- **서버 인메모리 구조 혁신 (`server.ts`)**:
  - `connectedClients: Set<express.Response>` ➔ `connectedTabs: Map<string, express.Response>`로 전면 리팩토링.
  - 동일 탭 재접속 시 이전 스트림을 안전하게 종료하고 교체하여 중복 계상 원천 차단.
- **탭 닫기/이탈 시 자동 자리 해제 파이프라인**:
  - SSE 스트림 `req.on('close')` 및 신규 엔드포인트 `POST /api/v1/games/rooms/:roomId/leave` 구축.
  - 해당 탭이 점유하고 있던 자리(`m.claimedBy === tabId`)를 `claimedBy: undefined`로 즉시 초기화.
  - 갱신된 멤버 목록 및 잔여 접속자 수를 모든 클라이언트에 브로드캐스트하여 다른 사용자가 즉시 해당 자리를 선택할 수 있도록 보장.
  - 클라이언트 채널(`ladderSyncChannel.ts`, `rouletteSyncChannel.ts`)의 `beforeunload` 리스너에서 `navigator.sendBeacon` 및 BroadcastChannel 연동으로 신뢰도 100% 달성.
