## 1. 구현 개요

본 태스크에서는 비로그인 게스트홈의 실시간 사다리 게임공유 환경에서 참가자 전원이 동일한 사다리 진행을 체감할 수 있도록 **마일스톤 기반 동기화**, **스마트 앵커 카메라 추적 뷰포트**, **순차 주자 스무스 패닝**, **결과 모달 동시 오픈**을 구현하였습니다.

---

## 2. 주요 변경 사항

### 2-1. 사다리 마일스톤 채널 액션 신설 및 서버 릴레이 (`ladderSyncChannel.ts`, `server.ts`)
- **`LADDER_PROCEED_NEXT`**: 방장이 주자 도착 팝업에서 "다음 주자 출발" 클릭 시 `nextMemberIndex`를 실시간 브로드캐스트하여 참가자 전원의 화면에서 다음 주자가 동시에 출발하도록 동기화.
- **`LADDER_COMPLETE`**: 모든 주자 완주 시 최종 결과 맵(`results`)을 브로드캐스트하여 참가자 전원의 화면에서 결과 모달을 동시 오픈.
- **`server.ts`**:
  - `HOST_ONLY_ACTIONS`에 `LADDER_PROCEED_NEXT`, `LADDER_COMPLETE`를 등록하여 방장 권한 토큰을 검증.
  - `LADDER_COMPLETE` 액션 수신 시 서버 룸 상태(`room.data.ladderResult`)를 갱신하여 늦게 접속한 유저나 새로고침 유저에게도 최신 결과를 보존.

### 2-2. 스마트 앵커 카메라 추적 & 0.5 step(52px) 안전 여백 확보 (`LadderGameZone.tsx`)
- **`ensureTracerVisible` 개선**:
  - `halfColPadding = LADDER_COL_WIDTH * 0.5` (52px)를 계산하여, 사다리 앵커(마커)가 뷰포트 좌우 벽에 닿기 전에 항상 최소 반 칸 이상의 공간을 선제 확보.
  - 트레이서가 뷰포트 좌/우측 경계 52px 이내로 진입할 경우 `targetScroll`을 강제로 클램핑하여 시야 가림을 원천 방어.
  - 선제적 진행 방향 예측(`forwardMargin`)과 스프링 감쇠(Easing factor 0.45)를 조합하여 부드럽고 끊김 없는 트레이싱 제공.

### 2-3. 순차 주자 스무스 패닝 (Smooth Panning) & 출발 연계 (`LadderGameZone.tsx`)
- 한 주자의 이동이 끝나면 다음 참가자의 시작 위치 기둥(`startPt.x`)으로 즉각 튀지 않고 부드러운 패닝(`isPanning = true`, 감쇠 계수 0.25)을 적용.
- 이전 마커 위치와 트레일 선을 완전히 소거한 후 새 주자의 최상단 출발 지점에서 정밀하게 출발.

### 2-4. 도착 팝업 게스트 대기 UI & 게임 완료 팝업 동기화 (`LadderModals.tsx`, `LadderGameZone.tsx`)
- **`LadderArrivalModal`**:
  - `isGuest={true}`일 경우 출발 버튼 대신 "방장이 다음 주자를 출발시킵니다 (대기 중...)" 안내 핑 배지를 노출하여 게스트의 조작 혼선을 방지.
  - 방장이 다음 주자를 출발시키면 게스트 모달이 닫히며 즉시 다음 주자 사다리 타기가 동시에 진행.
- **결과 모달 동기화**:
  - 마지막 주자 골인 후 `LADDER_COMPLETE` 수신 시 참가자 화면에서도 `setIsResultModalOpen(true)`를 호출하여 최종 매칭 결과 전폭 팝업 모달이 자동으로 오픈.

### 2-5. 아키텍처 문서 현행화 (`docs/02.아키텍처/03-실시간동기화-기술검토서.md`)
- §6 "사다리 스마트 카메라 뷰포트 & 마일스톤 실시간 동기화 (v2.1)" 섹션을 신설하고 안전 여백, 스무스 패닝, 마일스톤 릴레이, 게스트 대기 UI 정책을 명세.
