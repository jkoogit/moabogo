# [0032-03] 사다리 게임공유 보안 및 실시간 상호작용 결함 보완 검증 리뷰

## 1. 개요 및 목적
- **태스크 ID**: `[0032-03]`
- **태스크명**: 사다리 게임공유 보안 및 실시간 상호작용 결함 보완
- **목적**:
  1. 링크 참가자(게스트) 화면에서 초대/공유 버튼 비활성화 및 실시간 동기화 정합성 확보
  2. 링크 참가자의 참가자 섞기(`SHUFFLE_MEMBERS`) 실시간 브로드캐스트 및 서버 권한 허용
  3. 사다리 1번 주자 완료 후 도착 팝업 카운트다운(3초) 만료 또는 클릭 시 다음 주자로 끊김 없이 연속 출발 보장
  4. 초대자가 게임 종료 시 로컬 개인 게임 모드로 완전 복귀(실행 버튼 복구) 및 링크 참가자에게 친절한 종료 안내 팝업 제공

---

## 2. 주요 수정 내역

### 1) [3-a, 3-b] 연속 플레이 멈춤 해결 & 게스트 앵커 정지 방지 (최우선 과제)
- **`src/components/game/ladder/LadderModals.tsx` (`LadderArrivalModal`)**:
  - `onProceed` 호출 시 `countdown` 만료 또는 수동 클릭 시 다음 참가자 인덱스를 안전하게 계산하여 진행.
  - 카운트다운 자동 진행은 방장(`!isGuest`) 화면에서만 구동하여 다중 클라이언트 간 타이머 경합 및 중복 출발 방지.
  - 모달 텍스트에 `(N초 뒤 자동)` 표기하여 시각적 피드백 제공.
- **`src/components/game/ladder/LadderGameZone.tsx` (`handleProceedAfterArrival`)**:
  - `targetIdx`가 확실하게 전달되어 `arrivalPopup` 클로저 상태에 의존하지 않고 즉시 다음 주자 앵커 애니메이션 구동.
  - `stepIntervalRef.current` 이전 타이머 클리어 후 확실하게 인터벌 재등록.
  - `LADDER_PROCEED_NEXT` 브로드캐스트 시 `speed: ladderSpeed`를 전달하여 게스트 화면에서도 동일한 속도로 앵커 이동 동기화.

### 2) [1-a, 1-b] 게임 종료 후 URL 초기화 및 로컬 개인 게임 모드 완전 복귀
- **`src/components/game/ladder/LadderGameZone.tsx` (`handleCloseRoom`)**:
  - 방장이 게임 종료 클릭 시 `setRoomId(null)`, `setHostToken(null)`, `setIsRoomHost(false)`, `setIsRoomClosed(false)`, `setConnectedClients(1)`를 순차 실행.
  - URL 파라미터(`room`, `host`)를 삭제하여 로컬 모드로 전환.
  - `isRoomClosed` 배너가 사라지고 하단 메인 액션 버튼에 로컬 게임 실행 버튼(`[사다리 타기]`, `[즉시 결과]`)이 즉시 복구.
- **`src/sample/screen/SCR_GNT_01_비로그인게스트홈.tsx`**:
  - `isGuestInRoom` 판정 시 `sessionStorage`의 `moabogo_host_token_${r}` 유무를 안전하게 확인하고, 방 종료 및 이탈 시 상위 상태도 동기화.

### 3) [2] 링크 참가자의 참가자 섞기(`SHUFFLE_MEMBERS`) 동기화 완결
- **`server.ts`**:
  - `HOST_ONLY_ACTIONS`에서 `SHUFFLE_MEMBERS`를 제외하여 게스트가 섞기를 실행하더라도 403 Forbidden 없이 정상 SSE 릴레이 처리.
  - 서버 측 `room.data.members` 메모리 상태도 동기화.
- **`src/components/game/ladder/LadderGameZone.tsx`**:
  - 완전 교란(Derangement) 셔플 적용으로 고정 위치 없이 전체 재배치.
  - 섞기 완료 후 `membersRef.current = shuffled` 갱신 및 `channelRef.current.send({ type: 'SHUFFLE_MEMBERS', members: shuffled })` 발행.
  - 상대방 화면에서 `case 'SHUFFLE_MEMBERS'` 수신 시 즉시 재렌더링.

### 4) [4] 방장 게임 종료 시 링크 참가자 인터랙션 안내 팝업 제공
- **`src/components/game/ladder/LadderGameZone.tsx`**:
  - 방 종료 브로드캐스트(`CLOSE_ROOM`) 수신 시 게스트 화면에 `isGuestCloseNoticeOpen` 모달 노출.
  - 최종 결과 열람 버튼 및 `[참여종료 및 혼자 게임 계속하기]` 버튼 제공으로 자연스러운 로컬 모드 전이 지원.
