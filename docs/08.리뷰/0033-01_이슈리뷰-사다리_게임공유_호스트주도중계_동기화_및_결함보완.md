# [0033-01] 사다리 게임공유 결함 전면 보정: 호스트 주도 이벤트 중계 및 실시간 동기화 리뷰

## 1. 개요 및 목적
- **태스크 ID**: `[0033-01]`
- **태스크명**: 사다리 게임공유 결함 전면 보정 (연속 플레이 자동화, 호스트 주도 이벤트 중계, hostToken Race Condition 차단, 링크 참가자 화면 중계 및 게임종료 모달 동기화 완결)
- **목적**:
  1. 다음 참가자 연속 플레이 멈춤 해결 (참가자 1 도착 후 카운트다운 만료 시 참가자 2, 3... 전원 완주까지 연속 자동 주행)
  2. `GET /events`와 `POST /rooms` 간의 Race Condition으로 인한 `hostToken` 증발 및 403 Forbidden 사일런트 차단 원천 해결
  3. 실시간 동기화 채널 `useEffect`의 의존성 폭발 제거 및 채널 영구 연결 유지
  4. 링크 참가자(게스트) 화면에 방장의 게임 플레이 화면 실시간 중계 및 도착 팝업/목표 담당자 매핑 100% 동기화 (호스트 주도 이벤트 중계 아키텍처)
  5. 방장 게임 종료 시 게스트 화면에 종료 알림 팝업(`isGuestCloseNoticeOpen`) 즉각 표시 및 방장 화면의 로컬 모드 완전 복구

## 2. 주요 수정 내역

### 1) 연속 플레이 자동 주행 엔진 보완 (`LadderModals.tsx`, `LadderGameZone.tsx`)
- **`LadderArrivalModal` 카운트다운 타이머 클로저 해결**:
  - `onProceedRef`, `arrivalDataRef`를 도입하여 타이머 만료 시 `nextMemberIndex`를 명시적으로 전달함으로써 참가자 1 도착 후 참가자 2, 3... 전원 완주까지 멈춤 없는 자동 주행 완결.
- **주자별 카메라 부드러운 패닝**:
  - 다음 주자 시작 시 선제 화면 이동 후 250ms 여유를 두고 앵커 스텝 이동 시작.

### 2) `server.ts` 방장 토큰 거버넌스 보정 및 Race Condition 원천 차단
- **토큰 보장 반환**:
  - `GET /events` 요청이 `POST /rooms` 등록보다 먼저 인입되어 방이 즉석 생성되더라도, 이후 정식 `POST /rooms` 호출 시 `room.hostToken`을 온전히 방장 클라이언트에 100% 보장 반환하도록 수정.
- **방장 전용 액션(`HOST_ONLY_ACTIONS`) 검증 강화**:
  - `PLAY_LADDER`, `LADDER_RUNNER_ARRIVED`, `LADDER_PROCEED_NEXT`, `LADDER_COMPLETE`, `CLOSE_ROOM` 등 방장 전용 액션 검증 시 `headers['x-host-token']`, `body.hostToken`, `query.hostToken` 다층 fallback 지원 및 403 차단 시 상세 식별 로그 출력.
- **방 정보 조회 API 응답 일치**:
  - `GET /api/v1/games/rooms/:roomId` 응답에 최상위 필드와 `room` 래퍼를 동시 제공하여 클라이언트의 페이지 새로고침 시 방 상태 복원 보장.

### 3) `ladderSyncChannel.ts` 에러 피드백 및 토큰 페이로드 강화
- 액션 디스패치 시 헤더와 바디에 `hostToken` 동시 전달.
- HTTP 403 Forbidden 등 비정상 응답 시 `console.error`로 상세 에러 출력.

### 4) `LadderGameZone.tsx` 호스트 주도 이벤트 중계(Host-Authoritative Relay) 개편
- **채널 라이프사이클 분리**:
  - 채널 연결 `useEffect` 의존성 배열을 `[roomId, isRoomHost, currentTabId, showToast]`로 최소화하여 가변 상태 변경 시에도 채널이 절대 끊어지지 않도록 영구 유지.
  - 가변 상태는 `useRef`(`membersRef`, `ladderGoalsRef`, `ladderSeedRef`, `revealedGoalsRef`, `revealedGoalColsRef`, `ladderResultRef`, `hostTokenRef`)를 통해 실시간 조회.
- **`LADDER_RUNNER_ARRIVED` 신규 이벤트 방송**:
  - 방장 화면에서 각 주자가 목표에 도달하는 즉시 결과와 매핑 정보를 방송.
  - 게스트는 수신 즉시 로컬 주행 타이머를 정리하고 골인 지점으로 스냅하며, 방장과 정확히 일치하는 데이터로 도착 팝업 동시 오픈.
- **`LADDER_PROCEED_NEXT` 및 `LADDER_COMPLETE` 완결**:
  - 방장 카운트다운 만료 시 게스트 팝업 닫힘 및 다음 주자 동시 주행.
  - 전원 완주 시 최종 결과 및 목표-담당자 매핑 일원화 동기화.
- **3대 안전장치(Fail-Safe) 적용**:
  - 게스트 팝업에 5초 타임아웃 락 해제 제공 (`[신호 지연 시 직접 다음 주자로 넘어가기]`).
  - 게임 종료(`handleCloseRoom`) 시 원격 전송 후 로컬 개인 모드로 전환.
