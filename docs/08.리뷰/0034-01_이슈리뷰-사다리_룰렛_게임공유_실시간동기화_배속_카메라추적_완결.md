# [0034-01] 사다리·룰렛 게임공유 SSE 무한 재연결 차단, 주행/배속/즉시결과 실시간 동기화 및 60fps 카메라 추적 보정 리뷰

## 1. 개요 및 목적
- **세션 / 태스크 ID**: `[0034]` / `[0034-01]`
- **태스크명**: 사다리·룰렛 게임공유 SSE 무한 재연결 차단, 주행/배속/즉시결과 실시간 동기화, 60fps 카메라 추적 보정 및 종료 후 개인모드 전환 완결
- **목적**:
  1. `SCR_GNT_01` `showToast` 콜백 안정화 및 공유 종료/이탈 시 개인 플레이 모드 완벽 복구
  2. `LadderGameZone`·`RouletteGameZone` 실시간 채널 `useEffect` 의존성 격리(Ref 기반 동기화)로 SSE 무한 재연결 원천 차단
  3. 룰렛 호스트 주도 중계(`SPIN_ROULETTE` ➔ `ROULETTE_SPIN_COMPLETE`), 사다리 주행·배속(`UPDATE_SPEED`)·`전체 즉시 결과`(`PLAY_LADDER skipTrace: true`) 원자적 실시간 동기화
  4. `requestAnimationFrame` 기반 60/120fps 연속 보간 주행 및 지수 감쇠 카메라 추적으로 모바일·PC 크로스 디바이스 끊김/이탈 제거
  5. 방장 게임 종료(`CLOSE_ROOM`) 시 게스트 종료 안내 모달 표시 및 개인 플레이 모드 전환 완결
  6. Vite HMR Fast Refresh 호환성을 위한 컴포넌트-유틸리티 분리(`BKL-LAD-04`)

## 2. 주요 수정 내역

### 1) SSE 무한 재연결 차단 및 개인 플레이 모드 복구 (`SCR_GNT_01`, `RouletteGameZone.tsx`, `LadderGameZone.tsx`)
- **`SCR_GNT_01_비로그인게스트홈.tsx`**:
  - `showToast`를 `useCallback`으로 고정하고, `onRoomModeChange`·`onRegisterLeaveHandler` 연계를 통해 방 종료/퇴장 시 게스트 상태(`isGuestInRoom`)를 즉시 해제하여 상단 슬라이더·공유 제어를 개인 플레이 모드로 완벽 복구.
- **Ref 기반 채널 라이프사이클 격리**:
  - `RouletteGameZone.tsx` 및 `LadderGameZone.tsx`의 `useEffect` 의존성에서 가변 상태(`members`, `rouletteItems`, `ladderGoals`, `ladderSpeed` 등)를 제거하고 최신 Ref로 참조하도록 전환하여 `EventSource` 재연결 루프(기존 242회 반복) 원천 제거.

### 2) 룰렛 호스트 주도 중계 및 게스트 편집 잠금 (`RouletteGameZone.tsx`)
- 방장이 `SPIN_ROULETTE` 및 최종 authoritative 결과 `ROULETTE_SPIN_COMPLETE`(당첨자·항목·제외목록 포함)를 브로드캐스트하고, 모달 내 `즉시 결과` 실행 시에도 동일하게 전파.
- 게스트는 공유 버튼, 아이콘 피커, 항목명(`readOnly={isGuest}`), 가중치 증감(`disabled={isGuest}`)을 잠금 처리하며, 방 종료(`CLOSE_ROOM`) 시 종료 안내 모달(`isGuestCloseNoticeOpen`)에서 결과 확인 또는 `[참여종료 및 혼자 게임 계속하기]` 선택 가능.

### 3) `전체 즉시 결과` 원자적 동기화 및 배속(`UPDATE_SPEED`) 실시간 동기화 (`LadderGameZone.tsx`, `ladderSyncChannel.ts`, `server.ts`)
- **원자적 즉시결과 동기화**:
  - 기존 `SHUFFLE_RUNGS` + `PLAY_LADDER` 이중 비동기 POST로 인한 HTTP 레이스 및 게스트 결과 초기화(`setLadderResult(null)`) 문제를 제거하고, 사전 계산된 `results`, `revealedGoals`, `revealedGoalCols`를 단일 `PLAY_LADDER (skipTrace: true)` 액션으로 전송하며 `server.ts`의 `room.data.ladderResult`에 영속화.
  - 지연 도착한 `LADDER_RUNNER_ARRIVED` 패킷이 확정 결과를 덮어쓰지 않도록 `ladderResultRef.current !== null` 가드 추가.
- **초대자 배속 변경 실시간 전파 (`UPDATE_SPEED`)**:
  - `LadderSyncMessage`에 `UPDATE_SPEED`를 신설하고 `server.ts`의 `HOST_ONLY_ACTIONS` 검증 및 `room.data.ladderSpeed` 영속화 적용(`PLAY_LADDER`, `LADDER_PROCEED_NEXT` 포함).
  - 게임 시작 전·주행 중 어느 시점에 방장이 배속(`0.5x ~ 1.5x`)을 바꿔도 게스트 UI와 주행 루프가 즉시 동기화되며 새로고침 후에도 유지.

### 4) 60/120fps 연속 보간 주행 및 지수 감쇠 카메라 추적 (`ladderEngine.ts`, `LadderGameZone.tsx`, `LadderViewerSvg.tsx`)
- **원인 해결**:
  - CSS `scroll-smooth` 클래스가 매 틱 `scrollLeft` 할당 시 브라우저 easing을 초기화해 지연을 유발하던 문제 제거.
  - `setInterval(13~40ms)` + `6px` 정수 격자 점프 대신 `buildPolylineCurve` / `samplePolylineAtDistance` 기반 `requestAnimationFrame` 호 길이 연속 보간(`300 * activeSpeed * dt`) 적용 및 `polyline` 정점을 꼭짓점 위주(~10~25개)로 경량화.
  - 부동소수점 스크롤 누적기(`cameraScrollRef`) + 지수 감쇠 추종(`1 - Math.exp(-k * dt)`) + 부드러운 방향 시선 오프셋(`cameraLookAheadRef`) + 출발 열 220ms ease-out 팬 + 2차 안전 여백 하드 클램핑을 적용해 모든 배속에서 끊김과 뷰포트 이탈 제거.

### 5) Vite Fast Refresh 호환성 분리 (`BKL-LAD-04`)
- `LadderModals.tsx` 내 비-컴포넌트 헬퍼(`getStoreMenuEmoji`)를 `ladderEngine.ts`로 분리하여 `src/components/game/` 하위 `.tsx` 파일의 순수 React 컴포넌트 export 원칙 준수 및 `docs/01.프로젝트/02-backlog-spec.md` 현행화.

## 3. 정적 검증 및 Playwright 듀얼 브라우저 E2E 결과

   - `lint_applet` (`tsc --noEmit`): 오류 `0`건
2. **Playwright 듀얼 브라우저 E2E (Host PC `1280×900` + Guest Mobile `390×844`)**:
   - **연결 안정성**: SSE 연결 `hostSse: 1`, `guestSse: 1`, `403: 0`, 콘솔 에러 `0`건
