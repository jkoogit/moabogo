# [0035-01] 사다리·룰렛 게임공유 전 설정 실시간 동기화 및 룰렛 중앙버튼 연속회전 완결 리뷰

## 1. 개요 및 목적
- **세션 / 태스크 ID**: `[0035]` / `[0035-01]`
- **태스크명**: 사다리·룰렛 게임공유 전 설정 실시간 동기화 및 룰렛 중앙버튼 연속회전 보완 완결
- **목적**:
  1. 룰렛판 중앙 버튼(SPIN/RESTART) 회전 중 클릭 차단 가드를 해제하고, 클릭 시마다 최소 4바퀴 이상 즉시 연속 회전하도록 개편
  2. 룰렛 중앙 버튼을 회전하는 SVG 휠 내부에서 SVG 바깥 z-20 고정 오버레이로 전환하여 회전 중 텍스트 수평 유지 및 클릭/터치 이벤트 100% 감지 보장
  3. 룰렛 항목 편집(항목 수, 항목명, 가중치, 아이콘, 항목 추가/삭제) 및 설정 토글(가중치 모드, 당첨자 제외 모드) 방장 조작 전수를 원격 참여자에게 실시간 브로드캐스트
  4. 룰렛 모달 게스트 읽기 전용 UI Guard 적용 (항목 설정 모달 잠금 배너 및 추가/삭제/수정 비활성화, 결과 모달 방장 주도 안내 배너)
  5. 사다리 목표 직접 편집(`handleSaveGoal`), 당첨 인원수(`winnerCount`), 매장 연동(`selectedStore`), 가중치 토글(`useLadderWeight`) 변경 실시간 브로드캐스트 및 서버 영속화 완결
  6. 대규모 인프라·보안 과제인 `BKL-LAD-03`(RDBMS 세션/분산 락/CSPRNG) 백로그 분기 상태 현행화

---

## 2. 주요 아키텍처 및 구현 성과

### 2.1 룰렛판 중앙 버튼 연속 회전 및 SVG 외부 고정 허브 UI 고도화
- **회전 중 클릭 차단 가드 해제 (`RouletteGameZone.tsx`)**:
  - 기존 567라인의 `if (isSpinningRef.current && broadcast) return;`으로 인해 회전 중 중앙 버튼을 다시 누르면 요청이 무시되던 결함을 제거.
  - 회전 중 중앙 버튼 클릭 시 `clearSpinTimer()`로 이전 스핀 완료 타이머를 취소하고, 현재 각도(`rouletteRotationRef.current`) 기준으로 새로운 타겟 각도(`nextRotation`)를 계산하여 즉시 연속 회전하도록 처리.
  - `SPIN_ROULETTE` 브로드캐스트가 게스트들에게도 연속 전송되어, 다자간 동시 접속 환경에서도 모든 브라우저가 끊김 없이 즉시 새 각도로 함께 연속 회전.
- **SVG 휠 외부 고정 허브 오버레이 전환 (`RouletteWheelSvg.tsx`)**:
  - 중심 원 버튼을 SVG 바깥의 `absolute inset-0 m-auto z-20` 고정 레이어로 전환하여, 룰렛이 회전하는 동안에도 SPIN/RESTART 텍스트가 항상 수평 정방향으로 선명하게 유지되며 터치/클릭 이벤트가 0ms 즉시 100% 감지되도록 개선.

### 2.2 룰렛 항목 및 설정 변경 전수 실시간 브로드캐스트
- **항목 편집 전 핸들러 브로드캐스트 (`RouletteGameZone.tsx`)**:
  - `broadcastRouletteItems` 헬퍼 함수를 통해 다음 항목 조작 시 즉시 `SYNC_ROULETTE_ITEMS` 액션을 방장 권한으로 전송:
    1. `handleUpdateRouletteItemCount` (항목 수 +/- 변경)
    2. `handleUpdateItemName` (항목명 텍스트 인라인/칩 편집)
    3. `handleUpdateItemWeight` (항목별 가중치 +/- 조작)
    4. `handleSelectIcon` (항목 이모지 아이콘 변경)
    5. `handleAddNewItem` (새 커스텀 항목 추가)
    6. `handleRemoveItem` (모달 내 항목 삭제)
- **룰렛 설정 토글 동기화 (`rouletteSyncChannel.ts`, `server.ts`, `RouletteGameZone.tsx`)**:
  - `UPDATE_ROULETTE_CONFIG` 액션 신설 및 `server.ts`의 `HOST_ONLY_ACTIONS` 검증 등록.
  - 가중치 모드 토글(`useRouletteWeight`) 및 당첨자 제외 모드 토글(`excludeWinnerMode`) 시 참여자에게 실시간 전파 및 서버 영속화(`room.data`).
  - `server.ts`에서 `ROULETTE_SYNC_STATE` 수신 및 `SYNC_ROULETTE_ITEMS`의 `presetTitle` 영속화 보강.

### 2.3 룰렛 모달 게스트 읽기 전용 잠금(UI Guard)
- **`RouletteItemSettingModal`**:
  - `isGuest` 프로퍼티 전달을 통해 참여자 접속 시 잠금 안내 배너 노출, 새 항목 추가 폼 숨김, 가중치 +/- 및 삭제 휴지통 버튼 비활성화.
- **`RouletteResultModal`**:
  - 게스트에게는 `재실행` / `즉시결과` 조작 버튼 대신 "🎮 방장이 다시 돌리면 결과가 모든 화면에 자동 반영됩니다" 안내 배너를 노출하여 방장 주도 중계 질서 확립.

### 2.4 사다리게임 실시간 설정 동기화 누락 지점 보강
- **목표 직접 편집 실시간 전파 (`LadderGameZone.tsx`)**:
  - `handleSaveGoal` 실행 시 `SHUFFLE_GOALS` 액션을 즉시 전송하여, 방장이 특정 기둥 목표를 개별 편집하면 참여자 화면에도 실시간으로 목표가 즉시 반영됨.
- **당첨 인원수(`winnerCount`) 동기화 (`ladderSyncChannel.ts`, `server.ts`, `LadderGameZone.tsx`)**:
  - `UPDATE_WINNER_COUNT` 액션을 신설하여 방장이 슬라이더로 당첨 인원수를 변경할 때 재계산된 기본 목표(`goals`)와 함께 참여자에게 즉시 브로드캐스트 및 서버 영속화.
- **매장 연동(`selectedStore`) 및 가중치 토글(`useLadderWeight`) 동기화**:
  - `UPDATE_STORE`, `UPDATE_LADDER_WEIGHT` 액션을 신설하여 매장 선택/해제 및 가중치 ON/OFF가 참여자 화면에 실시간 동기화.
