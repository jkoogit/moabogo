# [0035-02] 게임공유 팝업 코드입력 모드 분리, 가중치/메뉴결과 동기화 및 사다리-룰렛 통합컨텐츠 동기화 완결 리뷰

## 1. 개요 및 목적
- **세션 / 태스크 ID**: `[0035]` / `[0035-02]`
- **태스크명**: 게임공유 팝업 코드입력 모드 분리, 중복버튼 삭제, 가중치/메뉴결과 동기화 및 사다리-룰렛 통합컨텐츠 동기화 완결
- **수행 목적**:
  1. **게임공유 팝업 모드 분리**: `[📱 공유 게시 · 관리]`와 `[🔑 방 코드로 참여]` 탭 모드를 명확히 분리하여, 링크 없이 6자리 방 코드만으로도 즉시 입장 가능하도록 개편.
  2. **새 방 입장 시 이전 방 자동 퇴장 및 인원수 즉시 차감**: 기존 방에 참여 중인 상태에서 새 방 입장 시 기존 연결을 정리하고 서버 인원수를 차감하여 고스트 접속자 방지.
  3. **중복 UI 요소 및 버튼 정리**: 사다리/룰렛 헤더 및 영역 내 중복 배치되었던 공유 버튼 말끔히 제거.
  4. **결과 공유 정보 강화**: 공유 결과 카드 및 결과 모달에 선택한 매장 메뉴명, 금액(₩원), 고유 이모지 아이콘을 포함하고, 2열 카드 그리드에서 줄바꿈 시에도 동일 라인 박스 높이 일치 유지.
  5. **사다리 ↔ 룰렛 게임 컨텐츠 전역 통합 동기화**:
     - 개별 게임 단위 공유에서 '통합 게임 플랫폼'으로 확대하여, 방장이 사다리/룰렛 화면을 이동하면 참여자 화면도 동일하게 동기화 이동.
     - 링크 참가자는 게임 탭(`SPLIT`, `LADDER`, `ROULETTE`) 이동을 차단(방장 주도).
     - 사다리 섞기 이벤트 시 배열(`customLadderRungs`) 자체를 직접 전송/동기화하여 싱크 불일치 원천 차단.
     - 매장 변경 시 참여자 화면의 선택 메뉴 즉시 초기화.
  6. **가중치 정책 3대 개선 완결**:
     - 사다리 및 룰렛 기본 가중치 초기값을 **`10`**으로 상향 및 증감 스텝 정수화.
     - 가중치 스위치를 끄면(OFF) 모든 참가자/항목의 가중치를 즉시 **`10`**으로 일괄 리셋 & 브로드캐스트.
     - 가중치 `0`에서 감소 클릭 시 수치는 `0`으로 고정 유지하고 나머지 항목들이 현재 가중치 비율에 비례하여 증가하는 풍선효과(Balloon Effect) 구현.
     - 회전판(룰렛 휠)에서 가중치 0 항목은 슬라이스 각도 0도(제외) 및 당첨 확률 0% 완전 배제.

## 2. 주요 아키텍처 및 구현 성과

### 2.1 게임공유 팝업 코드입력 모드 분리 및 자동 퇴장 (`LadderModals.tsx`)
- **2-Way 탭 인터페이스 분리**:
  - `[📱 공유 게시 · 관리]` 탭: 방장이 QR 코드, 초대 URL, 6자리 방 코드를 복사하고 참가자 현황 및 방 관리를 수행.
  - `[🔑 방 코드로 참여]` 탭: 영문 대문자 6자리 입력 폼과 `[입장하기]` 버튼을 제공하여, 별도 링크 전달 없이도 방 코드 직접 입력으로 즉시 방 참여 가능.
- **이전 방 자동 퇴장 및 인원수 차감 연동**:
  - 새 방 입장 시 `onJoinRoom` 핸들러에서 기존 연결된 방이 있는 경우 `channelRef.current.close()` 및 서버 `/api/v1/games/rooms/:id/leave`를 선행 호출하여 인원수를 정상 차감.

### 2.2 결과 공유 카드 높이 일치 및 메뉴/금액 무손실 렌더링 (`gameResultCardCanvas.ts`, `LadderModals.tsx`)
- **2열 박스 높이 일치 엔진 (`gameResultCardCanvas.ts`)**:
  - 행(Row) 단위로 왼쪽/오른쪽 참가자의 메뉴명 줄바꿈 라인 수를 사전 계산하여 `max(lines1, lines2)`를 공통 높이로 산출.
  - 긴 메뉴명이 줄바꿈되어도 카드 내 박스 하단 경계선이 완벽한 수평을 유지하도록 보정.
- **결과 모달 메뉴/가격/아이콘 전수 노출 (`LadderModals.tsx`)**:
  - 당첨자 및 전체 참가자 리스트에 선택 매장의 전용 메뉴 이모지 아이콘, 메뉴명, 금액(`₩XX,XXX원`)을 무손실 표기.

### 2.3 사다리 ↔ 룰렛 통합 플랫폼 화면 동기화 및 탭 권한 제어
- **호스트 주도 게임 탭 네비게이션 (`SCR_GNT_01_비로그인게스트홈.tsx`, `server.ts`)**:
  - 방장이 사다리에서 룰렛, 또는 룰렛에서 사다리로 탭을 이동할 때 `NAVIGATE_GAME_TAB` 액션을 브로드캐스트하여 원격 참가자 화면을 동일한 탭으로 강제 동기화 이동.
  - 참가자(게스트) 화면에서는 게임 탭 버튼을 비활성화(`disabled`, 자물쇠 뱃지, 툴팁)하여 방장 주도 중계 환경 보장.
- **사다리 가로줄 배열 직접 동기화 (`LadderGameZone.tsx`, `server.ts`)**:
  - `SHUFFLE_RUNGS` 액션 시 단순 시드값뿐만 아니라 계산된 `rungs` 배열 자체를 서버 영속화 및 전송하여, 클라이언트 환경별 시드 난수 편차로 인한 경로 불일치 원천 해소.
  - 버튼 레이블을 '가로줄 섞기'에서 직관적인 **'사다리 섞기'**로 개편.
- **매장 변경 시 참여자 메뉴 초기화**:
  - 방장이 연동 매장을 변경하면 `UPDATE_STORE` 액션을 수신한 참가자 화면도 선택 메뉴를 즉시 `undefined`로 초기화.

### 2.4 가중치 3대 개선 정책 완결
- **초기값 10 설정**:
  - 사다리 참가자, 룰렛 아이템, 그리고 시스템 프리셋 4종(점심/당번/벌칙/커피)의 기본 가중치를 `10`(`10x`)으로 설정.
- **가중치 토글 OFF 시 전원 10으로 일괄 리셋**:
  - 방장이 가중치를 끄면 로컬 및 브로드캐스트를 통해 모든 참가자/항목의 가중치를 즉시 `10`으로 리셋.
- **가중치 0 고정 및 비례 풍선효과**:
  - 수치가 0 이하로 내려가지 않고 `0`으로 고정 유지 (`0x 🎈`).
  - 0에서 `[-]` 클릭 시 나머지 양수 항목들이 각자의 현재 가중치 비율에 비례하여 증가(`proportionalBonus = Math.max(1, Math.round(otherW / minOtherW))`).
  - 가중치 0 항목은 룰렛 회전판 슬라이스 각도가 0도가 되어 휠에서 깔끔하게 사라지며, 추첨 확률 0% 완전 배제.
