## 1. 태스크 개요 및 추진 배경

기존 모아보고 플랫폼의 시스템 설정 경로(`/system`, `SCR-SYS-01`)는 단순 인프라 서버 및 리소스 관제(PostgreSQL, Cloudflare Tunnel, RAM OOM, EasyOCR 큐)에 국한되어 있었습니다. 플랫폼 확장에 따라 금융 컴플라이언스 통제, 로그인 보안 정책, 전역 서비스 알림 통제, RBAC 권한/화면/메뉴/사용자 관리, Markdown 약관 버전관리, 20대 마스터 코드 풀, 그리고 사다리/룰렛 기초 게임 콘텐츠 풀을 통합 제어할 수 있는 **'전역 거버넌스 백오피스'** 체계가 필수적으로 요구되었습니다.

이에 따라 백오피스 8대 핵심 거버넌스 아키텍처를 설계하고, 실시간 반응형 UI와 디자인 토큰(`ElmMkd01`, `ElmMkdViewer`, `ElmChk01`), `localStorage` 기반 무중단 데이터 영속화 스토어(`systemGovernancePool.ts`)를 완결하였습니다.

## 2. 8대 핵심 거버넌스 구현 상세

### 1) 실시간 인프라 관제 (Resource Dashboard)
- PostgreSQL 연결 풀(7/20), Cloudflare 터널 지연(42ms), EasyOCR 파이프라인 2GB RAM OOM 격리 버퍼(1,280MB), 큐 상태 모니터링 카드 완비.

### 2) 로그인 인증 및 보안 거버넌스 (AUTH_SEC)
- 간편로그인(OAuth) 전역 활성화 스위치 및 개별 소셜 공급자(카카오, 네이버, 구글) 3사 On/Off 제어.
- 로그인 2단계 인증(2FA: OTP/SMS) 적용 정책 스위치.
- 이메일 인증 강제 필수 여부 토글 제어.

### 3) 서비스 전역 알림 발송 매트릭스 (NOTIFY)
- 인증된 이메일에만 알림 발송 제한 보안 스위치.
- **12종 전역 서비스 알림 토글 매트릭스**:
  - 가계부 (2종): 구성원 등록 알림, 정기지출 예정 도래 알림.
  - 모아당번 (4종): 관람당번 이벤트 알림, 담당일정 도래 알림, 수행요청 알림, 초대요청/수용 알림.
  - 모아목표 (4종): 관람목표 이벤트 알림, 수행일정 알림, 응원메시지 알림, 초대요청/수용 알림.
  - 모아머니 (3종): 정산요청/승인 알림, 지원요청/승인 알림, 보상요청/승인 알림.

### 4) RBAC 및 약관 거버넌스 시스템 (RBAC)
- **메뉴 관리**: 메뉴 ID, 메뉴명, 메뉴구분, 연결 화면 경로, 사용여부 CRUD. 테이블 내 사용여부 비활성 체크박스(`ElmChk01`) 시각화.
- **화면 관리**: 화면 ID, 화면명, 라우트, 접근권한, 설명(Markdown), 사용여부, 매핑된 권한그룹 CRUD.
- **권한그룹 관리**: 그룹 ID, 그룹명, 설명, 사용여부 CRUD.
- **권한 관리**: 권한그룹 ➔ 화면 1:1 양방향 실시간 동기화 매핑 (`mappedRoleIds` ↔ `mappedScreenIds`).
- **사용자 관리**: 가입 회원 조회, 사용여부(ACTIVE/SUSPENDED 원클릭 토글), 사용자 상세 모달(개인설정 조회 + 계좌번호 `3333-**-****882` 마스킹 보호 + [비밀번호 초기화] 트리거).
- **약관 거버넌스 & 버전 관리**:
  - 3대 약관 구분(서비스이용약관, 개인정보수집및이용동의, 이벤트알림및정보수신동의) 관리.
  - 약관 카드에서 사용설정 라디오버튼 제거, 시행일/이력건수/삭제 액션 정돈.
  - 약관 상세 하단 개정 저장이력 배치 및 최근 작성본 상단 정렬.
  - **이력 체크박스(`ElmChk01`) 단일 배타적 선택**: 하나의 이력이 선택되면 다른 항목은 반드시 해제되는 SSOT 제어.
  - **이력 선택 시 상단 본문 실시간 전환**: 선택한 이력의 Markdown 내용과 버전으로 화면 표시 동기화.
  - **버전 자동 증가 알고리즘**:
    - 버전 미수정 저장 시: 서브버전 자동 증가 (`v1` ➔ `v1.1`, `v1.1` ➔ `v1.2`, `1.2` ➔ `1.3`).
    - 버전 직접 수정 시: 입력한 버전 그대로 저장.

### 5) 금융 컴플라이언스 송금통제 (FINANCE)
- 모아목표 응원 송금 URL 생성 차단/허용 통제.
- 모아머니 송금 URL 생성 차단/허용 통제.
- 정책 적용 미리보기 시뮬레이터 연동.

### 6) 20대 마스터 코드 관리 풀 (MASTER_CODES)
- 장부(6종: 장부유형, 회계기간, 세부성격, 책등디자인, 상태, 권한), 은행사, 카드사, 할부기간, 결제수단, 수입채널, 기초지출카테고리, 기초이동사유, 당번(4종: 기초카테고리, 순환정책, 정산주기, 완료방식), 목표(2종: 초기유형, 실천기간), 정산 초기카테고리 등 20대 그룹코드 및 계층형 상세코드 CRUD.

### 7) 기초 게임 콘텐츠 풀 관리 (GAME_POOL)
- 사다리: 기초 매장 등록/수정/삭제 및 매장별 메뉴(기본 아이콘 풀 선택, 메뉴명, 금액) CRUD 완비.
- `getSystemStorePool()` 헬퍼를 통해 사용자 환경설정(`SCR-SET-01`)과 실시간 동적 연동.
- 룰렛: 기초 게임 프리셋 풀 연계.

### 8) 긴급 공지 관리 (NOTICES)
- 공지 등록/수정/삭제, 공지 모드 3종(`TEXT`, `MD`, `IMAGE`) 지원.
- CTA 액션 버튼 옵션: 버튼명, 링크 URL, 타겟 3종(`INTERNAL_SCREEN`, `CONTENT_PATH`, `EXTERNAL_LINK`).
- 마크다운 모드 시 실시간 미리보기 제공.

## 3. 공통 디자인 토큰 신설 및 고도화 (`Tokens.tsx`)

1. **`ElmMkd01` (마크다운 에디터 & 실시간 미리보기)**:
   - 툴바 모드 전환 탭: 텍스트 없이 **아이콘 전용(`Edit2`, `Eye`, `Columns`)** 콤팩트 디자인.
   - **코드 프리셋 단축 버튼**: [+ 표], [+ Mermaid], [+ 코드], [+ 체크] 원클릭 템플릿 삽입 지원.
2. **`ElmMkdViewer` (마크다운 렌더러)**:
   - 마크다운 테이블(`| th1 | th2 |`) 다크모드 대응 HTML table 렌더링.
   - Mermaid 다이어그램(````mermaid ... ````) 파싱, 시각화된 노드-엣지 흐름도 카드 렌더링 및 [코드 원문 보기] 토글 지원.
   - 제목, 인용문, 코드블럭, 인라인코드, 체크리스트, 불릿/번호 리스트 완벽 파싱.
3. **`ElmChk01` (체크박스 토큰)**:
   - 라벨 텍스트 클릭 시 전체 영역 토글 이벤트 보장 (`sr-only` input + label onClick).
   - 테이블 내 disabled 체크박스 및 모든 폼 컨트롤 표준화.
