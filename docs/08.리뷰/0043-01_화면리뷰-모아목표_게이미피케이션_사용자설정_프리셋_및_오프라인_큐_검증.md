## 1. 구현 개요 및 주요 목표

본 작업은 모아목표(SCR_GOL_01/02)와 게이미피케이션(SCR_GAM_01) 간의 연동 효용성을 사용자 관점에서 면밀히 재검토하여 불필요한 노이즈 요소를 제거하고, **사용자설정(`SCR_SET_01`) 중심의 명시적 프리셋 거버넌스**와 **오프라인 우선 가계부 큐(`SCR_OFF_01`)의 무손실 원자적 동기화 체계**를 확립한 핵심 마일스톤 과제입니다.

### 사용자 피드백 기반 핵심 피벗 (Pivot)
1. **목표 상세(`SCR_GOL_02`) 달성 축하 배너 전면 제거**:
   - 목표 달성 후 룰렛을 돌려 얻는 실질적 이득이 모호하고 화면 진입 시마다 지속 노출되는 UX 결함을 해소.
   - 목표 달성 보상은 기 구축된 '용돈이체 모달'(`transferModalOpen`)을 단일 진실 공급원(SSOT)으로 일원화.
2. **동적 레퍼런스 주입 배제 & 사용자설정(`SCR_SET_01`) 명시적 프리셋 관리 채택**:
   - 모아게임 허브에 등록된 전체 목표 항목을 무차별 노출하지 않고, 사용자설정에서 사용자가 필요한 목표/당번을 선택하여 프리셋으로 구성하도록 분리.
3. **원본 구성원 변경 감지 및 온스크린 동기화 배너**:
   - 목표 동행원이나 당번 구성원이 변경되었을 때 시스템 알림 대신 프리셋 카드 상에 `⚠️ 원본 구성원 변경됨: 기존 N명 ➔ 현재 M명 [동기화]` 상태 알림 뱃지와 즉시 동기화 액션 제공.
4. **오프라인 가계부 큐(`offlineQueueStore`) 멱등키 보존 및 원자적 동기화**:
   - 모아게임에서 오프라인 중 기안된 지출을 멱등키(`idempotencyKey`) 기반으로 로컬 큐에 안전하게 격리 보관하고, 온라인 재연결 시 Stale 충돌 방어 및 원자적 일괄 동기화 검증.

## 2. 세부 구현 내역

### 1) 모아목표 상세(`SCR_GOL_02_모아목표상세.tsx`) 본연의 기능 집중
- 불필요한 게이미피케이션 축하 룰렛 배너를 전면 제거하여 목표 현황, 달성도 프로그레스, 실전 저축/활동 기록, 용돈이체 보상 기능에 집중하도록 화면 정돈 완료.

### 2) 사용자설정(`SCR_SET_01_사용자설정.tsx`) 프리셋 출처 선택 및 동기화 구현
- **프리셋 등록/수정 모달 UX 혁신 (`LadderManualModal`, `RouletteManualModal`)**:
  - 상단에 출처 선택기 세그먼트 버튼 배치: `[✏️ 직접 입력] | [🎯 모아목표] | [🧹 모아당번]`
  - `🎯 모아목표` 선택 시:
    - 등록된 모아목표 드롭다운(`INITIAL_GOAL_LIST`) 노출.
    - 선택 시 사다리/룰렛 제목, 설명, 참가인원, 참가자 목록(`companions`)이 자동 주입.
  - `🧹 모아당번` 선택 시:
    - 등록된 모아당번 드롭다운(`INITIAL_DUTIES`) 노출.
    - 선택 시 당번 제목, 담당자 목록(`participants`)이 자동 주입.
  - 저장 시 `sourceType`, `sourceId`, `sourceName`, `originalMemberCount`, `originalMembers` 메타데이터 영속화.
  - **당첨인원수 수정에 따른 목표 역할 건수 실시간 현행화**:
    - 사다리 등록 모달에서 `winnerCount` 증감 시 목표 역할 목록(`roles`) 내의 결제 당첨(`PAY`) 역할 개수가 자동 동기화되어 즉시 반영.
- **프리셋 카드 내 원본 구성원 변경 감지 뱃지 & 동기화 액션**:
  - `checkPresetSourceSyncStatus(preset)`를 통해 원본 목표/당번의 구성원 수 및 명단 변경 여부를 실시간 대사.
  - 변경 감지 시 카드 내 `⚠️ 원본 구성원 변경됨: 기존 N명 ➔ 현재 M명 [동기화]` 배너 노출.
  - `[동기화]` 버튼 클릭 시 즉시 현재 원본 구성원 명단으로 프리셋 참가자/아이템을 현행화하고 로컬 스토어 갱신.
- **UI 시인성 및 요소 줄바꿈 개선**:
  - 사다리 및 룰렛 프리셋 카드 헤더에서 뱃지 내부 텍스트 줄바꿈 방지(`whitespace-nowrap`) 및 요소 단위 자연스러운 줄바꿈(`flex-wrap`) 적용.
  - 버튼 레이블 명확화: `기초 프리셋 둘러보기`/`가져오기` ➔ `기초 프리셋 등록`, `+ 직접 등록` ➔ `직접 등록`.
  - 연동 뱃지 텍스트 명시: `🎯 목표(룰렛 동시 적용)`, `🧹 당번(룰렛 동시 적용)`.
  - 단골 매장 카테고리 필터 바에 `ElmSld03` 슬라이드드래그휠 적용 완료.

### 3) 모아게임 허브(`SCR_GAM_01_모아게임허브.tsx`) 및 룰렛존(`RouletteGameZone.tsx`) 정돈
- **서브탭 헤더 텍스트 줄바꿈 완전 방지**: `ElmSld03` 슬라이드드래그휠 내에서 버튼 및 텍스트에 `whitespace-nowrap flex-nowrap shrink-0`을 강제하여 좁은 화면에서도 글자 쪼개짐 없이 매끄러운 스크롤 보장.
- **단골 매장 퀵칩 바의 사다리(`LADDER`) 전용 격리**: 사다리와 달리 매장 메뉴를 사용하지 않는 룰렛(`ROULETTE`) 및 정산(`SPLIT`) 탭에서는 단골 매장 칩 바를 완전히 숨김 처리하여 화면 간섭 및 군더더기를 원천 제거.
- **룰렛 프리셋 바 개인 맞춤 프리셋(목표/당번) 통합 연동**: `RouletteGameZone` 내 추천 프리셋 슬라이더에 시스템 프리셋뿐만 아니라 사용자가 등록한 개인화 프리셋(`loadUserPersonalRoulettePresets()`)을 합쳐서 `[🎯 목표]`, `[🧹 당번]` 뱃지와 함께 노출함으로써, '참여 멤버 추첨'과 '프리셋 추첨' 간의 경쟁 조건을 해소하고 사용자가 명시적으로 선택할 수 있는 단일화된 진입점 제공.
- 전체 목표 목록을 그룹 드롭다운에 강제 바인딩하던 복잡도 로직을 제거하고 본래의 `DEFAULT_MEMBER_GROUPS`로 단순화.
- 오프라인 상태에서 지출 기안 시 `offlineQueueStore`로 멱등키와 함께 안전하게 적재.

### 4) 오프라인 동기화 인프라 및 화면 (`offlineQueueStore.ts`, `SCR_OFF_01_오프라인동기화.tsx`)
- **`offlineQueueStore.ts` 신규 구축**:
  - `OfflineQueueItem`: `idempotencyKey`, `type`, `title`, `amount`, `status ('PENDING' | 'SYNCED' | 'STALE_CONFLICT')`, `retryCount`, `createdAt` 관리.
  - `getOfflineQueue`, `addOfflineQueueItem`, `syncOfflineQueue`, `resolveOfflineConflict`, `getPendingCount` 핵심 API 및 브라우저 전역 이벤트(`moabogo:offline-queue-changed`) 브로드캐스트 지원.
- **`SCR_OFF_01_오프라인동기화.tsx` 실시간 검증**:
  - 대기열 실시간 목록 조회, 멱등키 태그 표시, 오프라인 시뮬레이션 지출 적재 버튼.
  - 네트워크 재연결 시 원자적 일괄 동기화 시뮬레이션 및 서버 최신상태 갱신 가드레일 구현.
- **글로벌 네비게이션 배지 (`App.tsx`)**:
  - 헤더/드로어의 오프라인 동기화 메뉴에 미반영 대기 건수(`pendingCount`) 뱃지 실시간 표시.
