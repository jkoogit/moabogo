## 1. 개요 및 목적 (Overview & Goals)

본 문서는 세션 `[0049-02]`에서 수행된 **모아부릉(`SCR-CAR-01`)**의 10대 심층 UX/UI 고도화(불필요 요소 제거, 슬라이드 드래그휠 스크롤 경계 제어, 대화형 OCR 추출 텍스트 매핑, 모아데이 수리계획 연계, 주차 시간 조절 등)와 **모아보고 프론트엔드 전체 21개 화면(`SCR_*`)**의 디자인 토큰 바인딩 및 360px 모바일 뷰포트 반응형 최종 동결 검증 결과를 기록합니다.

## 2. 핵심 고도화 내역 (Key Improvements)

### 2.1 UI 정리 및 레이아웃 점핑(Layout Shift) 원천 차단
- **스위처 번호판 중복 제거**: 상단 차량 칩에서 번호판을 제거하고 별칭만 노출하여 하단 차량 상세 영역 번호판 표시와의 중복을 해소했습니다.
- **요소 단위 줄바꿈(Element-level Wrapping)**: 차량 상세 정보 바를 `모델명`, `연식/유종 스펙`, `번호판 마스킹 버튼`의 독립 요소로 분리하여 360px 모바일 화면에서도 텍스트가 강제로 잘리지 않고 요소 단위로 깔끔하게 래핑되도록 개선했습니다.
- **부유형 플로팅 토스트(Floating Toast) 전환**: 모달 헤더와 폼 사이에 인라인으로 노출되던 알림 배너를 모달 우측 상단 플로팅 토스트(`absolute top-16 right-5 z-50`)로 전환하여 화면 밀림 현상을 원천 차단했습니다.
- **불필요 선택 전가 UI 제거**: 가계부 자동 기장 스위치 제거(시스템 1:1 기본 보장), 중복 경고 배너 상단 고정 제거(미해결 건 발생 시에만 탭 우측 `[중복정리]` 버튼 동적 노출).

### 2.2 슬라이더(`ElmSld03`) 스크롤 경계 이벤트 제어
- `CarMaintenanceStrip` 및 6대 카테고리 필터 탭 바에 `ElmSld03` 경계 기반 이벤트 제어를 적용했습니다.
- 첫 항목 또는 마지막 항목에 도달했을 때만 상하 페이지 스크롤 이벤트가 전파되고, 그 사이에서는 가로 슬라이더 영역만 부드럽게 이동하며 상하 화면 튕김을 차단합니다.

### 2.3 대화형 OCR 추출 텍스트 매핑 팝업 (`OcrMemoBoardModal`)
- **감지대상 매핑항목 폼**: 타이틀 버튼 + 입력필드 + 토큰 표준 `X` 클리어 버튼으로 구성.
- **선택 텍스트 원클릭 주입 (Interactive Selection Mapping)**: 하단 전문에서 원하는 텍스트를 마우스 드래그 또는 상단 줄 단위 탭 선택 칩으로 선택 후 타이틀 버튼을 클릭하면 해당 입력필드에 즉시 주입.
- **상하 리사이즈 핸들 (Draggable Splitter)**: 사용자가 마우스 드래그로 상단 매핑 폼과 하단 텍스트 전문의 높이 비율(20%~80%)을 자유롭게 조절 가능.
- **`?` 레이어 팝업**: 불필요한 인라인 괄호 설명 문구를 제거하고 타이틀 옆 `?` 버튼 클릭 시 상세 사용 가이드 레이어 팝업을 표시.

### 2.4 점검 카테고리화 및 모아데이(SCR-DAY-01) 수리 계획 연계
- 점검 항목을 4대 표준 카테고리(`정기 종합검사`, `엔진 및 구동계`, `제동 및 하체`, `전장 및 소모품`)로 체계화.
- 검사 결과표 첨부 후 `[OCR]` 클릭 시 정비 권장 항목 자동 체크.
- 체크된 항목들을 묶어 단일 모아데이 수리 계획(`차량 수리 계획: ...`, 수리 희망일자)으로 통합 등록할 수 있는 옵션을 제공하여, 추후 정비소 방문 시 수리 이력과 1:1로 자연스럽게 연결되도록 설계.

### 2.5 모아데이 상호 연결 팝업 (저장 시점 발생일자 검사)
- 폼 입력 중 고정 노출되던 배너를 배제하고, 사용자가 [등록] 버튼을 누르는 저장 시점에 `발생일자(occurredAt)`를 기준으로 계획된 모아데이 일정이 있는지 검사.
- 대상이 있을 때 `MoaDayScheduleLinkModal`을 띄워 [상호 연결하기] 또는 [연결 안 함]을 선택할 수 있도록 프로세스를 정류.

### 2.6 주차 입출차 시간 조절 인디케이터
- 입차시간 및 출차시간 인풋 카드를 직접 클릭/포커스하여 활성화 타겟을 지정.
- 상단 `[-30분]`, `[-10분]`, `[+10분]`, `[+30분]` 인디케이터 클릭 시 활성화된 시간 요소에 즉시 가감 반영.
