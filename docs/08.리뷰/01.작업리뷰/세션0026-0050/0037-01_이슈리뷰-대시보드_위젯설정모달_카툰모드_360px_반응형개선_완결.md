# [0037-01] 대시보드 위젯 설정 모달 및 카툰모드 1:1 연동, 화면타이틀 360px 반응형 전면 개선 완결 리뷰

## 1. 개요 및 목적
- **세션 / 태스크 ID**: `[0037]` / `[0037-01]`
- **태스크명**: 화면타이틀 반응형 규칙 현행화, 대시보드 위젯설정 및 책장모드 연계, 360px 반응형 전면 개선 완결
- **수행 목적**:
  1. **화면타이틀 반응형 처리 표준 규칙 정립 및 공통 토큰 현행화 (`Tokens.tsx`)**:
     - 모바일(최소 360px) 뷰포트에서 타이틀 영역의 화면 설명 문구(subtitle)가 헤더 액션 버튼들과 같은 줄에서 압축·줄바꿈되어 가독성을 저해하던 문제를 해결하기 위해, 1행(좌측 타이틀+화면ID 뱃지 ↔ 우측 헤더 액션 버튼 그룹) / 2행(설명문구 subtitle을 버튼 다음 줄로 전폭 분리 표시) 구조의 표준 반응형 규칙을 정의하고 공통 토큰(`ElmTyp01`)에 내장.
     - 빠른 실행 버튼(`ElmQck01`) 라벨에 `whitespace-nowrap shrink-0`를 적용하여 단어 중간 분절 방지.
  2. **대시보드 위젯 및 배치 설정 모달 UX 전면 개선 (`SCR_DSH_01`)**:
     - 저장 및 초기화 시 모달을 닫고 화면 하단에 플로팅 팝업(`ElmToast01`)으로 안내 메시지를 띄우도록 개선.
     - 저장 완료 버튼 좌측에 명시적인 `[닫기]` 버튼 추가.
     - `상세설정` 레이블 우측에 `전체 선택` 체크박스와 `초기화`(`RotateCcw`) 아이콘 버튼 배치.
     - 위젯별 체크박스와 기능이 중복되던 눈(Eye/EyeOff) 아이콘을 제거하고 체크박스 단독 제어로 일원화.
  3. **통합가계부 장부책장 카툰모드 1:1 동일 렌더링 및 중복 버튼 제거 (`SCR_DSH_01`)**:
     - `SCR_LED_01`의 SVG 정품 카툰 오브젝트(`CartoonStackedBookObject`) 및 두께 계산 로직을 1:1 연동하여 대시보드 `SHELF` 모드에서도 장부책장과 완전히 동일한 비주얼 렌더링 지원.
     - 카툰 책 클릭 시 해당 장부 집중(책장닫기) 모드로 자동 라우팅 연계.
     - 하단 전체보기 링크와 중복되던 상단 헤더 우측의 `장부책장 이동 →` 버튼 제거.
  4. **가계부 관리 상세 및 대사 모달 360px 반응형 보강 (`SCR_LED_01`, `LedgerProofReconcileModal.tsx`)**:
     - 상단 서류철 탭 모바일 2단 정렬 및 터치 영역(`min-h-[36px]`) 확보.
     - 카드 청구서 SSOT 대사 내역 금액, 할인 배지, 4열 메타데이터 모바일 줄바꿈 최적화.
  5. **대규모 확장 과제 공식 백로그 분기 (`docs/06.백로그/`)**:
     - `BKL-GAM-04`: 로그인 회원 전용 통합 게임/정산 허브 및 사용자·매장 프리셋 관리 플랫폼 구축.
     - `BKL-SYS-01`: 시스템 운영 관리 독립 접근 경로 (`/system`) 및 백오피스 아키텍처 구축.
     - `docs/01.프로젝트/02-backlog-spec.md` 총괄 명세서 현행화 완료.

## 2. 주요 아키텍처 및 구현 성과

### 2.1 공통 타이틀 토큰 반응형 규칙 정립 (`ElmTyp01`)
- `actions?: React.ReactNode` prop을 지원하도록 확장.
- 모바일에서 1행은 Flex justify-between으로 타이틀과 액션 버튼을 양 끝에 배치하고, 2행은 `subtitle`을 독립된 full-width 블록으로 렌더링하여 화면 설명이 긴 경우에도 헤더 버튼을 밀어내지 않고 자연스럽게 다음 줄에 표시되도록 구조화.

### 2.2 대시보드 위젯 커스터마이징 모달 고도화 (`SCR_DSH_01`)
- **플로팅 토스트**: `setFloatingToast` 및 `ElmToast01` 연동으로 저장 완료 시 모달이 닫히며 하단 중앙에 플로팅 토스트 안내 제공.
- **상세설정 제어바**: 타이틀 옆에 `전체 선택` 체크박스와 `초기화(RotateCcw)` 아이콘을 배치하여 한눈에 제어 가능.
- **단일 체크박스 제어**: 중복되던 Eye/EyeOff 아이콘을 제거하고 모바일 터치 접근성을 개선한 표준 체크박스로 일원화.
- **닫기 버튼**: 저장 완료 버튼 옆에 취소/닫기 버튼을 명시적으로 배치.

### 2.3 장부책장 카툰모드 1:1 비주얼 연동 (`SCR_DSH_01` ↔ `SCR_LED_01`)
- `SCR_LED_01`에서 `CartoonStackedBookObject`, `adjustBrightness`, `getThicknessScale`, `INITIAL_LEDGER_BOOKS`, `CartoonBookObjectProps`를 export.
- `SCR_DSH_01`의 `bookshelfViewMode === 'SHELF'` 영역에서 해당 컴포넌트를 직접 렌더링하고, 책 클릭 시 `moabogo_bookshelf_close_mode` 플래그를 세션 스토리지에 전달하여 상세 페이지 진입 시 해당 장부 집중 뷰로 자동 전환.
- 상단 중복 헤더 버튼을 제거하여 불필요한 공간 낭비 방지.
