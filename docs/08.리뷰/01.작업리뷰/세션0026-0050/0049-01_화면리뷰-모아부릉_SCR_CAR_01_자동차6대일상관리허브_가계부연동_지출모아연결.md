## 2. 핵심 구현 내역 (Key Implementations)

### 2.1 다중 차량(Multi-Vehicle) 관리 및 Odometer 트래커
- **차량 스위처 칩**: 가계부 책꽂이 스위처와 대등하게 상단에서 다중 차량(예: `우리집 쏘렌토`, `출퇴근 레이 EV`)을 원클릭으로 전환하여 차량별 독립 이력 및 유지비 조회.
- **계기판 주행거리(Odometer) 즉시 수정**: 헤더에서 현재 주행거리를 원터치 인라인 수정 가능하며, 이력 등록 시 입력된 주행거리가 더 높을 경우 차량 누적 주행거리 자동 현행화.
- **민감정보 마스킹 토글**: 차량 번호판을 기본 `12가 34**` 형태로 마스킹하고, 눈 아이콘 클릭 시 원본 확인 가능.

### 2.2 6대 관리포인트 이력 원장 및 보조 지표 차분한 배치
- **6대 관리포인트 CRUD**:
  - `주유·충전(FUEL)`: 유종, 주유량(L/kWh), 단가, 가득 주유 여부, 구간 연비 자동 산출.
  - `점검(INSPECTION)`: 소모품/교체 부품 내역, 보증기간.
  - `수리(REPAIR)`: 고장/부품 수리 내역.
  - `세차(WASH)`: 세차 방식(셀프/자동/손세차/디테일링).
  - `보험(INSURANCE)`: 보험사, 긴급출동 대표번호, 보험기간.
  - `주차(PARKING)`: 주차 층/기둥 위치 메모(예: `B4-G12`), 출차 시간, 주차 요금.
- **보조적 참고 지표 배치 (과장/강조 배제)**:
  - 당월 총유지비(TCO) 및 최근 연비(km/L)를 대형 차트나 과도한 주목도로 노출하지 않고, 상단 헤더 하단에 컴팩트한 보조 카드(`11px` 라벨, `bg-slate-50/80`)로 차분하게 배치.

### 2.3 사용자 설정 기반 모아데이(SCR-DAY-01) 전역 캘린더 연동 관리
- `SCR_SET_01` '모아부릉(차량)' 탭 신설.
- **모아데이 연동 대상 선택 체크박스**:
  - 자동차보험 만기 갱신 D-Day (`INSURANCE`)
  - 한국교통안전공단 정기종합검사 (`LEGAL_INSPECTION`)
  - 소모품(엔진오일/필터) 교체 도래 (`CONSUMABLES`)
  - 월 정기주차권 갱신일 (`PARKING_PASS`)
- 사용자가 체크한 항목에 한해서만 전역 캘린더(`모아데이`)에 자동 등록되도록 하여 알림 피로도 차단.

### 2.4 지출모아 연결 & 정산 원자성 관리 프로세스
- **동일 지출 3대 키 실시간 감지**: `지출일자 + 결제수단 + 금액`이 일치할 때 가계부 수기 지출(`LEDGER_EXPENSE`), 카드 승인 내역(`CARD_STATEMENT`), 모아부릉 이력(`CAR_LOG`)을 교차 감지.
- **지출모아 연결 팝업**:
  - 각 항목 앞에 원본 선택 라디오 버튼 제공 ➔ 사용자가 원하는 소스를 **기준 원본(Primary)**으로 직접 지정.
  - `[지출모아 연결]` 버튼 클릭 시, 선택된 원본의 ID를 기준으로 나머지 항목들을 동일 지출 **사본(Replica)**으로 연계 매핑하여 가계부 결산 및 정산 시 단 1건만 유효하게 반영 (이중계상 원천 차단).
- **상세 확인 팝업 (`LinkedExpenseDetailModal`)**:
  - 이력 카드에 `지출모아 연결됨 (N건 사본)` 녹색 뱃지 클릭 시 원본 지출과 연결된 사본 목록을 나열하여 투명한 원자성 검토 제공.
