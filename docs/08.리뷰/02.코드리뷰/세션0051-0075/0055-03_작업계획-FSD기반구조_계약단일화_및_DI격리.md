## 1. 목표 및 실행 전략

본 작업계획은 1단계 기반 구조 코드리뷰([0055-01](./0055-01_코드리뷰-React_FSD_기반구조.md))에서 식별된 7건의 구조적 발견사항(`FND-01` ~ `FND-07`)을 **백엔드 착수(`BKL-DATA-01`)와의 선후관계 및 보안·DI 요건**에 따라 5개 실행 패키지(`WP-01` ~ `WP-05`)로 묶은 계획이다.

- **핵심 원칙**:
  1. **화면 수정 0줄 백엔드 전환 기반 확보**: 화면이 더미데이터를 직접 `import`하지 않고 포트/훅 주입(DI)만 받도록 경계를 먼저 세운다.
  2. **공유 계약(SSOT) + 한글명 JSDoc 표준화**: 프론트·백엔드·미끼 데이터가 단일 TypeScript 계약을 공유하도록 묶어 스키마 드리프트를 컴파일 타임에 차단한다.
  3. **더미데이터의 허니팟(Decoy) 보안 격리**: 프로덕션 클라이언트 번들에서는 더미데이터를 제거하고, 공유 계약을 `satisfies`하는 서버 측 격리 미끼 픽스처로 이관한다.
