## 1. 놓치기 쉬운 5대 사각지대 (Identified Blind Spots)

### 1.1 [사각지대 1] 키보드 접근성(Keyboard Navigation) 및 스크린 리더(ARIA) 미흡
- **현상**:
  - `ElmInp01`(X 클리어 버튼), `ElmSwt01`(토글 스위치), `ThemeToggle` 등에서 마우스 클릭 위주로 동작이 설계되어 있음.
  - 탭 키(Tab) 이동 시 시각적 포커스 링(`focus-visible:ring`)이 누락되어 있거나, `aria-expanded`, `aria-haspopup` 속성이 부분적으로 누락됨.
- **예방 조치**:
  - 모든 대화형 버튼에 `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-indigo-500` 필수 부여.
  - 드롭다운 메뉴(`ThemeToggle`)에 `role="listbox"`, `aria-selected` 보완.

### 1.2 [사각지대 2] 모바일 가상 키보드 오픈 시 레이아웃 파손 (Viewport Resize)
- **현상**:
  - 모바일 스마트폰에서 입력 필드(`input`)를 터치하면 소프트웨어 가상 키보드가 올라오며 뷰포트 높이가 축소됨.
  - 이때 고정 높이(`min-h-screen`)나 `fixed bottom-0`으로 설정된 모바일 바텀바(`ElmNav01`)가 입력창을 가리는 현상이 발생할 수 있음.
- **예방 조치**:
  - 모바일 환경에서 입력 필드 포커스 시 `ElmNav01`을 일시적으로 숨기거나(`keyboard-open` 클래스 감지), `interactive-widget=resizes-content` 메타 태그 대응.

### 1.3 [사각지대 3] 번들 크기(Bundle Size) 최적화 및 코드 스플리팅(Code Splitting) 누락
- **현상**:
  - `App.tsx` 최상단에서 13개 화면 컴포넌트(`SCR_*`)를 모두 정적 `import`하고 있음.
  - 사용자가 첫 진입 시 보지 않는 나머지 12개 화면의 번들까지 한 번에 로드되므로 초기 페이징 속도(FCP: First Contentful Paint)에 불리함.
- **예방 조치**:
  - React의 `lazy()` 및 `Suspense`를 도입하여 라우팅 전환 시점에 동적 로딩하도록 분할:
    ```tsx
    const SCR_LED_01 = React.lazy(() => import('./sample/screen/SCR_LED_01_그룹가계부관리상세'));
    ```

### 1.4 [사각지대 4] 오프라인 전환 시 폼 입력 데이터 소실 방지 (Unsaved Form Protection)
- **현상**:
  - 사용자가 가계부나 당번 내역을 긴 호흡으로 작성 중 네트워크가 끊기거나 실수로 탭을 새로고침했을 때 입력 버퍼가 날아갈 수 있음.
- **예방 조치**:
  - `ElmInp01` 및 작성 모달에 `localStorage` 임시 드래프트 자동 저장(Auto-Draft) 훅 연동.

### 1.5 [사각지대 5] 다국어(i18n) 및 환율 통화 처리 하드코딩
- **현상**:
  - 화면 전반에 한국어 텍스트와 원화(`₩`) 단위가 하드코딩되어 있음.
- **예방 조치**:
  - 통화 포맷 함수 `formatCurrency(amount, currency = 'KRW')`를 유틸리티 함수로 표준화하고, 텍스트 키 기반 국제화 사전 구조를 미리 고려.
