# 261006_화면검토

1. 메인화면 : 비로그인 서비스(정산, 사다리, 술래잡기..) 제공, 로그인 및 회원가입 기능
2. 회원가입 : id/pw 와 카카오톡, 네이버, 구글 소셜인증 및 이메일인증 추가(시스템설정시 필수)
3. 로그인 : 앱 사용에 따라 한번 로그인하면 오프라인에서도 사용할 수 있게 세션관리
4. 로그인 메인화면 : 사용자 설정에서 주로 사용하는 기능 배치 가능  
   - 가계부(개인, 그룹, 개별),
   - 라이프서비스(모아목표, 모아당번, 모아머니, 요구머니, 요청머니)
   - 지출등록(영수증, 이체화면), 모아등록(목표, 당번) 빠른등록기능
   - 이벤트서비스(정산, 사다리, 술래잡기) - 구성원 관리기능 사용가능
5. 서비스별 상세화면 
5.1 그룹 가계부관리 : 등록, 수정, 삭제, 구성원관리(그룹 - 회원필수/개별-게스트가능) 
5.2 모아목표 : 등록, 수정, 삭제, 동행원관리(목표수행), 관람원관리(조회)  
   - 목표관리 항목 관리 (고정항목, 입력항목 등 ) 5.3 모아당번 : 등록, 수정, 삭제, 당번정책, 참석자관리(당번수행), 관림원관리(조회)
   - 수행 : 인증사진을 포함한 완료여부 등록, 메모, 상태설정(완료/보류양해/대신요청/예약)
   - 당번 대신수행 [요청, 실행] 건수관리 5.4 모아머니 : 머니이동관리
   - 요구머니 : 자금요청(지출이 필요한 자급 긴급요청) - 지급시 용돈 차감여부 관리(차감시 요청머니로 교체), 승인시 카톡, 토스로 이체가능한 링크생성
   - 요청머니 : 용돈에서 상환하거나 현물상환 대상 자금요청 - 상환여부, 분납 상태 관리 (상환예정일 알림) 5.5 빠른 머니등록 :
   - 지출내역 : 영수증 첨부, 사용자정보로 기본정보 설정 - 지출자, 소비자, 등록대상(가계부선택) 등
   - 지급내역 : 이체내역 첨부, 대상자, 금액 등 설정 - 추가 변경가능정보 관리 5.6 빠른 수행등록 :
   - 당번등록 : 인증사진 첨부, 메모, 상태, 수행시간 설정
   - 목표등록 : 인증사진 첨부, 메모, 상태, 수행시간 설정 
6 사용자설정 
6.1 메인화면 구성 설정 
6.2 빠른수행 우선순위 설정 - 설정별 표시? 우선1건 표시? 
6.3 알림설정 : 목표, 당번 알림여부, 알림시간, 반복알림 등 
6.4 소셜계정 설정 : 카카오톡, 토스
   - 이체링크 생성을 위한 정보 : 계좌번호?... 
6.5 OCR 최적화를 위한 사용서비스 인증키 관리 : 구글 등
